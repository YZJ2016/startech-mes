# Spec 06 — Quality (qc) pages

Date: 2026-08-21  
Parent: `2026-08-21-mes-vue3-front-upgrade.md`  
Depends on: `2026-08-21-spec-02-mes-selectors.md` (and spec 01)

## Goal

Rewrite all **13** Vue 2 qc views to `<script setup>` in the Vue 3 app, keeping IQC/IPQC/OQC, templates, defects, and shared record UI on 3.8.2 `/mes/qc/**` APIs.

## In scope (Vue 3 target)

`startech-mes-basic/startech-mes-front/src/views/mes/qc/**/*.vue`  
`startech-mes-basic/startech-mes-front/src/api/mes/qc/**/*.js`

## Source of truth (Vue 2)

Views (`frontend/src/views/mes/qc/`, 13 files):

- `components/DetailedRecord.vue`
- `defectrecord/index.vue`
- `ipqc/index.vue`
- `ipqc/line.vue`
- `iqc/iqc.vue`
- `iqc/iqcline.vue`
- `oqc/index.vue`
- `oqc/line.vue`
- `qcdefect/index.vue`
- `qcindex/index.vue`
- `qctemplate/index.vue`
- `qctemplate/templateindex.vue`
- `qctemplate/templateproduct.vue`

APIs (`frontend/src/api/mes/qc/`): `defectrecord.js`, `ipqc.js`, `ipqcline.js`, `iqc.js`, `iqcline.js`, `oqc.js`, `oqcline.js`, `qcdefect.js`, `qcindex.js`, `qctemplate.js`, `templateindex.js`, `templateproduct.js`

Selectors: `iqcSelect`, `oqcSelect`, `qcindexSelect`, `defectSelect`, `itemSelect`, `vendorSelect`, `clientSelect`, `workorderSelect`.

`genCode` is used on ipqc, iqc, oqc, qcindex, qctemplate. Keep it.

## Decisions

1. Shared `components/DetailedRecord.vue` stays shared; IQC/IPQC/OQC must import it rather than copy.
2. Keep Vue 2 filenames (`iqc/iqc.vue` not forced to `index.vue`) so router component paths from `/getRouters` keep working.
3. `<script setup>` only, including the shared record component.
4. Inspection line grids stay on the same line APIs; no batching or new save endpoints.
5. Parallel with 03/04/05/07 after spec 02.

## Conversion checklist

- Options API → `<script setup>`
- `visible.sync` → `v-model` / `v-model:visible`
- `slot-scope` → `#default`
- `el-icon` / `.native`
- dicts → `useDict`
- treeselect → `el-tree-select` if any
- Pagination/RightToolbar `v-model:*`
- date `YYYY-MM-DD`
- `import.meta.env.VITE_APP_*`

## Success criteria

- 13 qc Vue files under `startech-mes-front/src/views/mes/qc` with `<script setup>`.
- API URLs/methods match Vue 2; `rows`/`total` for lists.
- IQC/IPQC/OQC header+line flows still compose `DetailedRecord` (or Vue 2 equivalent structure).
- Selectors from spec 02.
- Vue 2 untouched; no backend contract change.

## Non-goals

- Other domains.
- Changing QC result state machines or inspection APIs.
- New SPC charts not in Vue 2.
- Cutover (spec 08).

## Verification

- Count `.vue` = 13.
- Grep Options API / `slot-scope` / `.sync`.
- Smoke (if claimed): open IQC list and one template page against local 8085.
- Do not claim build success without running the command.
