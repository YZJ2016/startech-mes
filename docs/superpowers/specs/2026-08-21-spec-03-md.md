# Spec 03 — Master data (md) pages

Date: 2026-08-21  
Parent: `2026-08-21-mes-vue3-front-upgrade.md`  
Depends on: `2026-08-21-spec-02-mes-selectors.md` (and spec 01)

## Goal

Rewrite all **18** Vue 2 md views to `<script setup>` in the Vue 3 app, with matching API modules, so master-data menus from `/getRouters` resolve and behave against 3.8.2 APIs.

## In scope (Vue 3 target)

`startech-mes-basic/startech-mes-front/src/views/mes/md/**/*.vue`  
`startech-mes-basic/startech-mes-front/src/api/mes/md/**/*.js`

Routes come from backend `/getRouters` (component path `mes/md/...`). Do not invent a second menu system. Register nothing that changes URL or permission strings.

Many of these pages call `genCode` (`/system/autocode/get/:ruleCode`). Keep that call.

## Decisions

1. One Vue file in Vue 3 per Vue 2 file; keep relative component splits (`mditem/components/*`, `workstation/components/*`).
2. `<script setup>` only.
3. API file names may keep Vue 2 spelling (`mdItem.js`, `taskTutnPlate.js`) so imports stay mechanical.
4. Item type trees: `el-tree-select` / existing shell `TreePanel` if the Vue 3 user page pattern fits; do not add `vue-treeselect`.
5. Upload fields use the spec 01 MinIO default.

## Conversion checklist

- Options API → `<script setup>`
- `visible.sync` → `v-model` / `v-model:visible`
- `slot-scope` → `#default`
- `el-icon` / `.native` as in parent overview
- dicts → `useDict`
- treeselect → `el-tree-select`
- Pagination `v-model:page` / `v-model:limit`; RightToolbar `v-model:showSearch`
- `yyyy-MM-dd` → `YYYY-MM-DD`
- `process.env.VUE_APP_*` → `import.meta.env.VITE_APP_*`

## Success criteria

- 18 md Vue files exist under `startech-mes-front/src/views/mes/md` and use `<script setup>`.
- Corresponding `src/api/mes/md` modules preserve Vue 2 URLs and HTTP methods.
- List/create/update/delete/export (where Vue 2 had them) still hit the same paths; list still reads `rows`/`total`.
- Selectors come from spec 02, not inlined dialogs.
- Vue 2 `frontend/` unchanged. No backend changes.

## Non-goals

- pro/wm/qc/cal/dv/tm and other domains.
- Changing md REST contracts or table schemas.
- Redesigning the md UX.
- Production cutover (spec 08).
