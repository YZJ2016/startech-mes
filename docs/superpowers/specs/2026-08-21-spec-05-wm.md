## Decisions

1. Map 34 files 1:1, including misspellings (`subpackge`, `productsalse`, `rtsalse`) so backend component paths and git history stay obvious.
2. Header/line split stays; line components are not merged into index.
3. Barcode print stays client-side as in Vue 2; do not add a new print service.
4. `<script setup>` only.
5. Can run in parallel with specs 03, 04, 06, 07 after selectors exist.

## Conversion checklist

- Options API → `<script setup>`
- `visible.sync` → `v-model` / `v-model:visible`
- `slot-scope` → `#default`
- `el-icon` / `.native`
- dicts → `useDict`
- treeselect → `el-tree-select` (warehouse/location trees)
- Pagination/RightToolbar `v-model:*`
- date formats `YYYY-MM-DD`
- `import.meta.env.VITE_APP_*`

## Success criteria

- 34 wm Vue files under `startech-mes-front/src/views/mes/wm` with `<script setup>`.
- API modules preserve Vue 2 URLs/methods; lists use `rows`/`total`.
- Header pages still open line editors; selectors are spec 02.
- Vue 2 untouched; no backend contract change.
