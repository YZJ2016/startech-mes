## Goal

Rewrite all **17** Vue 2 pro views to `<script setup>` in the Vue 3 app, including workorder, route, process, feedback, repair, and schedule. Preserve 3.8.2 `/mes/pro/**` contracts.

## Decision: dhtmlx-gantt (optional 4b)

Vue 2 `schedule/ganttx.vue` imports `dhtmlx-gantt` (also listed in Vue 2 `package.json` with `@dhtmlx/trial-vue-gantt`). The Vue 3 3.9.2 shell has **no** gantt dependency.

**Default (spec 04):** port `ganttx.vue` / `ganttedit.vue` / `schedule/index.vue` by adding **only** `dhtmlx-gantt` (the library Vue 2 actually imports in `ganttx.vue`) if it initializes cleanly under Vue 3 `<script setup>` (init/teardown on `onMounted`/`onBeforeUnmount`, `ref` on the DOM node). Do not bump Vue/Vite. Do not add the trial Vue wrapper unless 4a proves the raw library cannot bind.

**Optional 4b (if gantt blocks the rest of pro):** ship all non-gantt pro pages in 04; isolate `schedule/ganttedit.vue`, `schedule/ganttx.vue`, and any schedule view that cannot render without them into a follow-up 4b spec. List pages still count toward the 17; 4b is a risk valve, not a scope cut without an explicit note in the delivery report.

Do not copy license keys or private registry tokens if any appear in Vue 2 env; use the same public package Vue 2 already depends on.

## Decisions (other)

1. `<script setup>` for all 17 files, including gantt wrappers.
2. Keep `listGanttTaskList` URL and payload unchanged.
3. Workorder nested bom/item/tool tabs stay nested files.
4. `genCode` stays where Vue 2 uses it (process, proroute, workorder).

## Conversion checklist

- Options API → `<script setup>`
- `visible.sync` → `v-model` / `v-model:visible`
- `slot-scope` → `#default`
- `el-icon` / `.native`
- dicts → `useDict`
- treeselect → `el-tree-select`
- Pagination/RightToolbar `v-model:*`
- Gantt: replace `this.$refs.gantt` with `ref()`; destroy/clear gantt on unmount to avoid duplicate layouts
- `process.env` → `import.meta.env`

## Success criteria

- 17 pro Vue files under `startech-mes-front/src/views/mes/pro` with `<script setup>` **or** 04 + documented 4b remainder.
- `src/api/mes/pro` URLs match Vue 2 (including gantt list).
- Non-gantt workorder/process/route/feedback/repair usable with spec 02 selectors.
- If dhtmlx is added, it is a dependency addition only — no Vue/Vite major bump.
- Vue 2 untouched; no backend contract change.

## Non-goals

- Other MES domains.
- Replacing gantt with a different chart library in 04 (that would be a product decision in 4b).
- Changing `/mes/pro/**` APIs.
- Cutover (spec 08).

## Verification

- Count views = 17 (or 17 minus explicitly deferred 4b files, named in the report).
- Grep `slot-scope`, `visible.sync`, Options API in pro views.
- If gantt is in: open schedule page locally; if it fails, stop and open 4b rather than rewriting APIs.
- Do not claim build success without running `npm run build:prod`.
