## Goal

Rewrite **cal (13)** and **dv (8)** Vue 2 views to `<script setup>` in the Vue 3 app (21 pages total). Calendar/team/plan and equipment/check/repair stay on 3.8.2 `/mes/cal/**` and `/mes/dv/**` APIs.

These domains share team/machinery pickers but are otherwise independent; they ship as one spec because neither is large enough to split further.

## Decisions

1. Cal and dv may be implemented in either order inside this spec; both must land before spec 08.
2. Keep calendar sub-views as separate files (person/station/task/team), not one mega-calendar.
3. `<script setup>` only.
4. Machinery type tree: `el-tree-select` / shell tree patterns, not `vue-treeselect`.
5. Parallel with 03–06 after spec 02.

## Conversion checklist

- Options API → `<script setup>`
- `visible.sync` → `v-model` / `v-model:visible`
- `slot-scope` → `#default`
- `el-icon` / `.native`
- dicts → `useDict`
- treeselect → `el-tree-select`
- Pagination/RightToolbar `v-model:*`
- date/time pickers: Element Plus `YYYY-MM-DD` / `HH:mm` as Vue 2 intended
- `import.meta.env.VITE_APP_*`

## Success criteria

- 13 cal + 8 dv Vue files in the Vue 3 tree with `<script setup>`.
- API URLs/methods match Vue 2.
- Team member and check-plan subject/machinery subpages still attach to their headers.
- Selectors from spec 02.
- Vue 2 untouched; no backend contract change.

## Non-goals

- tm/edu/report/camera/contract/sale (spec 08).
- Changing shift or check-plan backend rules.
- New calendar libraries (FullCalendar, etc.) unless Vue 2 already used them — Vue 2 here is Element tables/dialogs, keep that.
- Cutover (spec 08).
