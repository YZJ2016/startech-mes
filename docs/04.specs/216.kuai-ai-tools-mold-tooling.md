# KU-AI 场景 Tool：模具寿命与工装状态

从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：已完成（集成登记与审计修复均落地）。

## 1. Spec

### Capability

- Name: 新增只读 Tool `query_molds`、`query_tooling`。
- Module: `riveredge-backend/src/apps/kuaiai/services`（tools 适配层）、manifest `ai_tools`。
- Priority: P3（S20 模具寿命/工装状态）。
- Related requirement/design documents: 需求 25 SC-D1、SC-D5、SC-D7；设计 26 §4、§5.2；前置 spec 189、190、210。

### Business Goal

工艺/设备问“模具 M-078 打了多少模次、还能用多久”“工装 T-110 现在在哪个库位、状态是否正常”，助手基于模具台账与工装台账的真实记录回答。

### Scope

In scope（模具与工装权限码不同，SC-D7 拆两个 Tool）：

| Tool | 参数 | 底层 service | 权限码 |
| --- | --- | --- | --- |
| `query_molds` | `keyword?`、`status?`、`life_warning_only?`、`limit≤20` | 模具台账 service（T1 核对类名/寿命字段） | `kuaizhizao:equipment-management-molds:read` |
| `query_tooling` | `keyword?`、`location?`、`status?`、`limit≤20` | 工装台账 service（T1 核对） | `kuaizhizao:equipment-management-tool-ledger:read` |

- `query_molds` 输出模具编码、名称、累计模次、寿命上限、剩余寿命百分比、状态、最近保养时间；`life_warning_only=true` 时只列剩余寿命低于阈值的（阈值取模型字段或固定 20%，T1 定）。
- `query_tooling` 输出工装编码、名称、库位、状态、领用/归还信息。
- 数据范围：service 不接收 `current_user` 的，适配层补行级范围；资源键 T1 定。

Out of scope:

- 模具/工装的领用、维修、保养登记（写操作）。
- 模具设计与图纸。

### Acceptance Criteria

1. `query_molds` 寿命字段齐全；`life_warning_only` 只列到期/预警模具；剩余寿命按 service 数据确定性计算。
2. `query_tooling` 库位与状态准确。
3. 行级范围收敛；非法参数固定错误文案；空结果、异常口径一致。
4. 两个 Tool 登记于 manifest（`label`、`kind=read`）。

### Rules and Constraints

Tenant isolation:

- 传 `ctx.tenant_id`。

Security and masking:

- 不输出模具采购价格与供应商商务信息（状态字段本身可见）。

Audit and lineage:

- 沿用 Tool 级审计。

AI/rule-engine rules:

- 寿命/状态来自记录；寿命预警阈值为确定性规则（SC-D5）。

Database rules:

- 无表结构变更。

### 场景模板（Y3=a）

本单元交付时同步登记场景模板 `mold-tooling`（模具工装助手）：预置档案 `enabled_tools` 为本单元 Tool 集合，停用 + 空授权（Y4=a）；模板 key 即能力矩阵场景卡，默认绑定同 key 预置实例（spec 191，Y1/Y2=a）。system_prompt 只引用本单元 Tool，插画按 spec 201 T2 约定。
