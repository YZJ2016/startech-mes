### Business Goal

`type=weaviate` 的读写删全部打 `MesAiD{dimension}` class，并强制 Weaviate tenant `t{tenantId}`；对象属性与 `where` 仍带 `tenant_id` 与 `kid`。

### Scope

In scope:

- Weaviate 专用命名：`weaviateClassName(dimension)` → `MesAiD{dimension}`；`weaviateTenantName(tenantId)` → `t{tenantId}`。现网 `collectionName(tenantId, kid)` **仅留给 DashVector**
- `createSchema`：MT enabled；class 用维度；确保 tenant 存在；属性集与现网相同；已存在 409/422 可忽略
- `storeEmbeddings` / `search` / `removeByDoc`：请求必须带 tenant；`where` 仍 And `tenant_id` + `kid`（删除再加 `docId`）
- `removeByDoc` 增加 `dimension`；Weaviate ≤0 失败关闭
- 单测 mock HTTP：schema body 含 multiTenancy 与 `MesAiD*`、**不含** `MesAiK*`；search/delete 带 tenant；无上下文 / 租户不一致失败关闭；DashVector 测例不因本单元改名

Out of scope:

- ingest / Retriever 调用方补维度（**101**）
- 手册（**102**）
- live Weaviate、旧 class 迁移
- 改 93 HTTP、Vue、DashVector collection 字符串

Non-goals:

- 不引入 `langchain4j-weaviate`
- 不实现「不带 tenant 则搜全 collection」

### Acceptance Criteria

- 建 schema POST 含 `MesAiD{dim}` 与 multi-tenancy enabled，tenant 名为 `t{tid}`
- search GraphQL（或等价）带 tenant，且 where 含 `tenant_id` 与 `kid`
- 无 `TenantContext` 或 `tenantId` 不匹配 → 不发 HTTP 或发前失败关闭
- `collectionName(1,8)` 仍为 `MesAiK1_8`（DashVector 回归夹具）
- 第 4 节未编码前不得写「测试通过」

### Rules and Constraints

Tenant isolation:

- tenant 名只从 `TenantContext` 拼；禁止参数另传 Weaviate tenant
- I-A3：`where` 不得省略 `tenant_id`

Security and masking:

- 测试夹具 host 用 `.invalid` / example；不写真实集群
- 日志不打 API Key

Audit and lineage:

- 无 DDL

AI/rule-engine rules:

- `vectorizer` 仍 `none`；embedding 不在本适配器内调用

Database rules:

- 不改 yml 真值；不改绑定表

## 2. Plan

### Implementation Approach

把 class 命名从共用 `collectionName` 拆出 Weaviate 函数，避免 DashVector 误伤。所有 Weaviate HTTP 入口统一附加 tenant。`removeByDoc` 签名变更后编译失败的调用点在本单元可暂时只改适配器接口与 Weaviate 实现，**调用方在 101 一次补齐**（本单元若改接口，须同步改编译能过的最小调用，避免仓库红；若选择 100 只加重载、旧签名 Weaviate 抛错，须在测试中锁死旧签名不可用）。

推荐：接口改为带 `dimension` 的唯一签名，100 改接口 + Weaviate + DashVector 忽略参数 + 现网调用点先传「从知识库模型读到的维度或失败关闭」，以免 `ktg-ai` 编译失败。若调用点改动超过适配器，把调用点算进 101，100 用重载：新签名完整实现，旧签名 Weaviate 抛「缺少维度」。

### Affected Modules

- `ktg-ai` `runtime/vector/WeaviateHttpVectorStore.java`、`VectorStoreSupport.java`（新增 Weaviate 方法，不改 `collectionName` 语义）、`VectorStoreService.java`、对应 `*Test`

### Public Contracts

- 对外 HTTP 不变
- 内部：`VectorStoreService.removeByDoc` 增维（WM-D7）

### Persistence Changes

- 无

### Transaction Boundaries

- 无新事务

### Risks

- 共用 `collectionName` 被改成 `MesAiD*`
- GraphQL 漏 `tenant` 导致 Weaviate 拒请求或扫错（实现须失败关闭，不得省略）
- 旧签名删除导致 101 未开工时主分支无法编译 → 用重载或 100/101 同 PR

### Verification Strategy

- `mvn -pl ktg-ai -am test`（Java 17）；不连 live
- 第 4 节据实
