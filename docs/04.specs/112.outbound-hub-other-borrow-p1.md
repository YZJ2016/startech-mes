### Business Goal

P0 只聚合现网领料 + 销售出库。本单元把 CAT-W03 剩余的**其他出库、借料**做成**两套独立头/行表、两套 REST、两套 Vue3 CRUD 页**（对照快格云分表+分权限，不合并成一张「杂项出库」表），再把类型臂加进出库 Hub UNION。还料（`material_return`）是入库方向，本单元不做。旧领料/销售出库契约不变。

### Scope

In scope:

- 其他出库：`wm_other_issue` / `wm_other_issue_line`，REST `/mes/wm/otherissue` + `/mes/wm/otherissueline`，Vue3 `views/mes/wm/otherissue`
- 借料：`wm_material_borrow` / `wm_material_borrow_line`，REST `/mes/wm/materialborrow` + `/mes/wm/materialborrowline`，Vue3 `views/mes/wm/materialborrow`
- `GET /mes/wm/outboundhub/list` **加法**类型臂 `OTHER_ISSUE` / `MATERIAL_BORROW`（仍服务端合并 + 每侧 `tenant_id`）
- 菜单 9320 段其他出库、9330 段借料（不占 9300–9319）；不自动 `sys_role_menu`
- UI-A：只新增上述两页 + Hub 类型筛/抽屉类型分支；不重排旧领料/销售出库/入库 Hub

Out of scope:

- 送货单（113）、退料/退货（114）、委外发料、采购退货（OH-G3 残留）
- 还料 / `material_return`（入库）
- Hub 拉单（130 / OH-G6，本单元 OUT）；撤回（本单元未写；131 标第二刀 OUT，现挂 **133**）
- CAT-W01 看板、CAT-W04 功能业务、CAT-W05 库存管理、CAT-W06 报表、CAT-W07 配料
- OQC（OH-G2）、出库金额（OH-G5）、Hub 打印（OH-G4）
- 改 Vue2、改入库 Hub、扩 permitAll、前端假分页

### Acceptance Criteria

- **编码门禁：**（1）点名 112；（2）107 编码完成；（3）头表与 HTTP 已书面拍板（见下与设计 15 §7.1）；（4）缺口 15 无未处理待确认（冲突）。OUT-F02 **已拍板不纳入** `rtissue`/`rtsalse`（114）。
- Hub 可按 `OTHER_ISSUE` / `MATERIAL_BORROW` 筛选；UNION 每侧租户条件；107 的 ISSUE/PRODUCT_SALSE 行为不回退
- 两套单据各自 CRUD + `@PreAuthorize`；不进 `MesPermitAllProvider`
- 无金额列；tenant Flyway；只信 JWT

### 表与 HTTP 拍板（本单元锁定）

对照快格云其他出库 / 借料是**分表、分 CRUD、分权限**。现网模型命名，不把快格云 6 种枚举当表名。

| 单据 | Hub 类型 | 表 | REST | 权限字 | 菜单 |
| --- | --- | --- | --- | --- | --- |
| 其他出库 | `OTHER_ISSUE` | `wm_other_issue` + `wm_other_issue_line` | `/mes/wm/otherissue`、`/mes/wm/otherissueline` | `mes:wm:otherissue:*` | 9320–9324 |
| 借料 | `MATERIAL_BORROW` | `wm_material_borrow` + `wm_material_borrow_line` | `/mes/wm/materialborrow`、`/mes/wm/materialborrowline` | `mes:wm:materialborrow:*` | 9330–9334 |

- 状态机：现网 `PREPARE` → `PUT /{id}` 执行过账 → `FINISHED`。无金额列。借料无还料数量列。
- Hub list query `outboundType` 加法上述两值；默认 UNION 四臂（领料+销售出库+其他出库+借料）。不含 rtissue/rtsalse/送货单。

### Rules and Constraints

Tenant isolation:

- 无 `TenantContext` 不得访问新 wm 表；Hub 每臂 `tenant_id`
- 只信 JWT；无客户端租户头

Security and masking:

- 新路径 `@PreAuthorize`；不进 `MesPermitAllProvider`

Audit and lineage:

- 新 DDL 只进 Flyway tenant；菜单走 master；不改历史 `backend/sql/`
- 菜单号禁止占用 9300–9319

Database rules:

- 不加金额列（OH-G5）
- 不写 yml 业务键；新表进 `tenant.line.include-tables` 与 `TenantDedicatedSchema.WM_TABLES`
