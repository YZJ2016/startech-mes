### Business Goal

能设计并预览一块大屏，并用已约定的免登录地址分享大屏与账表。两条链接在能打开时已经受到同一套过期、访问口令、IP 白名单和访问日志约束。本段不留下一条不受控的免登录链接。版本回看不在本段。

### Scope

In scope:

- 大屏使用迁移 92 / 563 已有字段，不新增列：`layout_config`、`widgets_config`、`theme_config`、`tv_config`（563 加在 `apps_kuaireport_dashboards`）、`status`（默认 `'DRAFT'`）。
- 每个组件只绑一个数据源，并自带刷新间隔。绑定与间隔写在 `widgets_config`，不新增列。一块大屏可以有多个组件、因而多个源；这不是跨库关联。
- 组件都在本切片内，分两截实现，但不拆成另一份 spec：先指标、表格、图表；再边框、标题、轮播、时钟、图片、视频、网页嵌入。
- 数据仍经 145 的执行路径。组件要数字或表格时，返回形态仍是 `data` / `total` / `summary`。不读数采。
- 免登录浏览路径已在 `riveredge-frontend/src/utils/kuaireportSharedPath.ts`：
  - `SHARED_DASHBOARD_PATH = '/apps/kuaireport/dashboards/shared'`
  - `isKuaireportSharedBrowsePath` / `isKuaireportSharedApiPath` 把该路径视为不携带会话的公开接口
- 分享文件预览已在 `kuaireportSharedFilePreview.ts`：`getDashboardSharedFilePreviewUrl` 请求 `/apps/kuaireport/dashboards/shared/file-preview`，查询参数名为 `token` 与 `uuid`（可选 `size`），这三项保持。成功响应必须是 `{ success, preview_url }`；`success` 为假或没有 `preview_url` 时调用方抛错。该 URL 是已有调用，处理函数是本切片要补的槽位行为。文档不写参数示例值。口令不进该 URL。文件预览可凭通过后的 8 小时 HttpOnly cookie 再走过期与 IP 检查。
- 主路由 `riveredge-frontend/src/routes/index.tsx` 用 `import.meta.glob('../apps/kuaireport/pages/*SharedView.tsx')`，再按文件名 `DashboardSharedView`、`ReportSharedView` 匹配。大屏分享页必须是 `riveredge-frontend/src/apps/kuaireport/pages/DashboardSharedView.tsx`；账表分享页为 `riveredge-frontend/src/apps/kuaireport/pages/ReportSharedView.tsx`。文件名对不上时该页渲染 `null`。
- 四项管控用大屏表上已有列（KRP-D7）：
  - 过期：`share_expires_at`（迁移 92）
  - 访问口令：只存哈希到 `share_password_hash`（迁移 563，`VARCHAR(128)`）。打开口令用请求头 `X-Share-Password`；通过后发 8 小时 HttpOnly cookie（解锁凭据，不是口令明文）。文件预览可凭该 cookie 再走过期与 IP 检查。口令不进 URL、响应和访问日志。不明文落库，不回传哈希。
  - IP 白名单：`share_allow_ip_cidrs`（JSONB）
  - 访问日志：`apps_kuaireport_share_access_logs`（`resource_type`、`resource_id`、`share_token`、`action` 默认 `'view'`、`client_ip`、`success`、`detail`）。日志不写口令。
- 开启分享时必须同时写入过期时间与口令哈希，缺一则分享地址拒绝打开。IP 白名单是可选加严，不是打开分享的必填项（**KRP-D8**）：`share_allow_ip_cidrs` 为空时不做 IP 匹配，过期与访问口令仍然有效；非空且客户端 IP 不在名单内才拒绝。不新增列。大屏与账表同一套规则。
- 每次打开（成功或拒绝）写一条访问日志。
- 账表免登录路径本期交付（**KRP-D9**）。磁盘上 `kuaireportSharedPath.ts` 已把 `SHARED_REPORT_PATH = '/apps/kuaireport/reports/shared'` 与大屏一样视为免登录路径。该路径与大屏同一套四项管控（过期、口令哈希、IP 白名单、访问日志；列仍是报表表上的 `share_expires_at`、`share_password_hash`、`share_allow_ip_cidrs`），通过后才返回账表数据。页面文件为 `riveredge-frontend/src/apps/kuaireport/pages/ReportSharedView.tsx`。四项管控不留到 149。不改 146 已种入行的默认不分享：KRP-D6 的 10 张系统报表默认 `is_shared` 为假，须人显式打开分享后才签发免登录链接。

### Acceptance Criteria

1. 能保存一块大屏的 `layout_config`、`widgets_config`、`theme_config`、`tv_config`。每个组件只有一个数据源引用。指标/表格/图表以及边框、标题、轮播、时钟、图片、视频、网页嵌入都能放进 `widgets_config` 并在预览中出现。
2. 已登录预览不走分享路径。免登录大屏只走 `/apps/kuaireport/dashboards/shared`（及该前缀下已有文件预览 URL）。分享页文件为 `pages/DashboardSharedView.tsx`，否则该页渲染 `null`。
3. 未写 `share_expires_at` 或未写 `share_password_hash` 时，分享地址打不开。过期后打不开。口令不匹配打不开。白名单为空时不做 IP 匹配，过期与访问口令仍然有效。白名单非空且 IP 不在名单内打不开。上述拒绝与成功打开各写 `apps_kuaireport_share_access_logs` 一行，`detail` 与日志中无口令、无哈希。大屏与账表同一套检查。
4. `getDashboardSharedFilePreviewUrl` 的查询参数仍是 `token`、`uuid`、可选 `size`。口令不进 URL。文件预览可凭通过后的 8 小时 HttpOnly cookie 再走过期与 IP 检查。校验通过后响应为 `{ success, preview_url }`，调用方返回 `preview_url`。`success` 为假或没有 `preview_url` 时调用方抛错。
5. 打开口令用请求头 `X-Share-Password`。通过后发 8 小时 HttpOnly cookie（解锁凭据，不是口令明文）。口令不进 URL、响应和访问日志，分享响应与日志也不包含哈希。
6. 大屏分享与账表分享都做，四项管控相同。`/apps/kuaireport/reports/shared` 在过期、口令哈希、IP 白名单、访问日志通过后才返回账表数据。页面文件为 `riveredge-frontend/src/apps/kuaireport/pages/ReportSharedView.tsx`。146 已种入的 10 张系统报表默认 `is_shared` 为假；本切片不改这些行的默认不分享，显式开启后才签发免登录链接。
7. 本切片没有角色授权页、订阅任务、版本恢复操作，也不自己插入 `apps_kuaireport_dashboard_versions`。大屏保存仍走本切片；保存成功后同一事务调用 149 的插入函数。

### Rules and Constraints

Tenant isolation:

- 大屏行带 `tenant_id`。分享解析只加载该大屏所属租户的数据，不靠客户端传租户。
- 无登录会话时只允许上述分享路径，其它报表接口仍要登录。

Security and masking:

- 口令只以哈希写入 `share_password_hash`。打开口令用请求头 `X-Share-Password`；通过后发 8 小时 HttpOnly cookie（解锁凭据，不是口令明文）。口令不进 URL、响应和访问日志。
- `share_token` 是访问凭据，不写进日志以外的调试输出；访问日志表本身已有 `share_token` 列，只按该列记录，不附加口令。

Audit and lineage:

- 访问结果只记 `apps_kuaireport_share_access_logs` 的已有列。

AI/rule-engine rules:

- 不涉及。

Database rules:

- 不新增列。`apps_kuaireport_dashboards.code` 在迁移 92 是表级 `UNIQUE`，本切片不改已入库迁移，新建大屏时仍写入 `tenant_id`。
- 本切片不自己插入 `apps_kuaireport_dashboard_versions`，也不提供回看或恢复。大屏保存仍走本切片；保存成功后同一事务调用 149 的插入函数。

### 依赖顺序

- 依赖 145 的数据源与执行。预览大屏组件不依赖 146 的十张系统报表，也不依赖 147 的设计器。
- 排序仍放在 147 之后，与 KRP-P1→P5 一致。
- 不依赖 149 才能分享。大屏保存仍走本切片；保存成功后同一事务调用 149 的插入函数。

## 2. Plan

### Implementation Approach

1. 大屏设计只编辑已有 JSON 列。组件数据源引用指向 `apps_kuaireport_data_sources`。
2. 分享打开前按顺序检查：哈希已存在、未过期、请求头 `X-Share-Password` 与口令匹配、白名单（非空才检查）。通过后发 8 小时 HttpOnly cookie（解锁凭据，不是口令明文）。任一失败写失败日志并拒绝。口令不进 URL、响应和访问日志。
3. 文件预览复用已有查询参数名 `token`、`uuid`、可选 `size`，口令不进 URL，先做与打开相同的校验。文件预览可凭通过后的 8 小时 HttpOnly cookie 再走过期与 IP 检查。成功响应为 `{ success, preview_url }`；失败则让调用方抛错。
4. `/apps/kuaireport/reports/shared` 与大屏同一套四项管控，通过后才返回账表数据。不把四项管控留到 149。146 已种入的 10 张保持默认不分享，显式开启后才签发免登录链接。

### Affected Modules

- `riveredge-backend/src/apps/kuaireport`（大屏保存、分享打开、文件预览、访问日志）
- `riveredge-frontend/src/apps/kuaireport`（大屏设计与预览；分享页 `pages/DashboardSharedView.tsx` 与 `pages/ReportSharedView.tsx`）
- 只读已有：`src/utils/kuaireportSharedPath.ts`、`src/utils/kuaireportSharedFilePreview.ts`
- 不改这两个 utils 的路径常量，除非实现发现常量与路由不一致；不一致时先改槽位路由去对齐常量。

### Public Contracts

- 已存在的浏览路径：`/apps/kuaireport/dashboards/shared`。
- 已存在的预览调用：`/apps/kuaireport/dashboards/shared/file-preview`，参数名 `token`、`uuid`、可选 `size`。成功响应为 `{ success, preview_url }`。处理函数是要补的槽位行为。
- 已存在的账表路径：`/apps/kuaireport/reports/shared`。本切片套上与大屏相同的四项管控，通过后才返回账表数据。页面文件为 `riveredge-frontend/src/apps/kuaireport/pages/ReportSharedView.tsx`。

### Persistence Changes

- 无新表。更新 `apps_kuaireport_dashboards` 的布局列与 `share_expires_at`、`share_password_hash`、`share_allow_ip_cidrs`、`share_token`、`is_shared`。插入 `apps_kuaireport_share_access_logs`。

### Transaction Boundaries

- 拒绝分享时仍要留下访问日志；日志写入失败不得变成「未记录但已把大屏数据返回」。
- 大屏保存与调用 149 插入函数在同一事务。保存未成功则不插入版本行。

### Risks

- 只做路径、不做过期与口令，会留下 KRP-D7 禁止的不受控链接。
- 把口令明文写入 `share_password_hash` 或日志，验收不通过。
