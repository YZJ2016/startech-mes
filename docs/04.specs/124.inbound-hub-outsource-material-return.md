## 1. Spec

### Capability

- Name: 入库 Hub — 委外退料（IH-G13 臂 B：`OUTSOURCE_MATERIAL_RETURN`）
- Module: **`startech-mes-basic/backend/ktg-mes`**（新建委外退料头/行 + 过账；扩入库 Hub UNION）+ Flyway + Vue3。**禁止**改 Vue2；**禁止**合并快格源码。**本文件仅文档**；编码须点名 **124**。
- Priority: **默认后置**（**CAT-O01**）。依赖委外工单；建议在 **123** 收货与委外 **发料**（出库 OH-G3 或 CAT-O01 发料）可追溯之后开工。
- Related requirement/design documents:
  - 缺口 14 **IH-G13**；总览 **CAT-O01**；设计 14 §7.5；总控 104
  - 兄弟：`123` 收货、`125` 退货；出库发料指针 OH-G3
  - 对照只读：`OutsourceMaterialReturn` / Hub `outsource_material_return`

### 拆分决策

见 **123** §「拆分决策」——三独立表/服务 → **123/124/125** 三分文件。本文件 **只** 交付退料臂。

### Business Goal

供应商将委外未使用原料退回本厂仓库：仓管建 **委外退料单**（关联委外工单，可选关联委外发料单），校验可退数量后过账 **加库存**，并在入库 Hub 以 `OUTSOURCE_MATERIAL_RETURN` 可见。

**现网事实（2026-09-17）：**

| 项 | 现网 | 124 假设 |
| --- | --- | --- |
| 委外退料/发料表 | **无** | 新建 `wm_outsource_material_return*`；发料表属 CAT-O01/OH-G3（可空关联） |
| 入库 Hub | 七臂起 | +本类型臂 |
| 快格 capabilities | 退料为 Hub **preview-only**、**不可 withdraw** | Startech：本单元提供 CRUD+过账+Hub 展示；**撤回留给 127 且默认本类型不支持**（对齐快格） |

**对照只读：** `OutsourceMaterialReturnService`：按发料汇总已退、校验 `quantity ≤ returnable`；无发料 id 时按工单 preview 行校验。

### Scope

In scope:

- tenant：`wm_outsource_material_return` / `_line`（若单行模型够用可头表承载数量——**默认头+行** 对齐 119）
- master：菜单 **9400–9404**
- REST：`/mes/wm/outsourcematerialreturn`；权限 `mes:wm:outsourcematerialreturn:*`
- 规则：`outsource_work_order_id` 必填；可选 `outsource_issue_id`；超量拒绝；`PREPARE`→`FINISHED` 一步过账 `+1`
- Hub 臂 + Vue3 UI-A

Out of scope:

- 123 收货、125 退货、122 客供、126 拉单、127 撤回实现
- 委外发料出库页（OH-G3）——本单元 **只读引用** 发料 id（若尚无发料表：仅按工单可退量，T0 允许）
- 快格审核流 / 结算

### Acceptance Criteria

1. 点名 **124** + 委外工单可读；否则停止。
2. 超量退料拒绝；执行加库存；Hub 可筛。
3. 不改 123/125 表；出库 Hub 无本类型。
4. §4 **已实跑（代码已落）**；部署手验仍开。
