# Development Unit Template

Use this template before each implementation unit.

## 1. Spec

### Capability

- Name: 用 springboot2 内容替换 `ktg-generator`
- Module: `ktg-generator`
- Priority: P0
- Related requirement/design documents:
  - `docs/04.specs/11.backend-shell-swap-program.md`
  - 上一单元：`12.swap-ktg-quartz.md`（须 JDK 8 编译通过）

### Business Goal

代码生成器与若依 3.9.2 `springboot2` 的 `ruoyi-generator` 对齐，仍为 `ktg-generator` / `com.ktg.generator`。生成模板里的包名必须是 `com.ktg`，避免以后点生成产出 `com.ruoyi`。不改现有 Vue2 工程，不把 Vue3 前端引进仓库。

### Scope

In scope:

- 对照：`RuoYi-Vue-springboot2/ruoyi-generator/`（同一 commit `913524b1525a0e374774afbb54c452d8f68a5a8f`）
- 覆盖 nested `backend/ktg-generator/` 的 Java、`mapper/generator/*.xml`、`generator.yml`、`vm/**`
- 机械替换：Java/XML/yml/ **vm 模板** 中 `com.ruoyi` → `com.ktg`；pom `ruoyi-generator` → `ktg-generator`；parent 保持 `com.ktg:ktg`
- 对照 pom 使用 `velocity-engine-core`（上游 2.3）。允许根 POM 把 velocity 坐标/版本对齐到 springboot2；这不是 Boot 3/4 升级
- nested 旧 pom 声明的是 `org.apache.velocity:velocity`（1.7）——以对照模块 pom 为准切换，不要两套 velocity 混用

Out of scope:

- 改模块名/包名为 ruoyi
- 把生成器产出接到 `RuoYi-Vue3-front` 或改 `frontend/` Vue2
- 执行一次真实「生成并覆盖业务代码」
- Java 17 / Boot 3/4 / jakarta
- 五项接线

### Acceptance Criteria

- `rg "com\\.ruoyi" backend/ktg-generator` 为 0（含 `.vm`）
- `artifactId` 仍为 `ktg-generator`
- JDK 8 `mvn -pl ktg-generator -am compiler:compile` 成功后再开始 `14`
- 未改 `ktg-mes` 业务 Java

### Rules and Constraints

Tenant isolation:

- 不涉及

Security and masking:

- `generator.yml` 若含路径示例，不把本机绝对路径或密钥写入 spec

Audit and lineage:

- 不把生成结果提交进 mes 业务包

AI/rule-engine rules:

- 不涉及

Database rules:

- 不改 `gen_table` 结构（除非对照 XML 与现表不兼容——若发生，停止并写明，不要静默改生产库）

## 2. Plan

### Implementation Approach

1. 确认 `12` 已编译通过
2. 整树覆盖 `ruoyi-generator` → `ktg-generator`
3. 机械替换包名；**特别检查** `src/main/resources/vm/**`（上游含 vue3/ts 模板文件：只换包名字符串，不把 Vue3 工程引进本仓库）
4. 更新模块 pom：依赖跟对照走，GAV 留 ktg
5. 若根 POM 缺少 `velocity-engine-core` 管理，按 springboot2 根 POM 补属性/dependencyManagement，仍 Java 8

### Affected Modules

- `ktg-generator`
- 根 `backend/pom.xml`：仅 velocity 等 generator 所需的同代属性

### Public Contracts

- `GenController` HTTP 保持若依代码生成路径；管理端 Vue2 现有页面继续打这些 URL

### Persistence Changes

- 无新表。若 XML 列与现库不一致，记入第 4 节，不在本单元改库

### Transaction Boundaries

- 沿用换入源码

### Risks

- vm 漏替换导致生成物包名为 `com.ruoyi`
- velocity 1.7 与 2.x API 混用编不过
- 误改 `frontend/` 去「配套」vue3 模板

### Verification Strategy

- `rg "com\\.ruoyi" backend/ktg-generator`
- JDK 8 compile
