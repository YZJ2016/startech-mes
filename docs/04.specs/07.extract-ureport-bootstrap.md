# Development Unit Template

Use this template before each implementation unit.

## 1. Spec

### Capability

- Name: UReport 启动接线从 `ktg-admin` / `ktg-common` 迁出
- Module: `ktg-admin` / `ktg-common` → `ktg-mes`
- Priority: P1
- Related requirement/design documents:
  - `docs/04.specs/00.backend-extract-program.md`
  - 调查：报表业务已在 `ktg-mes.report`（`MySQLProvider`、`UreportFileTblController` `/ureportM`）；平台仍注册 Servlet 与内置数据源

### Business Goal

报表设计器与 `ktg-mes.report` 存储在换壳替换 admin/common 后仍能启动。`RuoYiApplication` 回到瘦入口，不再绑定 UReport。

### Scope

In scope:

- 将 `UReportConfig`（`BuildinDatasource`）迁入 `ktg-mes` 配置包
- 将 `RuoYiApplication` 上的 `@ImportResource("classpath:ureport-console-context.xml")`、`UReportServlet` 注册、`/ureport/*` 映射迁到 `ktg-mes` 的 `@Configuration`（ServletRegistrationBean 或等价）
- `ureport2-console` 依赖从 `ktg-common` 改挂 `ktg-mes`（`ktg-mes` 已有报表代码）
- 启动类去掉 UReport 专用注解/Bean；保留 `@SpringBootApplication` 与现有 `@EnableAsync` / `@EnableScheduling`（调度是否属于 MES 在 `09` 再评，本单元不删 `@EnableScheduling`）

Out of scope:

- 改报表模板存储、改 `MySQLProvider` 前缀
- 验证 UReport 在 Spring Boot 4 / Jakarta 上的兼容（属未来换壳，本单元仍在 Boot 2.5）
- `/ureport/**` 匿名策略（`08`）

### Acceptance Criteria

- `ktg-admin` 的 `RuoYiApplication` 不再 import `UReportServlet`，不再 `@ImportResource` ureport xml
- `UReportConfig` 不在 `ktg-admin`
- `ureport2-console` 不再由 `ktg-common/pom.xml` 声明
- `/ureport/*` Servlet 在启动后仍注册（有环境时访问控制台入口不 404）
- `/ureportM` 业务接口仍由 `ktg-mes.report` 提供
- compile 通过

### Rules and Constraints

Tenant isolation:

- 内置数据源仍用当前应用 DataSource，不按租户拆库

Security and masking:

- 报表可能查业务库，本单元不把数据源口令写入文档
- 不扩大 `/ureport/**` 暴露面

Audit and lineage:

- 模板仍走现有 MySQL Provider，不改表结构

AI/rule-engine rules:

- 不涉及

Database rules:

- 不改 `ureport` 相关业务表；只搬 Spring 接线

## 2. Plan

### Implementation Approach

1. 在 `ktg-mes` 增加配置类：注册 `UReportServlet` 到 `/ureport/*`，并 `@ImportResource` 原 xml（xml 若在 common 资源中，改为 mes 资源或明确仍从依赖 jar 读取）
2. 迁移 `UReportConfig`
3. 依赖改挂 `ktg-mes`
4. 瘦身 `RuoYiApplication`

### Affected Modules

- `ktg-mes`：配置类 + pom
- `ktg-admin`：`RuoYiApplication`、删除 `UReportConfig`
- `ktg-common`：删除 ureport 依赖（无其它引用后）

### Public Contracts

- Servlet 映射 `/ureport/*` 不变
- 业务 `/ureportM` 不变
- `ureport.mysql.provider` 配置前缀不变（`MySQLProvider` 已有 `@ConfigurationProperties`）

### Persistence Changes

- 无

### Transaction Boundaries

- 报表查询使用 UReport 自己的连接获取，不纳入 MES 业务事务

### Risks

- `ureport-console-context.xml` 找不到导致启动失败
- Servlet 注册晚于 Security 过滤器顺序变化（本单元不改 Security，若启动后 401 交给 `08`）
- 后续 Boot 4 换壳时 UReport 仍可能无法运行——本单元只保证当前栈可启动

### Verification Strategy

- 源码检索 `UReportServlet` 仅 mes 配置类
- Maven compile
- 有环境时启动 `ktg-admin` 看控制台是否出现应用启动成功，且 `/ureport/` 不是 404（不要把内网地址写入记录）
