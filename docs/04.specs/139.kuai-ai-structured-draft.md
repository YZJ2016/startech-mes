## 1. Spec

### Capability

- Name: S6 — `structured_draft` 换 `with_structured_output`
- Module: **仅** `kuaigeyun-mes` 的 `core/ai/structured_draft.py`（白名单内）+ 经 S2 `runtime/model_factory` 解析模型。**禁止**改其它 `core/ai`；**禁止**绑 DeepSeek SDK。
- Priority: P2（KR-X6；依赖 S2 `model_factory`）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/16.kuai-ai-rebuild-gaps.md`（KR-D13、KR-X6）
  - 设计：`docs/03.design/16.kuai-ai-rebuild-plan.md`（§6 路径 C、§15 S6）
  - 依赖：`135.kuai-ai-runtime-agent.md`

### Business Goal

结构化草稿主路径改为 `ChatOpenAI.with_structured_output(Pydantic)`（目录行优先），删除字符串抠 JSON 主路径；图片走多模态 content block（vision 目录行或同工厂兜底），不再绑 `deepseek_vision_client` / DeepSeek SDK。

### Scope

In scope:

- 改 `structured_draft.py`：`complete_json`（或等价入口）→ `build_chat_model` / vision 工厂 → `with_structured_output` → 校验过的 pydantic 对象
- 删/停用 `extract_json_object` 主路径依赖
- 图片：多模态 content block；vision 目录行优先，同工厂兜底（OpenAI 兼容，非 DeepSeek SDK）
- 保持现有对外调用方可用（签名尽量兼容；若必须微调仅限内部，产品信封不变）

Out of scope:

- 新前端页；确认闸；工作流；知识/MCP/会话新功能
- 恢复字符串抠 JSON 为主路径；按厂商分支 SDK
- 改 `chat_handler` 契约；改 `/ai/**` 或 `code/msg/data`
- HyDE、OCR 扫描件产品化、审计查询页

## 5. Final Summary

Files changed:

- `kuaigeyun-mes/riveredge-backend/src/core/ai/structured_draft.py`（改）
- `kuaigeyun-mes/riveredge-backend/tests/core/ai/test_s6_structured_draft.py`（新增）

Behavior delivered:

- `complete_json`：主路径 `build_chat_model(tenant_id)` → `with_structured_output(schema, method="json_mode")`（schema=None 回 dict；BaseModel 子类回校验实例；json_mode 响应面仍是 `response_format=json_object`，兼容面最广）；非 dict 顶层结果失败关闭；上游异常统一 → `ValidationError(error_prefix)`，日志仅落 error_type/tenant_id（KR-I5）
- `structure_text`：`with_structured_output(result_type, include_raw=True)`；解析失败先走 `_salvage_parsed` 严格归一（`json.loads` + `items` 归一沿用旧口径，非正则抠 JSON），再 `model_validate`，全败 → `ValidationError`；OCR meaningfulness 校验保留
- `structure_from_image`：vision OCR 经 `extract_text_from_image`（S2 多模态 content block）→ `structure_text`；12MB / 非 image mime / 空 bytes 前置校验不变
- 兼容：`complete_json` 原 kwargs 签名不变（新增可选 `schema` 尾参），全部既有调用方（router / ai_tasks / 三个 OCR service / scheduling）零改动
- 未改：产品 REST 表、权限码、`chat_handler`、`/ai/**` 信封、其它 `core/ai` 文件
