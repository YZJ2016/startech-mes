## 1. Spec

### Capability

- Name: 入库 Hub P3 — 入库金额列（IH-G5）
- Module: `startech-mes-basic/backend/ktg-mes`（入库行加法字段）+ Flyway tenant + Vue3 **仅**入库 Hub 抽屉展示/编辑。**禁止**改 Vue2。本单元已编码。
- Priority: P3（入库切片后续；挂采购/财务对齐；**不**改 105 范围）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/14.mes-inbound-hub-iqc-gaps.md`（**IH-G5**、INV-F03）
  - 设计：`docs/03.design/14.mes-inbound-hub-iqc-plan.md`（§7）
  - 总览：`docs/02.requirements/13.mes-kuaige-capability-overview.md`（CAT-N3：不强制同开价目 CAT-M06；CAT-A01 快财务默认后置）
  - 切片总控：`docs/04.specs/104.mes-inbound-hub-iqc-program.md`
  - 出库金额不是本单元：缺口 15 **OH-G5**（禁止绑在一起）

### Business Goal

采购/财务对齐时，入库行可填单价、行金额，Hub 可见合计。金额可手工填，**不**要求先有价目主档（CAT-N3）。105 已明确不加金额列；本单元才允许加。

### Scope

In scope（**仅当编码门禁满足**）:

- tenant：入库行（及若需要则头）可空金额列；**不**建价目表
- Hub 抽屉可编辑加法字段；头/打印「合计」为**整单**行金额合计（拉全部分页行），不是当前表页切片；旧 `itemrecpt`/`productrecpt` 页不重排（UI-A）
- 旧行 POST/PUT body 加法；URL/method 不变

Out of scope:

- 在 105 范围声明里补金额列（105 基线仍无金额；本单元才加）
- 价目主档（CAT-M06）、快财务模块（CAT-A01）、出库金额（OH-G5 / 不预占出库文件）
- Hub 打印（111）、FQC（108）
- 改 Vue2、yml 开关、扩 permitAll

### Acceptance Criteria

- **编码门禁（已满足）：** 点名 110。
- 新列可空，历史行不报错；Hub 能展示/编辑；无价目表也能手工填；旧 list URL 不变
- 第 4 节未跑命令不得写绿

### Rules and Constraints

Tenant isolation:

- 加列走 tenant Flyway；SQL 带 `tenant_id`
- 只信 JWT

Security and masking:

- 不把金额接口写入 `MesPermitAllProvider`
- 日志不打印凭据

Audit and lineage:

- 只进 `db/migration`；不改历史 `backend/sql/`
- 不占用 105 已用版本号

AI/rule-engine rules:

- 不涉及

Database rules:

- 只加可空金额列；不建价目、不建第三张入库头表
- 不写 yml

## 2. Plan

### Implementation Approach

- tenant 加可空 `unit_price` / `line_amount`；Mapper 加法；Hub 抽屉列与合计；禁止把快格云金额模型拷进 SQL。不建价目表。

### Affected Modules

- `ktg-mes` 入库行实体/Mapper；Flyway tenant；`inboundhub` 抽屉
- 不改出库、不改快财务（无此模块）

### Public Contracts

- 旧入库行 API 加法字段；无新必填
- 不加价目 REST

### Persistence Changes

- 可空单价/行金额（及可选头合计）；列名实现时与现网风格对齐，本文不锁英文列名以免拍板前写死

### Transaction Boundaries

- 金额与现有行保存同一事务；无独立过账闸

### Risks

- 未开口就加列（违反 IH-G5）
- 顺手建价目表（违反 CAT-N3）
- 与出库 OH-G5 绑同一迁移

### Verification Strategy

- 列 + Mapper + Hub 抽屉；npm / mvn 实跑后写第 4 节
- 门禁后：空列兼容 + Hub 编辑；实跑命令后写第 4 节
