### Business Goal

Vue3 角色勾选 9310 后出现出库 Hub：生产领料与销售出库一张表（可按仓库筛）、抽屉看现网明细与深链；执行走旧 PUT。旧菜单与旧 URL 仍可用。无金额列、无打印、无 OQC 闸。

### Scope

In scope:

- Flyway **master**：`sys_menu` 9310 段（仓储目录下，`parent_id` 取现网领料单之父）
- `GET /mes/wm/outboundhub/list`：服务端合并 `wm_issue_header` 与 `wm_product_salse`，`TableDataInfo`，可筛 `warehouseId`，`@PreAuthorize mes:wm:outboundhub:list`
- Vue3：`outboundhub/index.vue` — 类型/仓库筛 + `el-table` + `el-drawer`；执行调现有 API；无打印按钮；无 OQC 块
- 单测：Hub UNION 两侧 `tenant_id`；无权限 403；分页 `total` 不是前端切片
- **负向：** 不改 `issue/index.vue`、`productsalse/index.vue`、入库 Hub、`rtissue`/`rtsalse` 布局；不自动 `sys_role_menu`；不扩 permitAll；不引入 Ant Design

Out of scope:

- 生产退料 / 销售退货进 Hub（**OH-G1**，默认不含）
- 借料 / 送货单 / 委外 / 其它出库 / 采购退货 / 11 种类型（**OH-G3**）
- 销售出库 OQC 闸（**OH-G2**）
- CAT-W01 / W04 / W05 / W06 / W07
- 出库金额（**OH-G5**）、Hub 打印（**OH-G4**）
- 入库 Hub / IQC 闸 / 105 已交付范围
- Demand/MRP、kiosk、改壳、改首页、改 F1、改行业包、改 Vue2
- 替换旧 list URL；前端拉多源再分页

### Rules and Constraints

Tenant isolation:

- 无 `TenantContext` 不得访问 wm 表
- Hub UNION/合并查询每侧都带租户条件；禁止先查全表再在内存滤租户作为唯一隔离

- 新路径须登录 + `@PreAuthorize`；403 不泄漏他厂是否存在该 id
- toast/API 不打印 JDBC、cipher、内部路径

Audit and lineage:

- Flyway 版本号实现时按目录现网最大号顺延（以当时目录为准；不得沿用入库 `V20260915.01` 号）
- 菜单 id 冻结 9310–9319

AI/rule-engine rules:

- 不涉及

Database rules:

- 不加第二套出库表、不加金额列
- 配置不进 yml
- 本刀默认无 tenant 新列（OUT-F04/F05 已核完：现网行表无单价、无序列号集合）

## 2. Plan

### Implementation Approach

- 先 Flyway 菜单，再 Hub list，最后 Vue3 Hub 页调附加 GET + 现有执行 API。对照入库 Hub 的服务端合并思路，禁止拷快格云 `outboundListAggregate.ts`。不改入库 Hub / IQC。

### Affected Modules

- `ktg-mes`：新增 outboundhub Controller / Service / Mapper（与 inboundhub 同包风格，不把业务搬进 `ktg-admin`）
- `ktg-system`：Flyway master 菜单脚本
- `startech-mes-front`：`src/views/mes/wm/outboundhub/`、`src/api/mes/wm/outboundhub.js`
- 不改：`frontend/`、layout 壳、dashboard、旧 issue/productsalse 页皮肤、`kuaigeyun-mes/`、入库 Hub / IQC

### Public Contracts

- 保持：见设计 15 §3.1
- 新增：见设计 15 §3.2

### Persistence Changes

- `sys_menu` 9310 段
- 无金额列；本刀默认无 tenant 加列

### Transaction Boundaries

- list 只读
- 执行仍在现网 `WmIssueHeaderController.execute` / `WmProductSalseController.execute`

### Risks

- PageHelper 对 UNION 分页行为
- 现网 `productsalse/list` 注解被注释：Hub **自己的** list 必须有注解，不在本单元大规模恢复其它注释掉的 `@PreAuthorize`
- 默默纳入 rtissue/rtsalse 或借料/送货

### Verification Strategy

- 单测租户 / 403 注解 / PageHelper COUNT rewrite；静态旧 Vue API 文件 URL 未改；命令实跑后写入第 4 节
