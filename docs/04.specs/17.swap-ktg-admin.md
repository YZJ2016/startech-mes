## 1. Spec

### Capability

- Name: 用 springboot2 内容替换 `ktg-admin`（前缀、notice list、uploadMinio、启动注解、yml 键）
- Module: `ktg-admin`
- Priority: P0
- Related requirement/design documents:
  - `docs/04.specs/11.backend-shell-swap-program.md`
  - `docs/04.specs/07.extract-ureport-bootstrap.md`（启动类保留 Async/Scheduling）
  - `docs/04.specs/09.platform-purity-gate.md` / `10.backend-extract-review.md` 第 7 节

### Business Goal

Web 入口换成若依 3.9.2 springboot2 的 `ruoyi-admin` **Java 与可合并的配置键**，仍为 `ktg-admin` / `com.ktg`。换入当时做完剩余五项：配置根键 `ktg-mes:`→`ruoyi:`；删掉若依自带的 `GET /system/notice/list`；不覆盖 mes 的 `POST /common/uploadMinio`；启动类保留 `@EnableAsync` `@EnableScheduling`；yml **只对键、不抄密钥**。admin 必须继续依赖 `ktg-mes`。

### Scope

In scope:

- 对照：`RuoYi-Vue-springboot2/ruoyi-admin/`（commit `913524b1525a0e374774afbb54c452d8f68a5a8f`）
- 覆盖 nested **Java**（`com.ktg.web`、启动类等），机械替换 `com.ruoyi` → `com.ktg`
- pom：以对照 `ruoyi-admin/pom.xml` 为依赖底稿，但必须
  - `artifactId=ktg-admin`，parent=`com.ktg:ktg`
  - **保留** `<artifactId>ktg-mes</artifactId>` 依赖（对照 admin **没有** mes 模块，漏加则 MES 全没）
  - **保留** nested 现有 `maven-antrun-plugin`（拷 `ktg-mes-ui-master/dist`）；对照 admin 无此插件，不要删。编译验证继续 `-Dmaven.antrun.skip=true`
  - `spring-boot-maven-plugin` 版本允许 2.5.15（与允许的 Boot 微升一致），不要写成 Boot 4 插件
- `RuoYiApplication`：对照源只有 `@SpringBootApplication`。换入后必须再加 nested 现有的 `@EnableAsync`、`@EnableScheduling`。包名仍 `com.ktg.RuoYiApplication`。不要加回 UReport 注解（`07`）
- `SysNoticeController`：对照有 `@GetMapping("/list")` 以及 3.9.2 的 `/listTop` `/markRead*` `/readUsers/list`。**必须删除 `/list`**，避免与 mes `SysNoticeListController` 双映射。`/listTop` `/markRead*` 不要接到 mes 已读；阶段 1 默认删掉这些若依已读 HTTP，以免缺表 500 或与 mes 平行。详情 GET/POST/PUT/DELETE 可留
- `CommonController`：对照无 `uploadMinio`。换入后 **禁止** 增加该方法；mes `MesMinioUploadController` 继续 `POST /common/uploadMinio`。本地盘 `/upload` `/uploads` `/download` 跟对照
- yml：**禁止整文件覆盖** `application.yml` / `application-druid.yml` / `application-druid-prod.yml` / `application-back.yml`
  - 把根键 `ktg-mes:` 改为 `ruoyi:`（与 `RuoYiConfig` `prefix = "ruoyi"` 对齐）
  - 按对照 `application.yml` **补键名**（没有的键才加）；**已有键的值一律保留**
  - `server.port` 保持现网 `8085`（不要改成若依示例 8080）
  - `logging.level` 包名 `com.ktg` 不是 `com.ruoyi`
  - 不粘贴、不改写 password / secret / jdbc url / minio endpoint / oauth 值；OAuth 段保持环境变量占位
- 资源：可按需合并对照的 `i18n/messages.properties`、`mybatis-config.xml`、`logback.xml`、`banner.txt`。**禁止清空或覆盖** nested 已有 `static/`、`templates/`（MES UI 打包产物）
- `RuoYiConfig` 若在 `14` 已变成 `prefix = "ruoyi"`，本块必须完成 yml 根键同步；若仍为 `ktg-mes`，本块改 common 的 prefix **或** 确认 `14` 已改——最终两者一致为 `ruoyi`

Out of scope:

- 用若依 yml 覆盖密钥、库地址、对象存储
- 改 Vue2 `frontend/` 或 `RuoYi-Vue3-front`
- Java 17 / Boot 3/4 / jakarta / 模块改名为 `ruoyi-admin`
- 把 721 个 mes 文件改路径
- 运行时启动（`18` 列为未验证）

- admin `SysNoticeController` 无 `@GetMapping("/list")`；mes 仍有 `GET /system/notice/list`
- admin `CommonController` 无 `uploadMinio`；mes 仍有 `POST /common/uploadMinio`
- 配置根键与 `RuoYiConfig` 均为 `ruoyi`；文档中无密钥值
- `rg "com\\.ruoyi" backend/ktg-admin/src` 为 0（banner 艺术字除外若不含包名）
- JDK 8 `mvn -pl ktg-admin -am compiler:compile "-DskipTests" "-Dmaven.antrun.skip=true"` 通过后再进入 `18`

## 2. Plan

### Implementation Approach

5. 删 `SysNoticeController` 的 `/list`（及默认删除若依已读附加映射）
6. 确认 `CommonController` 无 Minio 入口
7. **手工合并** yml 键：根键改名、补缺键、保留全部秘密值与 `8085`
8. 需要时合并 i18n/mybatis/logback；不动 `static/`
