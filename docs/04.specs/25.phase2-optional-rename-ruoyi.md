# Development Unit Template

Use this template before each implementation unit.

## 1. Spec

### Capability

- Name: 可选 2c：Maven 模块改名为 `ruoyi-*`、包名 `com.ktg`→`com.ruoyi`
- Module: nested `backend` 全聚合（含 `ktg-mes`）
- Priority: P2（默认 **不做**）
- Related requirement/design documents:
  - `docs/04.specs/19.backend-shell-swap-phase2-program.md`
  - AGENTS.md：改实体/包名必须检查 Web 调用方；本仓库管理端仍是 Vue2 `frontend/`

### Business Goal

仅当产品 **书面要求** 对外 GAV/包名与上游若依一致时，把 `ktg-*` / `com.ktg` 改成 `ruoyi-*` / `com.ruoyi`。这不是 2a/2b 的完成条件。默认跳过本单元，阶段 2 仍以 ktg 坐标系交付。

### Scope

In scope（**仅当**用户/产品明确下令「执行 25」之后）：

- 目录与 `<modules>`：`ktg-admin` 等 → `ruoyi-admin` 等；**`ktg-mes` 是否改名必须单独拍板**（上游无 mes 模块；建议默认仍叫 `ktg-mes` 或改 `ruoyi-mes`，禁止静默）
- 所有 `pom.xml` 的 `groupId`/`artifactId`/`parent` 与依赖坐标
- 所有 Java/XML/vm/yml logging 包名 `com.ktg` → `com.ruoyi`（含 mes）
- `frontend/` 里若有写死的 Java 包名（极少）才改；**不是** Vue3 换壳
- 启动类 `com.ktg.RuoYiApplication` → `com.ruoyi.RuoYiApplication` 时，同步文档与进程检查脚本（若有），不要改端口与密钥

Out of scope（默认整单元都是 Out of scope）：

- 与 `20`/`21` 同一 PR、同一天「顺便改名」
- 借改名升级 Boot、改五项 URL、改 Vue3
- 把 mes 业务搬进 `ruoyi-admin`
- 未下令就改 `groupId` 为 `com.ruoyi`

### Acceptance Criteria

默认：

- 本文件第 4 节写明 **跳过**；`rg "artifactId>ruoyi-" backend --glob pom.xml` 为 0；业务包仍 `com.ktg`

若执行：

- 全仓（nested）无残留 `com.ktg` 作为 Java 包（除非产品批准 mes 保留 `com.ktg.mes`——必须写在第 4 节）
- JDK 17 聚合编译 SUCCESS
- 五项路径不变；只变包名
- Vue2 管理端仍能按现有 `src/api` 调 HTTP（包名对前端不可见则前端可无 diff）

### Rules and Constraints

Tenant isolation:

- 不涉及

Security and masking:

- 不借改名扩大匿名面、不改 Token 头

Audit and lineage:

- 改名 PR 必须列出模块目录 rename 清单，避免半改导致 CI 找不到 `ktg-admin`

AI/rule-engine rules:

- 不涉及

Database rules:

- 不改表名；MyBatis namespace 随包名变

## 2. Plan

### Implementation Approach

默认：读到本文件即停止，进入 `26`。

若执行：

1. 产品确认：mes 模块目录与 `com.ktg.mes` 是否一起改
2. 先 rename 目录与根 `<modules>`，再全局替换包名（先 pom，后 Java/XML/vm）
3. 一次提交尽量可编译；不要只改一半模块
4. 编译 + 五项 `rg`（Controller 的 `@RequestMapping` 字符串不应被包名替换误伤——用语言感知替换，不要 `sed` 整个仓库含 URL）

### Affected Modules

- 潜在：backend 全部 + 可能的脚本
- 默认：无

### Public Contracts

- HTTP 契约不变；变的是 Maven 坐标与 Java 包（对外部集成可能破坏二进制兼容，必须产品确认）

### Persistence Changes

- 无表结构变更

### Transaction Boundaries

- 无

### Risks

- 与 2a 混做导致无法回滚
- 半改名：磁盘目录还是 `ktg-admin`，pom 已是 `ruoyi-admin`
- 误替换 URL 中的 `ktg` 文本或配置根键
- Vue2 / 权限字符串不受影响却被大面积改前端

### Verification Strategy

默认：确认无 rename diff。

若执行：JDK 17 `mvn -pl <admin-artifact> -am compiler:compile` + 包名 rg。
