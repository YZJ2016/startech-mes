## 1. Spec

### Capability

- Name: 阶段 2a 工具链与平台命名空间（JDK 17、javax→jakarta 约定、父 POM）
- Module: `startech-mes-basic/backend/pom.xml`（及编译插件）；不覆盖六模块 src，不一次改完 mes 第三方
- Priority: P0
- Related requirement/design documents:
  - `docs/04.specs/19.backend-shell-swap-phase2-program.md`
  - 对照：`RuoYi-Vue-springboot3/pom.xml` @ `9e3fb55f46d9998c6cecefd04fcf55c5d17158af`

### Business Goal

先把聚合工程的 **编译器与 BOM** 切到若依 springboot3 的 Java 17 / Boot 3.5.16 / jakarta 平台坐标，让后续 `21` 换入的平台源码有合法依赖。本单元 **只动父 POM（及确属平台 BOM 的 dependencyManagement）**，不把 `ktg-mes` 的 UReport/Minio/Jasper/EasyExcel 一次升完。

### Scope

In scope:

- 前提：`18` 阶段 1 门禁已收口；对照 worktree HEAD = `9e3fb55f46d9998c6cecefd04fcf55c5d17158af`
- 根 `backend/pom.xml` 按对照 `pom.xml` **属性与平台依赖**对齐，但坐标系留在 `com.ktg` / `ktg` / `${ktg.version}`（当前 parent `3.8.2`）
- 必须写入（值以对照 pom 为准，已实测）：
  - `java.version` = `17`
  - `spring-boot.version` = `3.5.16`（`spring-boot-dependencies` import 用该属性，不要写死 4.1.0）
  - `mybatis-spring-boot.version` = `3.0.5`
  - `springdoc.version` = `2.9.0`；dependencyManagement 增加 `org.springdoc:springdoc-openapi-starter-webmvc-ui`
  - `druid` 平台 starter 改为 `druid-spring-boot-3-starter`（版本跟对照 `1.2.28`，不要抄现网口令）
  - 对照已有的 `yauaa`、`fastjson.version`（2.x）、`poi.version`、`oshi.version`、`pagehelper.boot.version=2.1.1`、`kaptcha`、`velocity`、`jwt`、`jaxb-api` 等 **平台** 属性
  - `maven-compiler-plugin`：`source`/`target` = `${java.version}`（对照为插件 3.13.0，允许对齐）
- 平台侧 jakarta 约定（本单元写进 pom / 说明，源码替换在 `21`）：
  - `javax.servlet.*` → `jakarta.servlet.*`
  - `javax.annotation.Resource` / `PreDestroy` → `jakarta.annotation.*`
  - `javax.servlet-api` 依赖删除或改为 jakarta servlet API（由 `spring-boot-starter-web` 传递即可，不要两套并存）
  - 删除父 POM / admin 的 `io.springfox:springfox-boot-starter`（springfox 不支持 Boot 3）；文档组件改 SpringDoc
- 保留 `<module>ktg-mes</module>`、`groupId` `com.ktg`、`artifactId` `ktg`
- 实施机确认 `JAVA_HOME` 为 JDK 17

Out of scope:

- 覆盖任一 `ktg-*/src`（那是 `21`）
- 一次改完 mes：`ureport2-console`、`minio`、`jasperreports`、`easyexcel`、`hutool`、`barcode4j`、阿里 OSS（那是 `22`，且未知则先编再记）
- Boot 4.1、`druid-spring-boot-4-starter`、`tools.jackson`、`spring-boot-starter-webmvc`（那是 `24`）
- 模块改名为 `ruoyi-*`、包名 `com.ruoyi`（`25`）
- 前端 Vue3
- 把 mes 仍使用的 **fastjson 1.x** 从仓库删掉：若 mes 仍 `import com.alibaba.fastjson`，父 POM 或 `ktg-mes/pom.xml` **继续能解析 fastjson1**，不要逼 721 文件本单元改 import

### Acceptance Criteria

- `rg "springfox" backend --glob pom.xml` 在平台模块与父 POM 为 0（mes 若仍暂时引用 swagger-models 1.x，记入 `22`，本单元不假装已迁完）
- `rg "druid-spring-boot-starter" backend --glob pom.xml` 平台侧已改为 `-3-starter`（不要留 Boot 2 的 `druid-spring-boot-starter` 给 framework）

- 第 4 节记录 `java -version` 为 17

## 2. Plan

### Implementation Approach

1. 确认 nested toplevel 是 `startech-mes-basic`；`18` 已收口；对照 `RuoYi-Vue-springboot3` HEAD 锁定
2. `git status`：不要盖用户未提交 pom
3. 以对照根 `pom.xml` 的 `<properties>` / `<dependencyManagement>` / `<build>` 为底稿，**逐项合并**进 nested 根 POM：
   - 保留 nested 的 `ktg.version`、`modules`（含 `ktg-mes`）、url/description 不必改成若依官网
   - 删除或停止管理 `swagger.version` + `springfox-boot-starter`（平台）
   - Boot 依赖 import 改为 `${spring-boot.version}` = 3.5.16
4. `ktg-admin/pom.xml`：本单元 **可以** 把 `springfox-boot-starter` 换成 `springdoc-openapi-starter-webmvc-ui`（否则父 POM 删 springfox 后 admin 立刻缺坐标）。**不要**覆盖 admin Java（SwaggerConfig 源码在 `21`）
5. 不要改 `ktg-mes/pom.xml` 的 ureport/minio/jasper，除非父 POM 一改 mes 的 BOM 解析立即失败且只需补一行 **已有** 坐标——超出则留给 `22`
6. 用 JDK 17 试编 `ktg-common`（此时 src 可能仍 javax）：把输出摘要写入第 4 节。失败是预期则写明「待 `21`」

平台 jakarta 替换规则（给 `21`/`22` 执行，本单元不批量改 Java）：

| 旧 | 新 | 谁改 |
| -- | -- | ---- |
| `javax.servlet.*` | `jakarta.servlet.*` | 平台 `21`；mes `22` |
| `javax.annotation.Resource` / `PreDestroy` | `jakarta.annotation.*` | 同上 |
| `javax.websocket.*` | `jakarta.websocket.*` | `22`（仅 mes） |
| `javax.sql.DataSource` | **保持**（JDK） | 不改 |
| `javax.xml.bind` | 对照仍用 `javax.xml.bind:jaxb-api` | 跟对照，不要擅自改 jakarta.xml.bind |

### Affected Modules

- 必改：`backend/pom.xml`
- 允许：`ktg-admin/pom.xml` 文档坐标（springfox→springdoc）
- 原则上不改：各模块 `src/`、`ktg-mes/pom.xml` 第三方版本

### Public Contracts

- Maven GAV 对外仍 `com.ktg:ktg:3.8.2`（版本号不跟若依 3.9.2）

### Persistence Changes

### Risks

- 本机仍用 JDK 8 编，错误信息被当成「jakarta 没换完」
