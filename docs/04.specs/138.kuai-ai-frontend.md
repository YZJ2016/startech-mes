## 1. Spec

### Capability

- Name: S5 — 前端五页 + 档案下拉 + 模型选择 + 工具轨迹历史 + 会话恢复 + F1
- Module: **业务**落 `kuaigeyun-mes/riveredge-frontend` 的 `src/apps/kuaiai` + KR-G0 例外：已登录布局只加 F1 挂钩，不改其它业务页。复用件（抽屉/`AiContext`/`deepseekChat`/ai-draft）契约零改。**禁止**改 `startech-mes-basic/`。
- Priority: P1（KR-X5；依赖后端 S1–S4 产品 REST 可用）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/16.kuai-ai-rebuild-gaps.md`（KR-F1–F6、KR-G5、KR-X5）
  - 设计：`docs/03.design/16.kuai-ai-rebuild-plan.md`（§12、§15 S5）
  - 后端契约：`134`–`137`（权限码与路径必须同文）；页上下文摘要规则归属 `135`

### Business Goal

管理端交付五页（chat/agents/knowledge/models/mcp）：全宽对话可选档案或无档案时选 chat 模型、历史渲染工具轨迹、会话恢复规则；全局 F1 开同一助手抽屉（KR-F4），全宽页不传页上下文摘要。

### Scope

In scope:

- `src/apps/kuaiai/pages/{chat,agents,knowledge,models,mcp}` + manifest/entry
- API client 对齐契约表路径；options 不下发 Key/cipher/base 口令
- **chat：** 会话列表 + 档案下拉（`agents/options`）+ 无档案可选 `llm-models/options`（chat）；有档案用档案 `default_model_id`，不再另传模型覆盖；**历史渲染** `role=tool` 与 `assistant.tool_calls` 的**名称、参数摘要、结果文本**（不只存/展示原始 JSON 就算完成）；抽屉发送传 `AiContext`（screen/resource_key/record_id 等），全宽不传页上下文；摘要拼装属后端 `135`
- **agents：** Tool 五值勾选（默认不勾写）/MCP/知识库 + ROLE|USER 授权 + 模型下拉
- **knowledge：** 库/文档/切块 + embed 下拉 + 切块参数 + 解析失败文案 + 重解析
- **models：** 厂商/模型多行增删改；厂商**不是**死名单；`model_name` **自由填写**；`model_type` 为 `chat`\|`embed`\|`vision`；内置名只是可选模板
- **mcp：** 白名单表格（连接打码）
- **F1：** 已登录布局全局 keydown；无 `entry:read` 不拦截；输入框内仍拦截；窄屏可隐藏按钮但有权限时 F1 仍可用；抽屉链到全宽 chat；冲突则改键并回写 KR-G5
- **工作台：** 若已有「打开助手并预填、不自动发送」则保持，不改成路由跳转（KR-F4）
- **会话恢复（KR-F5）：** 旧会话 `agent_id` 无使用权或停用 → 选择器清空且不带入 send；不删历史
- lockfile 遵循本仓惯例；不引新 UI 库

Out of scope:

- 改抽屉实时工具轨迹（可只历史可见）；改 `deepseekChat` 线格式
- 后端页上下文摘要规则（属 `135`）；确认闸 UI、工作流页、审计查询页、FAQ/training 产品页
- 后端新接口；改 `/ai/**` 或 `code/msg/data`
- HyDE/OCR 扫描件/外部向量相关 UI
- 改已登录布局以外的其它业务页（KR-G0）

### Acceptance Criteria

1. 五页可按权限进入；无对应管理位隐藏写操作。
2. 全宽 chat：无档案可选 chat 模型；有档案不覆盖模型；历史可见工具**名称、参数摘要、结果文本**。
3. 模型页：`model_name` 自由填；`model_type` 为 chat|embed|vision；厂商非死名单；内置名仅模板。
4. 会话恢复：失效档案不带入 send、不删消息。
5. F1 行为符合 KR-F4；抽屉传 context、全宽不传；摘要只服务端（`135`）；工作台「打开助手并预填、不自动发送」若已有则保持。
6. options/表单不展示明文 Key/MCP token；不引新 UI 库。

### Rules and Constraints

Tenant isolation:

- 前端不传 `tenantId`；依赖服务端隔离。

Security and masking:

- toast/控制台不打印密文；SSE 仍走现网 OpenAI chunk 消费者。

Audit and lineage:

- 无前端审计页（本期不做）。

AI/rule-engine rules:

- 发送仍 `act:execute` → `POST /api/v1/core/ai/chat/completions`。
- 抽屉传 context 字段；全宽不传页上下文；不拼客户端 label 进 prompt（摘要在后端）。

Database rules:

- 无前端直连库。
