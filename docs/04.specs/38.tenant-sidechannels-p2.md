## 1. Spec

### Capability

- Name: P2 租户旁路隔离（缓存 / 文件 / 异步 / Quartz 钩子 / WebSocket）
- Module: `startech-mes-basic/backend` 的 `ktg-common`、`ktg-framework`、`ktg-system`、`ktg-admin`、`ktg-mes`、`ktg-quartz`
- Priority: P2（依赖 P1 的 `LoginUser.tenantId`）
- Related requirement/design documents:
  - 设计：`docs/03.design/04.mes-shared-db-tenant-plan.md`（§7 缓存/文件/异步/Quartz/WebSocket，§8 菜单边界）
  - 缺口清单：`docs/02.requirements/02.mes-multi-tenant-gaps.md`（R1–R6、I2、I3、I9、D6）
  - 总控：`docs/04.specs/35.mes-multi-tenant-program.md`
  - 上一单元：`docs/04.specs/37.tenant-identity-p1.md`
  - 下一单元：`docs/04.specs/39.tenant-catalog-p3.md`

### Business Goal

堵住登录之后仍会串租户的旁路：共享 Redis 上的租户键、在线会话与强退、zip 任务状态、本地盘/对象存储路径、线程池与异步登录日志、站内信 WebSocket。空租户上下文不得写租户键、不得上传。本单元不启用第二家工厂。

### Scope

In scope:

- 新增 `TenantCacheKeys`，改各调用点组装键；**不**改 `RedisCache` 的 get/set 签名与自动前缀行为（R1）
- 作用域键：`pwd_err_cnt`、`sys_config` overlay、`repeat_submit`、`rate_limit`、`upload_task_status`、在线列表过滤
- `login_tokens` **保持** `login_tokens:{uuid}`，值内含 `tenantId`；停用租户 SCAN 按值删除（R6/D6）；不加二级 SET
- 验证码、字典缓存保持全局（手写 `CacheConstants`）
- `/monitor/online` 与 `forceLogout` / `refreshPermissionByRoleId`（R4/R5，含 runAs）
- `TenantTaskDecorator` 拷贝 `TenantContext` + MDC + `SecurityContext`，`finally` clear；**禁止** `InheritableThreadLocal`（I3）
- `ThreadPoolConfig.threadPoolTaskExecutor`、`AsyncManager` / `AsyncFactory`、Spring `@Async` 执行器同一套装饰
- 登录失败日志：能解析到租户则写该 `tenant_id`，否则 `0`（I3）
- 上传对象键/相对路径含 `tenant/{id}/`；空上下文拒绝上传；下载键不匹配 **403**（I2）
- `ZipFileUtil` 状态键 `upload_task_status:{tenantId}`；空上下文禁止；同厂一个并发 zip（R3）
- `AbstractQuartzJob` **仅**上下文钩子；`sys_job.tenant_id` 列放到 P8（45）
- `WebSocketServer` / `WebSocketUsers` / `MessageProvider` 按 `{tenantId}:{userId}` 隔离（I9）；路径仍为 `/websocket/message/{token}`

Out of scope:

- 改 Vue2 `startech-mes-basic/frontend/`（F1）
- 每租户独立 Redis；改 `login_tokens` key 前缀；二级 SET 索引（R6）
- 引入 Jugg / Sa-Token / MyBatis-Plus / fail-open
- MQ / Feign / OpenAPI 验签 / BPM（v1 非目标）
- `sys_message.tenant_id`（随 S5，落 45）；不替代本单元会话 key 改造
- `sys_job` / `sys_job_log` 加列与 JobKey 后缀（45 / S2）
- I8 忽略名单 Mapper 绑主库（41）；I5 专池；I1 UReport Filter（45）；S1 缺 CREATE 表
- 启用第二个 `ROW` 工厂（门禁在 40 / P4）
- 菜单克隆、许可裁剪（39）；P9 Vue3 登录页

### Acceptance Criteria

- 空 `tenantId` 写租户缓存键 → 单测抛异常（`TenantCacheKeys` 组装；`RedisCache` get/set 不加自动前缀）
- `pwd_err_cnt` 键为 `pwd_err_cnt:{tenantId}:{username}`；两租户同名用户互不锁号
- 已登录时 `repeat_submit` / `rate_limit` 键含 `tenantId`；登录前限流仍仅 IP（R2）
- zip 状态键为 `upload_task_status:{tenantId}`；空上下文禁止写；同厂已有「处理中」则拒绝第二并发
- `GET /monitor/online`：工厂只看本 `LoginUser.tenantId`；工厂看不见他厂；平台未 runAs 可列全部（R4/F9）。`forceLogout` / `refreshPermissionByRoleId` 按 R5（含 runAs）
- D6：SCAN `login_tokens:*`，按值中 `LoginUser.tenantId` 删除；不改 key 前缀、不加二级 SET
- 异步线程内 `TenantContext.get()` 等于提交方；任务结束后 ThreadLocal 为空（防池化泄漏）。两租户交错提交不串
- 上传路径或对象键含 `tenant/{id}/`；无上下文上传失败；下载键不匹配当前租户 → **HTTP 403**
- WebSocket：会话 key 为 `{tenantId}:{userId}`；两租户同名用户互收不到对方推送；无 `tenantId` 的 token 拒绝建连；不存在 `USERS.get(username)` 推送路径；禁止跨租户广播（I9）
- 登录失败写 `sys_logininfor.tenant_id`：解析到租户用该 id，否则 `0`；空上下文不得写租户 Redis 键
- 代码中无 `InheritableThreadLocal` 用于租户传播
- 本单元不启用第二家工厂；不把 S1/I1/I5/I8 标成已实现

### Rules and Constraints

Tenant isolation:

- 共享 **一个** Redis 实例；租户键由 `TenantCacheKeys` 组装，不按隔离级别分前缀
- 空 `tenantId` 写租户键 → **抛异常**，禁止 `pwd_err_cnt::admin`、`sys_config::key`、`upload_task_status:` 空段
- 验证码 `captcha_codes:`、字典 `sys_dict:` **全局**
- `login_tokens:{uuid}` 形态不变；权威租户在 `LoginUser.tenantId` 值内
- SQL **永不跳过 `tenant_id`**（含现网 `user_id=1`）；本单元不改拦截器 include 名单
- runAs 到工厂 X 时，在线强退/刷权限视为工厂 X（R5）；未 runAs 的平台账号可列全部在线（R4）
- WebSocket 会话不得用裸 `username`；推送必须带当前租户

Security and masking:

- 不引入第二套认证；继续 Spring Security + JWT + Redis `LoginUser`
- 下载不得靠可猜测 URL 读他厂文件；键前缀与当前租户不符 → 403，不得 200 空体冒充成功
- `MesPermitAllProviderImpl` 现网匿名放行 `/files/**`、`/upload/**`、`/uploadFiles/**` 与 `SecurityConfig` 的 `/profile/**` GET permitAll：**不得**继续匿名读 `tenant/` 前缀文件
- WebSocket 路径保持 `/websocket/message/{token}`，仍可靠路径 token 鉴权；无 `tenantId` 拒绝建连
- 日志、异常不得打印 token、口令、JDBC、内部绝对路径、对象存储凭据
- 禁止 API 回传 JDBC 口令；本单元不新增租户管理揭明文接口

Audit and lineage:

- 停用租户立即 SCAN 作废该租户全部 `login_tokens`（D6）；下一请求 401
- 登录失败/成功日志写入 `sys_logininfor.tenant_id`（列由 37 加）；失败且未解析到租户则 `0`
- 历史 SQL 不改；本单元原则上无表变更
- 不把明文 token 写入审计正文

AI/rule-engine rules:

- 本单元不涉及规则引擎或 AI

Database rules:

- 增量脚本只放 `startech-mes-basic/backend/sql/`，命名 `YYYYMMDD_NN_<topic>.sql`，接当日已有最大序号追加；禁止改 `ry_*.sql` / `mes-*.sql` / `quartz.sql`
- 本单元 **默认无 DDL**。若 36/37 尚未给 `sys_config` 加上可空 `tenant_id`，先补那一列再接线缓存，不在本单元重开 D1
- 不改 `QRTZ_*`；不加 `sys_job.tenant_id`（45）
- 不加 `sys_message.tenant_id`（45 / S5）
- 禁止一次 ALTER 全部 MES 表；本单元不扩大拦截器 include

## 2. Plan

### Implementation Approach

1. 在 `ktg-common` 新增 `com.ktg.common.tenant.TenantCacheKeys`：所有租户 Redis 键只经此组装；`requireTenantId` 空则抛 `ServiceException`（或现有运行时异常类型，与 P0 `TenantContext.getRequired()` 风格一致）。`RedisCache` **只调用、不改 get/set**。
2. 改调用点：`SysPasswordService`、`SysConfigServiceImpl`、`SameUrlDataInterceptor`、`RateLimiterAspect`、`ZipFileUtil`。全局键继续 `CacheConstants`。
3. 在 `TokenService` 增加「按 `LoginUser.tenantId` SCAN 删除」；停用租户走此方法。`getTokenKey` 仍为 `login_tokens:` + uuid。
4. `SysUserOnlineController` 列表按当前租户过滤；平台未 runAs 不过滤。`forceLogout` 先读目标会话再比租户。`refreshPermissionByRoleId` 只刷新当前租户（含 runAs 目标）持有该角色的用户。
5. `TenantTaskDecorator` + `threadPoolTaskExecutor.setTaskDecorator`；`AsyncConfigurer` 让 `@Async` 走同一执行器。`AsyncManager.execute` 在提交时捕获三件套，任务 `finally` clear。禁止 `InheritableThreadLocal`。
6. `AsyncFactory.recordLogininfor` 增加捕获的 `tenantId` 参数（或从提交时上下文读取）；`SysLoginService` / `MobileLoginService` 失败路径传入已解析租户，否则 `0`。
7. `FileUploadUtils.extractFilename` / `MesFileUploadUtils` 对象键前缀 `tenant/{id}/`；空上下文拒绝。`CommonController` 与 OSS/zip 下载做前缀校验，不匹配 403。收紧匿名静态资源。
8. `WebSocketUsers` 改为 `{tenantId}:{userId}`；`onOpen` 无 tenantId 关连；删除 `sendMesssageToUserByName(username)` 作为对外推送入口；群发只限同租户。
9. `AbstractQuartzJob.before/after` 设/清 `TenantContext`（Java 预留 `SysJob.tenantId` 即可）；无 id 则不得写租户 Redis、不得碰租户表。列 DDL 留给 45。

### Public Contracts

APIs, facades, DTOs, events, or database contracts:

- 保持：`POST /login`、`GET /getInfo`、`GET /getRouters`、`Authorization: Bearer`、`code/msg/data`；登录成功仍 `token` 字段
- 保持：`GET /monitor/online/list`、`DELETE /monitor/online/{tokenId}` 路径与权限字 `monitor:online:list` / `monitor:online:forceLogout`
- 保持：`POST /common/upload`、`POST /common/uploads`、`POST /common/uploadMinio`、`GET /common/download`、`GET /common/download/resource`
- 保持：WebSocket ` /websocket/message/{token}`，不改握手 URL
- 变更（行为，非 URL）：在线列表工厂不可见他厂；强退跨租户 403；上传相对路径/对象键含 `tenant/{id}/`；下载跨租户 403
- 不新增登录后仍生效的客户端租户 Header
- Redis 键契约见设计 §7.1：`login_tokens:{uuid}`、`captcha_codes:`、`sys_dict:` 全局；其余租户键见 `TenantCacheKeys`

### Persistence Changes

Tables, indexes, migrations, mapper XML, and lifecycle rules:

- 本单元无必须 DDL。`sys_config` overlay 列、`sys_logininfor.tenant_id`、`LoginUser.tenantId` 依赖 36/37
- 不改 `SysMenuMapper.xml` / 字典 Mapper（39）
- 不改 `QRTZ_*`、不加 `sys_job` 列
- 若必须补 `sys_config.tenant_id`：新文件 `startech-mes-basic/backend/sql/YYYYMMDD_NN_sys_config_tenant_overlay.sql`，可空列、禁止写真实主机

### Transaction Boundaries

- Redis 键读写不进业务 DB 事务
- D6 SCAN 删除会话：尽力删除匹配 token，不与租户表更新强绑同一事务（停用登记仍在 36/37 的租户更新事务内，作废 token 紧随其后）
- `AsyncFactory` 插登录日志：沿用现有 `insertLogininfor`；登录失败写**主库**，P-D 前不得误路由专池
- 上传：先校验 `TenantContext`，再写盘/对象存储；失败不留下无前缀对象
- WebSocket `MessageProvider.sendMessage`：先校验收件人属于当前租户，再推送再插 `sys_message`（表列未加也不按用户名跨租查找会话）

### Risks

- `RedisCache.keys()` 现为 KEYS：D6 必须改用 SCAN，避免阻塞；仍不得改 get/set 自动加前缀
- `@EnableAsync` 未指定执行器时走 `SimpleAsyncTaskExecutor`，装饰器不会生效 → zip/`@Async` 串租户
- `scheduledExecutorService` 无 TaskDecorator → 必须在 `AsyncManager` 包装任务
- `/profile/**`、`/files/**` 匿名映射是文件越权口
- `WebSocketUsers.sendMesssageToUserByName` 与 `sendMessageToUsersByText` 是跨租广播口
- `SysMenuServiceImpl.selectMenuTreeByUserId` 对 `isAdmin` 返回全菜单与本单元无关，但 `isAdmin` **不得**用于跳过在线列表租户过滤
- Quartz 钩子若在无 tenantId 时仍跑租户 SQL，会在 P8 前打穿；本单元必须失败关闭该路径
- 空 `tenantId` 写成空段键会让两厂互锁密码（pwd_err_cnt）

### Verification Strategy

- 单测（优先 `ktg-common` / `ktg-framework` / `ktg-mes`，无测则本单元新建，不引入新测试框架）：
  - `TenantCacheKeys`：`tenantId==null` 写 `pwdErrCnt` / `uploadTaskStatus` / overlay → 异常
  - `TenantTaskDecorator`：提交租户 A，工作线程读到 A，结束后 ThreadLocal 空；A/B 交错不串
  - D6：两个 `login_tokens:{uuid}` 值内不同 tenantId，作废 A 只删 A
  - WebSocket：同名不同 tenantId 的 put/get 互不可见；无 tenantId 建连失败
- 编译：`mvn -pl ktg-common,ktg-framework,ktg-system,ktg-admin,ktg-mes,ktg-quartz -am test`（有测跑测；无测至少编译）
- 静态：`rg InheritableThreadLocal` 租户传播为零；`rg "USERS.get\\(username" ` 或 `sendMesssageToUserByName` 不得再按裸名推送
- 不改 Vue2，不跑 `frontend/`
- 未实际跑通不得写「测试通过」；第 4 节实现前保持「未执行」
