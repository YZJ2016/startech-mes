# KU-AI 场景 Tool：设备台账、故障与保养到期

从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：待实施。

## 1. Spec

### Capability

- Name: 新增只读 Tool `query_equipment`、`query_equipment_faults`、`query_maintenance_plans`、`query_maintenance_reminders`、`query_calibration_alerts`。
- Module: `riveredge-backend/src/apps/kuaiai/services`（tools 适配层）、manifest `ai_tools`。
- Priority: P2（S17 设备故障诊断的 MES 部分、S19 保养/点检/校准到期）。
- Related requirement/design documents: 需求 25 SC-D1、SC-D5、SC-D7；设计 26 §4、§5.2；前置 spec 189、190。

### Business Goal

设备工程师问“3 号注塑机最近有哪些故障、修了几次”“本周哪些设备该保养、哪些量具校准到期”，助手基于设备台账、故障维修与保养/校准提醒的真实记录回答。

### Scope

In scope（权限码各不相同，SC-D7）：

| Tool | 底层 service（已读方法名） | 权限码 |
| --- | --- | --- |
| `query_equipment` | `EquipmentService.list_equipment` / `get_equipment_by_code` | `kuaizhizao:equipment-management-equipment:read` |
| `query_equipment_faults` | `EquipmentFaultService.list_equipment_faults` / `list_equipment_repairs` | `kuaizhizao:equipment-fault:read` |
| `query_maintenance_plans` | `MaintenancePlanService.list_maintenance_plans` / `list_maintenance_executions` | `kuaizhizao:maintenance-plan:read` |
| `query_maintenance_reminders` | `MaintenanceReminderService.list_reminders` | `kuaizhizao:maintenance-reminder:read` |
| `query_calibration_alerts` | `EquipmentService.list_calibration_alerts` | `kuaizhizao:equipment-calibration:read`（T1 核对该方法对应页面权限；量具校准提醒 `measuring-instrument-calibration-reminder:read` 若为另一数据源则另立） |

- `query_equipment_faults` 支持 `view=faults|repairs`（同一权限码），`equipment_id?`、`status?`、`date_start?`、`date_end?`、`limit≤20`。
- 数据范围：各 service 不接收 `current_user` 的，适配层补行级范围；资源键 T1 定。

Out of scope:

- 报修、派工、完成维修、执行保养（写操作）。
- OEE、MTTR/MTBF（spec 211）；IoT 告警与趋势（spec 212）；模具/工装（spec 217）。

### Acceptance Criteria

1. 各 Tool 输出编码、名称、状态、时间等摘要字段；`query_equipment_faults` 两视图分别输出故障与维修记录。
2. 行级范围收敛；非法参数固定错误文案；空结果、异常口径一致。
3. 五个 Tool 登记于 manifest（`label`、`kind=read`）。

### Rules and Constraints

Tenant isolation:

- 传 `ctx.tenant_id`。

Security and masking:

- 不输出维修人员联系方式与费用金额。

Audit and lineage:

- 沿用 Tool 级审计。

AI/rule-engine rules:

- 到期、故障状态来自业务记录（SC-D5）；故障原因推测须标注为推测并引用历史记录。

Database rules:

- 无表结构变更。

### 场景模板（Y3=a）

本单元交付时同步登记场景模板 `equipment-ops`（设备运维助手）：预置档案 `enabled_tools` 为本单元 Tool 集合，停用 + 空授权（Y4=a）；模板 key 即能力矩阵场景卡，默认绑定同 key 预置实例（spec 191，Y1/Y2=a）。system_prompt 只引用本单元 Tool，插画按 spec 201 T2 约定。
