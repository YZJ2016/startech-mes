## 1. Spec

### Capability

- Name: P3 共享菜单 / 字典 + 模块许可裁剪路由
- Module: `startech-mes-basic/backend` 的 `ktg-system`（`SysMenuService`、许可 Service）、`ktg-admin`（`SysLoginController.getRouters`、字典接口）、许可表（P0 已建则本阶段只补字典与校验）
- Priority: P3（可与 38 并行；依赖 37 的 `LoginUser.tenantId`）
- Related requirement/design documents:
  - 设计：`docs/03.design/04.mes-shared-db-tenant-plan.md`（§4.1 全局表、§8 / §8.1 菜单与许可、P3 退出标准）
  - 缺口清单：`docs/02.requirements/02.mes-multi-tenant-gaps.md`（F2、F3、I8 边界）
  - 总控：`docs/04.specs/35.mes-multi-tenant-program.md`
  - 上一单元：`docs/04.specs/38.tenant-sidechannels-p2.md`
  - 下一单元：`docs/04.specs/40.tenant-md-p4.md`
  - 行业包许可码将追加 `mes_module`（不重开本单元、不按租户克隆菜单）：`docs/02.requirements/09.mes-industry-pack-gaps.md`；编码 `docs/04.specs/87.industry-pack-shell-p0.md`

### Business Goal

菜单与字典继续一份全局表，不按租户克隆。工厂能看见的模块由 `sys_tenant_license` 裁剪 `GET /getRouters`（及对应权限字）。平台租户管理模块永不许可给工厂。关闭某厂某模块许可后，该厂路由不再出现该模块。

### Scope

In scope:

- `SysMenuServiceImpl.selectMenuTreeByUserId` / `buildMenus` 链路与 `SysLoginController.getRouters`：按当前租户有效许可过滤
- `SysPermissionService.getMenuPermission`：权限字与路由同一套许可裁剪，避免「菜单没了接口还在」
- 许可 Service：校验 `module_code` 属于全局字典 `mes_module`；过期无效；**拒绝**把平台模块许可给工厂（F3）
- 全局字典 `mes_module` 增量 SQL + 许可写入校验
- 工厂 `userId==1`（`isAdmin`）也必须走许可过滤，不得 `selectMenuTreeAll` 漏出未许可模块
- 平台租户（`tenant_id=0`）可见平台模块；工厂会话即使角色误绑也剥离 `platform` 模块
- 静态保证：不存在「按租户循环 INSERT `sys_menu`」的代码路径
- 字典接口与 `SysDictTypeMapper.xml` / `SysDictDataMapper.xml` **不加** `tenant_id` 谓词（忽略表）

Out of scope:

- 按租户复制 `sys_menu` 行；按端（PC/平板）克隆菜单
- 改 Vue2 `startech-mes-basic/frontend/`；P9 登录页 F5/F6、精确 Vue 路由挂载（46 可定稿 `/platform/tenant` 页面，本单元只保证服务端裁剪）
- I8：`DATABASE` 租户读菜单/字典绑主库（41）。本单元禁止把菜单拷进专库，但不实现 DS 路由
- 启用第二个 `ROW` 工厂（40 / P4 门禁）
- S1 / I1 / I5 实现
- 定时任务菜单对工厂隐藏的角色模板细化可在 45/S2 收口；本单元须保证 `monitor:job:*` 不得经许可发给工厂作为「工厂自助调度」（S2：一期仅平台）
- 平板工程、runAs UI（46/F9）

### Acceptance Criteria

- 租户 1 关闭某模块许可（夹具，例如 `md`）后，该租户会话 `GET /getRouters` **不再出现**该模块（对照现网顶级 path `mes/md`）；不克隆菜单行
- 字典 API（`/system/dict/type`、`/system/dict/data` 及 Mapper XML）无 `tenant_id` 谓词
- 仓库内无「按 tenant 循环 INSERT `sys_menu`」代码；`SysMenuServiceImpl.insertMenu` 仍只插全局一行，不得包一层按租户复制
- 平台模块（`module_code=platform`，菜单 path 前缀 `platform`）**永不**写入工厂租户的 `sys_tenant_license`；工厂 `getRouters` 永不出现该模块（F3）
- `sys_menu` / `sys_dict_type` / `sys_dict_data` 保持全局；文档写明 `DATABASE` 租户仍读主库（I8 在 41 实现，本单元不克隆）
- `isAdmin()` / `userId==1` 不得跳过许可过滤
- 许可 `module_code` 必须落在 `mes_module` 字典；未知码拒绝保存
- 过期许可视为未许可
- 本单元不把 S1/I1/I5/I8 标成已实现；不启用第二家工厂
- 工厂 `getInfo` 仍不回许可清单、不回 `isolationLevel`（F2）；显隐只靠 `getRouters`

### Rules and Constraints

Tenant isolation:

- 菜单/字典是**忽略表**：拦截器不加 `tenant_id`；内容共享
- 工厂可见范围 = 角色菜单 ∩ 有效许可；平台模块不在工厂许可域
- 平台租户 `tenant_id=0` 强制 `ROW`，不靠工厂许可看运营菜单
- SQL 永不跳过 `tenant_id`（本单元不改租户业务表）
- 登录后租户只信 JWT/`LoginUser`，忽略客户端租户头
- 不按隔离级别复制菜单

Security and masking:

- 不引入第二套认证
- 许可 API 仅平台账号；工厂调许可写接口 403（精确 path 可与 36/46 对齐，建议挂在 `/platform/tenant/...`，本单元若仅 Service 则 Controller 仍须 `@PreAuthorize` + 平台校验）
- 禁止 API 回传 JDBC 口令、许可接口不返回 cipher
- 日志不打印 token/口令
- 菜单管理（`/system/menu`）改的是**全局**菜单，工厂管理员不应获得 `system:menu:add` 去给自己加平台模块；许可裁剪是第二道闸

Audit and lineage:

- 许可变更写操作日志（现有 `@Log` 即可）；不把菜单按租户备份
- 历史 `sys_menu.sql` / `ry_*.sql` 不原地改写；只追加增量
- 全局可插入**一行**平台目录（path=`platform`），这不是按租户克隆

AI/rule-engine rules:

- 本单元不涉及规则引擎或 AI

Database rules:

- 增量只放 `startech-mes-basic/backend/sql/YYYYMMDD_NN_<topic>.sql`，接现有最大序号
- 许可表若 36 已 `CREATE sys_tenant_license`，本阶段 **禁止**再建一张许可表；只追加 `mes_module` 字典及必要种子许可
- `sys_dict_type.dict_type` 保持全局唯一；字典行无 `tenant_id`
- 不改 `sys_menu` 表结构去加租户列
- 建议脚本名：`YYYYMMDD_NN_mes_module_dict.sql`
- 禁止一次 ALTER 全部 MES 表

## 2. Plan

### Implementation Approach

1. 锁定模块码与现网顶级菜单 path 映射（不改历史 INSERT，运行时按 path/祖先映射）：
   - `md` ← `mes/md`（菜单 2000 主数据）
   - `wm` ← `mes/wm`（2042 仓储）
   - `dv` ← `mes/dv`（2059 设备）
   - `pro` ← `mes/pro`（2072 生产）
   - `tm` ← `tm`（2095 工装）
   - `qc` ← `mes/qc`（2124 质量）
   - `cal` ← `cal`（2160 排班）
   - `system` ← `system`（系统管理，工厂身份管理；仍受许可，默认给租户 1）
   - `monitor` ← `monitor`（在线用户等；**不含**工厂自助 `job`：S2 一期定时任务仅平台，工厂许可不得授予 `monitor:job:*`）
   - `tool` ← `tool`（代码生成等，默认不许可给工厂）
   - `platform` ← path 前缀 `platform`（租户 CRUD/JDBC/许可/runAs）。**硬拒绝**许可给 `is_platform=N`
2. 增量插入全局字典 `mes_module`（type + data）。种子：租户 1（`default`）许可 MES 模块 `md,wm,dv,pro,tm,qc,cal` 与 `system`（及按需 `monitor` 在线用户）；**不**许可 `platform`、`tool`。租户 0 不写工厂许可行。
3. 可选：向全局 `sys_menu` **插入一行**目录 `platform`（及子菜单占位 `tenant`）。精确 Vue 组件由 46 填。禁止 for-each 租户 INSERT。
4. `ISysTenantLicenseService`（`ktg-system`）：列有效许可（未过期）；保存前校验字典 + F3 拒绝工厂获得 `platform`。
5. `SysMenuServiceImpl.selectMenuTreeByUserId`：先按角色取菜单（**包括** admin，不再 `selectMenuTreeAll` 无过滤），再按模块映射丢掉未许可节点及其子树。平台租户保留 `platform`；工厂强制剔除 `platform`。
6. `SysPermissionService.getMenuPermission` 同样过滤，避免权限字泄漏。
7. 字典 Mapper/Controller 不加租户条件；单测或 XML 断言无 `tenant_id`。
8. `rg` 保证没有按 tenant 复制菜单的工具方法。

### Public Contracts

APIs, facades, DTOs, events, or database contracts:

- 保持：`GET /getRouters` 路径、方法、`code/msg/data`，`data` 仍为路由树
- 保持：`GET /getInfo` 不回许可清单、不回 `isolationLevel`（F2）

### Persistence Changes

Tables, indexes, migrations, mapper XML, and lifecycle rules:

- 使用 P0 `sys_tenant_license`（只在主库，拦截器忽略）
- 新增量（示例结构，实现时接序号）：
  - `INSERT` `sys_dict_type`：`dict_type='mes_module'`，`dict_name='MES模块许可'`
  - `INSERT` `sys_dict_data`：`md,wm,dv,pro,tm,qc,cal,system,monitor,tool,platform`（标签用中文模块名，**不要**写主机/口令）
  - 为租户 1 插入默认许可行（上列 MES + `system`，不含 `platform`/`tool`）
  - 可选：一条全局 `sys_menu`（`path='platform'`）
- `SysDictTypeMapper.xml` / `SysDictDataMapper.xml` / `SysMenuMapper.xml`：**禁止**增加 `tenant_id` 条件
- 回滚：`DELETE` 本脚本插入的 dict/license/可选菜单 id，不 DROP 许可表

### Transaction Boundaries

- 保存许可：字典校验 + F3 校验 + 写 `sys_tenant_license` 同一事务
- `getRouters` 只读：读菜单（全局）+ 读许可（全局表）+ 内存过滤；无写
- 不把「克隆菜单」放进开通事务（I7 复制的是角色/角色菜单授权，指向全局 `menu_id`，在 41/开通单元；本单元不写那条路径的菜单 INSERT）

### Risks

- `isAdmin()` 走 `selectMenuTreeAll` 会让租户 1 的 admin 在关许可后仍看见全量模块 → 必须先改这条
- 只滤 `getRouters` 不滤 `getMenuPermission` → 前端无菜单仍可调 API
- path 映射漏子菜单：必须以顶级目录模块码覆盖整棵子树
- 误给工厂许可 `platform` 或把 `/platform/**` 配进工厂角色
- 在专库 INSERT `sys_menu`「方便 getRouters」会破坏 I8，本单元禁止
- 字典一旦加 `tenant_id` 谓词，`DATABASE` 未迁字典时全空

### Verification Strategy

- 夹具（主库、不启用第二工厂登录）：租户 1 有 `md` 许可时 `getRouters` 含 `mes/md`；删除或过期该许可后不含。使用停用第二租户行仅当 37 已有夹具用户，否则直接改租户 1 许可即可
- 尝试给租户 1 保存 `module_code=platform` → 400；`getRouters` 无 `platform`
- `rg tenant_id` 于 `SysDictTypeMapper.xml`、`SysDictDataMapper.xml`、`SysMenuMapper.xml` 的 WHERE 为空
- `rg` 无 `for` 租户 `insertMenu` / `INSERT INTO sys_menu` 出现在 Java 开通循环
- `mvn -pl ktg-system,ktg-admin,ktg-framework -am test`（有测跑测，无测编译 + 本单元新建夹具测试）
- 不改 Vue2，不跑 `frontend/`
- 未跑通不得写「测试通过」
