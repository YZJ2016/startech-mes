### Business Goal

业务必须同时支持：① 无法自建向量库的工厂 → 用**平台提供的共享**向量集群；② 能且必须用自建向量库的工厂 → 用**该厂自己的**集群。效果对齐本 MES 的 MySQL 隔离（`ROW` 共享库 vs `DATABASE` 专库）：**平台绑定连接**，工厂不能在 AI 菜单或「参数设置」自改集群 URL。向量集群仍是**基础设施**，不是工厂模型那种自助配置。API Key 不进 yml、不进参数表明文。

### Scope

In scope:

- **是**现网 `ruoyi.ai.vector-store.*`：`type`（`weaviate` | `dashvector`；未知失败关闭）、Weaviate `host`、DashVector `endpoint`。不是 MinIO，不是 chat 模型 host，不是 `ai.rag.*` 切块旋钮。
- **两档（冻结名 `SHARED` / `DEDICATED`，不复用 MySQL 的 `ROW`/`DATABASE`）：**
  - **SHARED（默认）：** 该租户无专集群绑定 → `VectorStoreFactory`（或其后继）用**平台默认**集群（同一套 Weaviate/DashVector；默认行空则 env 回落）。共享集群上仍逻辑过滤 `tenant_id`（I-A3）。
  - **DEDICATED：** 平台运营为本租户绑定其自建集群（type + host/endpoint + 只写 API Key）。运行时用**该租户客户端**，不用共享客户端。专集群上仍写/滤 `tenant_id`（对齐 `DATABASE` 行仍带 `tenant_id`）。
- **谁写绑定：** 仅 `isPlatformOperator` 的 `/platform/**`。工厂 `/ai/**` 与工厂 `sys_config` overlay **不得**改指向。工厂 403：写、以及读他厂绑定、以及读默认集群配置。专集群工厂用户也不得看见 API Key。
- **谁部署库：** 租户/其运维在其网络部署；MES 只存连接绑定，不替厂建向量进程。
- **页挂平台模块，不挂 AI 助手。** 现网 JDBC 在 `/platform/tenant` 表单（隔离级别 + 加密 JDBC，工厂不可改）。**本单元选择（与 JDBC 同操作面，不另起两套表）：**
  1. **平台默认集群：** 薄页 `/platform/ai-vector`（侧栏平台模块；精确 path 实现写死）。类比应用自己的 MySQL 数据源——不出现在租户表单。
  2. **每租户专绑定：** 做在 **同一** `/platform/tenant` 新建/编辑表单（JDBC 段旁「向量库」段），HTTP 对齐许可的兄弟资源：`GET`/`PUT /platform/tenant/{id}/vector-store`。不把向量列加进 `sys_tenant`（JDBC 已占该表且 cipher 密钥不同）。
- HTTP：一律 `/platform/**`，JWT/`LoginUser` 只信。不进 `MesPermitAllProvider`。不走 `/ai/**`（工厂 `ai` 许可闸）。信封 `code/msg/data`。
- **不落 overlay 型 `sys_config`。** 现网工厂「参数设置」可对同键插入 overlay，且 `selectConfigByKey` **overlay 优先于全局行**。集群 URL 若进该表，工厂就能劫持指向。禁止。
- **持久化（一张 master 表，禁止两套竞争表）：** Flyway **master** `ai_platform_vector_store`（名可微调）。
  - 平台默认：`tenant_id` **NULL** 一行（唯一）。
  - 专绑定：`tenant_id` = 工厂 id，每租户至多一行。
  - **无绑定行 = SHARED**（用默认）。不把 `tenant_id` 当行级业务隔离谓词（表在主库、拦截 **ignore**，**不**进 `tenant.line.include-tables`，**不**拷进专库 catalog）。
  - 列：`store_type`、`weaviate_host`、`dashvector_endpoint`、两列 cipher（或等价）。无真实 host/key 种子。
- GET：回 `type`、`weaviateHost`、`dashvectorEndpoint`、可用 `*ApiKeySet` 布尔；租户绑定另回档位 `SHARED` | `DEDICATED`。**永不**回 apiKey / cipher。
- PUT 默认：可写 type + 对应地址；api-key **只写不回填**（空 = 保留密文；仍空则 **仅默认行** 允许 env `WEAVIATE_API_KEY` / `DASHVECTOR_API_KEY` 回落）。cipher 算法与 `ai_model` 相同（AES-256-GCM，`AI_MODEL_CIPHER_KEY`）。明文禁止进表、禁止进 `sys_config`、禁止进 yml。
- PUT 专绑定：`DEDICATED` 必须有平台录入的 type + 对应 host/endpoint；缺 host / 未知 type → 失败关闭，**禁止**回落平台默认，**禁止**「工厂 env」。`SHARED`（或清空绑定）= 删该租户行，此后走默认。平台允许改档（与 MySQL D8「v1 禁改 JDBC 档」不同：向量无迁库工单）。
- **运行时解析（当前 `TenantContext`）：** 有该 `tenant_id` 专行 → 用该客户端；否则用默认行；默认行空 → env `VECTOR_STORE_TYPE` / `WEAVIATE_HOST` / `DASHVECTOR_ENDPOINT`（及对应 `*_API_KEY`）。yml `@Value` 只保留这套占位，**不再是产品面**。空默认 + 空 env 行为与现网一致（Weaviate 懒连、缺 host 到调用再失败；DashVector 缺 endpoint/key 失败关闭）。
- **V4（2026-09-08 修订）：** 一种 type 绑定**一个租户客户端**，不是一 JVM 一种。A 厂 Weaviate、B 厂 DashVector 必须可同时存活。懒缓存键对齐 A24：`(tenantId)`（SHARED 租户共用默认客户端，键可用 `0` / 哨兵）。改默认或改该租户绑定后 **evict**；下次 `get()` 用新配置。不是 per-knowledge。
- 引导（非硬禁）：不能出厂/须自建的租户**通常**绑自建 Weaviate；DashVector 留给能走云的租户。V2 本地默认仍建议 `weaviate`。
- 单测：非平台 403（含工厂读默认、读他厂绑定）；工厂 overlay 写不进本表；GET 无密钥；未知 type / DEDICATED 缺 host 失败关闭；默认行空则读 env 夹具；DEDICATED 不读 env；改 host 后不再打旧 host；两租户不同 type 各打各的客户端（mock）。
- `npm run build:prod`（有前端改动）

Out of scope:

### Acceptance Criteria

- 平台账号能保存默认集群，并能在租户表单把某厂设为 `DEDICATED` 或改回 `SHARED`；工厂账号对上述 HTTP 一律 403
- GET 无 apiKey/cipher；空 key 提交不擦掉已有密文
- SHARED：默认行优先，空则 env；DEDICATED：只用该行，不 env、不回落默认
- 同进程可同时持有不同 type 的租户客户端；未知 type 失败关闭；改配置后旧客户端不再被使用
- 知识库表单仍无集群字段
- 第 4 节未编码前不得写成已改 Java
- 文档无真实主机/凭据

### Rules and Constraints

Tenant isolation:

- 写/读本配置只信平台身份（`isPlatformOperator` / 平台 `tenant_id=0`），不信客户端租户头
- ingest / 检索解析 store 只信当前请求 `TenantContext`（90/91 同一 facade）
- 向量读写仍带 `TenantContext.tenantId`（I-A3），含 DEDICATED
- 表在主库 ignore；不是租户业务表

Security and masking:

- API Key 只写、加密、不回显、不打日志
- 地址可出现在**平台**页；工厂 UI / 列表 JSON 不得出现 Key
- 不扩匿名面

Audit and lineage:

- 新 DDL 只进 Flyway `db/migration/master/`
- 不改历史 `backend/sql/`
- 可用现有 `@Log`；审计不记明文 Key

AI/rule-engine rules:

- V4：每租户客户端一种后端；代码可同时存在多种实现
- 不换官方 EmbeddingStore
- 不把集群当知识库表单字段
- AI 仍禁止 SQL MES 业务库（A7）

Database rules:

- 一张 master 表：默认 NULL 行 + 每租户至多一行；ignore；专库不建此表
- 密钥列只存 cipher，不存明文
- 不改 `sys_tenant` 结构

## 2. Plan

### Implementation Approach

1. Flyway master 建 `ai_platform_vector_store`（默认空行种子可有、无真实 host）+ ignore。
2. `ktg-ai` 解析：当前 `tenantId` → 专行否则默认行否则 env；`VectorStoreFactory` / HTTP 适配按租户懒缓存；平台保存后 evict。
3. `ktg-admin` 薄 Controller：默认 `GET`/`PUT /platform/ai-vector`；绑定 `GET`/`PUT /platform/tenant/{id}/vector-store`。编排在 `ktg-ai` service。
4. Vue3：默认集群薄页；`views/platform/tenant` 表单增加向量档位/地址/只写 Key（与 JDBC 同页，调兄弟 API，对齐 `licenses`）。
5. yml 保留 `${VECTOR_STORE_TYPE:weaviate}` `${WEAVIATE_*}` `${DASHVECTOR_*}` 作**默认集群**启动回落；手册写明 DEDICATED 不靠 env。

### Affected Modules

- `ktg-ai`：解析、cipher、按租户 evict、Factory
- `ktg-admin`：`/platform/**` 薄 Controller
- `ktg-framework` 或既有 ignore 名单：本表不进行级租户拦截 include
- Flyway master
- Vue3 `startech-mes-front` 平台默认页 + 租户表单
- 不改 `frontend/`、不改 92 知识库页、不改 `sys_tenant` 列

### Public Contracts

- **新增**（实现写死 path）：`GET`/`PUT /platform/ai-vector`（默认集群）；`GET`/`PUT /platform/tenant/{id}/vector-store`（专绑定）。仅平台
- **冻结：** `/ai/knowledge` CRUD 与 92 表单不加集群字段；parse / chat/send / agent/send 不变
- 默认 GET `data` 建议：`{ type, weaviateHost, dashvectorEndpoint, weaviateApiKeySet, dashvectorApiKeySet }`
- 绑定 GET `data` 建议：上述字段 + `{ vectorIsolation: 'SHARED' | 'DEDICATED' }`；`SHARED` 时地址可空（表示走默认，不回默认行的 Key 布尔冒充本厂）
- PUT body：档位 + 地址字段 + 可选 `weaviateApiKey` / `dashvectorApiKey`（只写）

### Persistence Changes

- master：`ai_platform_vector_store`：`tenant_id` NULL=默认，非空=专绑定；`store_type`、`weaviate_host`、`dashvector_endpoint`、两列 cipher。无真实值种子。
- 不改 `ai_knowledge`；不改工厂 overlay `sys_config`；不改 `sys_tenant`

### Transaction Boundaries

- PUT 默认：校验 type →（若有 key）加密 → 更新 NULL 行 → evict 默认客户端。短事务。
- PUT 绑定：校验档位/host → 插入或删除该 `tenant_id` 行 → evict 该 `tenantId`。短事务。
- GET：只读，不解密到响应

### Risks

- 误用 `selectConfigByKey` 导致工厂 overlay 劫持集群（禁止）
- 改 type 后仍命中旧 Weaviate bean 内缓存 host（必须按租户 evict / 每次解析）
- 把 Key 放进 GET、参数设置或工厂租户 `getInfo`
- DEDICATED 缺 host 却静默打共享集群（禁止）
- 默认 PUT 未 evict 共享客户端，SHARED 厂仍打旧 host

### Verification Strategy

- `mvn -pl ktg-ai,ktg-admin -am test`（Java 17）；有前端则 `npm run build:prod`
- 不连 live Weaviate/DashVector 也可完成本单元
- 第 4 节据实；未跑通不得写通过
