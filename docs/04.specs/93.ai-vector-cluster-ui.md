### Business Goal

平台运营在管理端页面配置**向量数据库**集群：类型（`weaviate` | `dashvector`）与 Weaviate host / DashVector endpoint。不再把「必须改 yml / 环境变量」当产品面。工厂知识库页只管 embedding / 切块 / 片段。一进程仍只连一种向量后端（V4）。API Key 不进 yml、不进参数表明文。

### Scope

In scope:

- **是**现网 `ruoyi.ai.vector-store.*`：`type`（`weaviate` | `dashvector`；未知失败关闭）、Weaviate `host`、DashVector `endpoint`。不是 MinIO，不是 chat 模型 host，不是 `ai.rag.*` 切块旋钮。
- **页 = 平台运营。** Vue3 薄块：路由 `/platform/**`（如 `/platform/ai-vector`），菜单挂平台模块，**不是** `/ai/knowledge`，**不是**系统管理「参数设置」。鉴权对齐租户管理 / 平台首页：仅 `isPlatformOperator`（或现网等价平台闸）。工厂账号 403。
- HTTP：新 `/platform/**` GET + PUT（精确 path 实现时写死；信封 `code/msg/data`）。不进 `MesPermitAllProvider`。不走 `/ai/**`（工厂 `ai` 许可闸）。
- **不落 overlay 型 `sys_config`。** 现网工厂「参数设置」可对同键插入 overlay，且 `selectConfigByKey` **overlay 优先于全局行**。集群 URL 若进该表，工厂就能把本厂指向另一集群，等于重开 A14。禁止。
- 持久化：Flyway **master** 一行平台表（建议名 `ai_platform_vector_store`；`id=1`）。`tenant_id` **不**用于工厂隔离（可 NULL / 不用）。**不**进 `tenant.line.include-tables`，**不**拷进专库 catalog；加入租户拦截 **ignore**（同 `sys_config`）。禁止每厂一行。
- GET：回 `type`、`weaviateHost`、`dashvectorEndpoint`；可用 `*ApiKeySet` 布尔。**永不**回 apiKey / cipher。
- PUT：可写 type + 对应地址；api-key **只写不回填**（空 = 保留库内密文，或仍空则 env 回落）。cipher 算法与 `ai_model` 相同（AES-256-GCM，`AI_MODEL_CIPHER_KEY`）。明文禁止进表、禁止进 `sys_config`、禁止进 yml。
- 运行时解析（进程一份，V4）：**页/库非空优先** → 否则环境变量 `VECTOR_STORE_TYPE` / `WEAVIATE_HOST` / `DASHVECTOR_ENDPOINT`（及对应 `*_API_KEY`）。yml `@Value` 只保留这套占位，**不再是产品面**。空库 + 空 env 行为与现网一致（Weaviate 懒连、缺 host 到调用再失败；DashVector 缺 endpoint/key 失败关闭）。
- 改 type / host / endpoint / 已保存的 key 后 **evict** 懒向量客户端（对齐 A24 改 Key 即 evict）。下次 `VectorStoreFactory.get()` 用新配置。不是 per-knowledge、不是 per-factory 客户端。
- 单测：非平台 403；工厂 overlay / 参数设置写不进本表；GET 无密钥；未知 type 失败关闭；库空则读 env 夹具；改 host 后不再打旧 host（mock）。
- `npm run build:prod`（有前端改动）

Out of scope:

- 每工厂独立 Cluster / 每知识库独立 Cluster（不重开 A14）
- 把集群字段放进 92 知识库对话框或 `ai_knowledge`
- 工厂可改的 `sys_config` overlay（含「参数设置」同键覆盖）
- 明文 API Key 进参数表或 GET 列表
- 补齐 Milvus / Qdrant 产品字段（V2 仍开放；本页只 `weaviate` | `dashvector`）
- 改 parse / chat/send / agent/send；改 90 解析器；改 91 Augmentor
- live 真实集群 IT（可选、可跳过）；文档不写真实 host / key
- 改 Vue2；pad 注册 `/platform/**`

### Acceptance Criteria

- 平台账号能在 `/platform/**` 页看到并保存 type + 地址；工厂账号不能
- GET 无 apiKey/cipher；空 key 提交不擦掉已有密文
- 运行时：库中地址优先，空则 `WEAVIATE_HOST` / `DASHVECTOR_*` / `VECTOR_STORE_TYPE`
- 一进程一种 type；未知 type 失败关闭；改配置后旧客户端不再被使用
- 第 4 节未编码前不得写成已改 Java
- 文档无真实主机/凭据

### Rules and Constraints

Tenant isolation:

- 写/读本配置只信平台身份（`isPlatformOperator` / 平台 `tenant_id=0`），不信客户端租户头
- 向量检索/写入仍带当前请求 `TenantContext.tenantId`（I-A3）；本页不改变量隔离模型
- 表不按工厂 `tenant_id` 分行

Security and masking:

- API Key 只写、加密、不回显、不打日志
- 地址可出现在平台页；日志/toast 仍不打印 token
- 不扩匿名面

Audit and lineage:

- 新 DDL 只进 Flyway `db/migration/master/`
- 不改历史 `backend/sql/`
- 可用现有 `@Log`；审计不记明文 Key

AI/rule-engine rules:

- V4：一个进程一个激活后端
- 不换官方 EmbeddingStore
- 不把集群当知识库表单字段

Database rules:

- master 全局一行；ignore 名单；专库不建此表
- 密钥列只存 cipher，不存明文

## 2. Plan

### Implementation Approach

1. Flyway master 建一行表 + 可选空行种子（无真实 host）。
2. `ktg-ai` 解析：库 → env；`VectorStoreFactory` / HTTP 适配改读解析结果；改配置 evict。
3. `ktg-admin` 薄 Controller：`GET`/`PUT /platform/...`，编排在 `ktg-ai` service。
4. Vue3：`src/api/platform/` + `views/platform/` 薄表单（type 下拉、host/endpoint、两个只写 Key）。
5. yml 保留 `${VECTOR_STORE_TYPE:weaviate}` `${WEAVIATE_*}` `${DASHVECTOR_*}` 作启动回落；手册不再写「只能改 env」。

### Affected Modules

- `ktg-ai`：解析、cipher、evict、Factory
- `ktg-admin`：`/platform/**` 薄 Controller
- `ktg-framework` 或既有 ignore 名单：本表不进行级租户拦截 include
- Flyway master
- Vue3 `startech-mes-front` 平台页
- 不改 `frontend/`、不改 92 知识库页

### Public Contracts

- **新增**（实现写死 path）：平台 GET/PUT 向量集群；仅平台
- **冻结：** `/ai/knowledge` CRUD 与 92 表单不加集群字段；parse / chat/send / agent/send 不变
- GET `data` 建议：`{ type, weaviateHost, dashvectorEndpoint, weaviateApiKeySet, dashvectorApiKeySet }`
- PUT body：上述地址字段 + 可选 `weaviateApiKey` / `dashvectorApiKey`（只写）

### Persistence Changes

- master：`ai_platform_vector_store`（名可微调）一行：`store_type`、`weaviate_host`、`dashvector_endpoint`、两列 cipher（或等价）。无真实值种子。
- 不改 `ai_knowledge`；不改工厂 overlay `sys_config`

### Transaction Boundaries

- PUT：校验 type →（若有 key）加密 → 更新一行 → evict。短事务。
- GET：只读，不解密到响应

### Risks

- 误用 `selectConfigByKey` 导致工厂 overlay 劫持集群（禁止）
- 改 type 后仍命中旧 Weaviate bean 内缓存 host（必须 evict / 每次解析）
- 把 Key 放进 GET 或参数设置列表

### Verification Strategy

- `mvn -pl ktg-ai,ktg-admin -am test`（Java 17）；有前端则 `npm run build:prod`
- 不连 live Weaviate/DashVector 也可完成本单元
- 第 4 节据实；未跑通不得写通过
