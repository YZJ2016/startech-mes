### Business Goal

解析写入、检索、按文档删除在 `type=weaviate` 时按 embedding 维度选 class；维度不一致失败关闭。SHARED/DEDICATED 解析不变。DashVector 仍 `MesAiK*` + partition。

### Scope

In scope:

- ingest `createSchema` / `storeEmbeddings`：维度来自本库 embedding 模型；与向量长度不一致失败关闭，不得标解析成功
- `search`：用 query 向量长度选 class（适配器 100 已做）；Retriever 仍只传 `TenantContext` + kid，禁止客户端 `tenantId`
- 删除附件 / `removeByDoc`：从该知识库 embedding 模型读维度后传入；无模型或维度 ≤0 失败关闭（不删他库 class）
- Factory：无专行走 yml Weaviate；有专行不读 yml；A 厂 Weaviate、B 厂 DashVector 共存；改绑定 evict
- 单测：跨租户 search 失败关闭；Weaviate HTTP 不含 `MesAiK`；DashVector 仍 POST `MesAiK{tid}_{kid}` 与 partition `t{tid}`；minScore 对 Weaviate 仍 distance → `1-distance`（91 不得回退）

Out of scope:

- Weaviate REST 细节（**100**）
- 手册正文（**102**）
- live 集群、旧 class 双读
- 改 93 绑定 HTTP、知识库表单、向导

Non-goals:

- 不按 kid 建 Weaviate class
- 不把 DashVector collection 改成 `MesAiD*`

### Acceptance Criteria

- 同厂两个 kid、同一维度：Weaviate 打同一 class、同一 tenant，where 的 kid 不同
- 向量长度与模型维度不同 → 不写向量、解析失败可重试
- DEDICATED 行存在时不打 yml host
- DashVector 回归：`collectionName` 与 partition 现网字符串不变
- 第 4 节未编码前不得写「测试通过」

### Rules and Constraints

Tenant isolation:

- Filter 只信 `TenantContext` + 已校验 kid
- 空上下文不得 ingest / search / delete 向量

Security and masking:

- 单测不写真实 host/Key

Audit and lineage:

- 无新表

AI/rule-engine rules:

- embedding 仍 A24 `(tenantId, modelId)`
- 不换官方 EmbeddingStore

Database rules:

- fragment 回表仍带 `tenant_id`
