  - 总控：`docs/04.specs/86.mes-industry-pack-program.md`

  - 下一单元：`docs/04.specs/88.industry-pack-extensions-p1.md`

### Business Goal

平台给工厂勾选 `ip.demo` **且**该厂角色已勾 9200 后，Vue3 侧栏出现「行业包 / 行业说明」桩页（两步，**IP-D21**）；仅许可不够。撤勾选许可后 `getRouters` 不再出现 9200 段。不改工单/BOM/工艺。无 `ip` / `ip.*` 的工厂行为与今天一致（**IP-D20**）。不选定真实垂直（**IP-G1** 仍开放，不挡本单元）。

### Scope

In scope:

- Flyway **master**：`mes_module` 增加 `ip`（标签「行业包」）、`ip.demo`（标签「行业说明（桩）」）；`sys_menu` `9200` 目录、`9201` 桩页、必要按钮（如 `9210`）
- `MenuModuleMapper`：`mes/ip/demo`→`ip.demo`，`mes/ip`→`ip`；`mes:ip:demo:`→`ip.demo`，壳 `mes:ip:` / `mes:ip:list`→`ip`。长前缀必须先于短前缀
- `saveLicenses`：入参含任意 `ip.*` 则保证集合含 `ip`；不含任何 `ip.*` 则不含 `ip`。仍拒绝未知码、仍拒绝工厂获得 `platform`/`job`
- 平台页 `views/platform/tenant/index.vue`：`licenseOptions` **同时隐藏** `platform` 与 `ip`
- Vue3 `src/views/mes/ip/demo/index.vue`：说明页（IP-D17 文案），无业务 CRUD
- 单测：映射；`saveLicenses` 派生/剥离 `ip`；工厂许可集不含 `ip.demo` 时菜单过滤掉 9200 段（可沿用 `SysMenuServiceImplLicenseTest` 风格）
- **许可 → 侧栏（两步，IP-D21 / 已收口的 IP-G2=A）：** （1）平台给该租户许可 `ip.demo`（派生 `ip`）；（2）工厂管理员（或能编辑角色菜单者）在「角色管理」手动勾 9200 段。两步都满足后侧栏才出现「行业包」。本单元**禁止** `saveLicenses` 给任何角色 INSERT `sys_role_menu` 9200；**禁止**用新开租户角色模板当机制。零包路径不依赖角色勾选（无 9200 可展示，IP-D20）
- **负向约束（IP-D20）：** 不得默认给任何租户写 `ip` / `ip.demo`；不得把 9200 做成无许可也必见的空目录；不得改现网工单 / BOM 等 `sys_menu` 结构使全厂可见变化；不得把 `ip` 放进必选许可

Out of scope:

- 选定第一个真实行业（**IP-G1** / U1；later-not-now，不挡本单元）
- replace / profile / 换组件（**88 / IP-D9 / IP-G3**）
- 扫描插件、按租户写 `sys_menu`、新 Maven 模块
- 真实行业表、spoke-wheel 领域
- 改 Vue2；改 `MesPermitAllProvider`；改 `/getRouters` URL
- 把 `ip` 列入「不得许可给工厂」黑名单（那是 `platform`/`job`）
- tenant Flyway；yml 开关

### Acceptance Criteria

- 字典存在 `ip`、`ip.demo`；平台勾选列表能看到 `ip.demo`、**看不到** `ip` 与 `platform`
- `PUT /platform/tenant/{id}/licenses` 只传 `ip.demo`（及该厂原有 md/pro 等）：落库含 `ip` 与 `ip.demo`；再去掉 `ip.demo`：落库无 `ip`、无 `ip.demo`
- 工厂会话有效许可含 `ip`+`ip.demo` **且**角色已绑 9200/9201：`GET /getRouters` 含 path 前缀 `mes/ip` 与组件 `mes/ip/demo/index`
- **已许可、角色未勾 9200：** `getRouters` **无**「行业包」/ `mes/ip`；工单 / BOM 等其余 MES 菜单与许可前一致，系统仍可用
- 工厂无上述许可：`getRouters` **无** `mes/ip`；其它 MES 模块与许可前一致
- **负向（无 `ip` / `ip.*` 许可的租户 = 现网，IP-D20）：** `getRouters` 无「行业包」目录、无 9200 / 9201；侧栏 MES 菜单与今日一致；登录与工单 / BOM 路径不变；`getRouters` 不得因未启用行业包而 500；种子不得默认给全厂写 `ip` 许可
- 平台 `tenantId==0` 回家仍不靠工厂许可看菜单（现网 `licensed==null`）
- `MenuModuleMapper` 单测：`mes/ip/demo` 不是 `ip`；`mes/pro` 仍是 `pro`
- `npm run build:prod`（有前端改动时）与 `mvn -pl ktg-system -am test`（或至少 `compiler:compile`）实跑后写入第 4 节
- 文档与代码无密钥；无按租户循环 INSERT `sys_menu`；`saveLicenses` **不** INSERT `sys_role_menu` 9200
- **许可 → 侧栏是两步：** 平台许可 `ip.demo` 之后，还须工厂角色勾 9200，侧栏才有「行业包」。不得把「只许可即见侧栏」列为通过。零包负向验收不依赖角色勾选（IP-D20）

### Rules and Constraints

Tenant isolation:

- 不克隆 `sys_menu`；`DATABASE` 仍读主库菜单（I8）
- `TenantContext` 来自 JWT；无客户端租户头
- 无上下文不访问租户表（本单元无新租户表）

Security and masking:

- 许可 API 仅平台
- 桩页若无 API 则无新匿名口；若加 `/mes/ip/**` 必须登录且不进 permitAll
- 权限字用 `mes:ip:demo:list` 等，禁止杜撰与映射不一致的码

Audit and lineage:

- 不改历史 SQL 文件；只用新 Flyway 版本（master 号须大于现网最大 `V20260902.33`，实现时按目录最大号顺延）
- 菜单 id 冻结在 9200 段

AI/rule-engine rules:

- 无

Database rules:

- 全局字典/菜单 → master location
- 不把 `ip` 开关写入 yml / `sys_config`（本期无键）

## 2. Plan

### Implementation Approach

- 映射：在 `PATH_PREFIX` **插入**更长键于 `mes/ip` 之前；`resolvePerm` 对 `mes:ip:demo` 前缀先于 `mes:ip:`
- 许可：`saveLicenses` 在校验未知码之后、delete+insert 之前，规范化 `ip` 派生。未知 `ip.foo`（字典没有）仍拒绝
- 前端：桩页静态文案；许可 options filter `!== 'platform' && !== 'ip'`
- **不要**调用任何「重建菜单」服务去改库中菜单树
- **不要**在 `saveLicenses` 或 Flyway 中给角色 INSERT 9200（IP-D21）

### Affected Modules

- 可改：`MenuModuleMapper.java` 及测试；`SysTenantLicenseServiceImpl` 及测试；`SysMenuServiceImplLicenseTest` 如需覆盖 `ip`
- 可改：`db/migration/master/V*.sql`（字典+菜单；**不要** INSERT `sys_role_menu` 9200，含全厂默认与新租户模板）
- 可改：`startech-mes-front/src/views/mes/ip/demo/index.vue`、`views/platform/tenant/index.vue`
- 不可改：`frontend/`、`kuaigeyun-mes/`、对话 path、`MesPermitAllProvider`

### Public Contracts

- **冻结：** `PUT /platform/tenant/{id}/licenses`、`GET /getRouters`、`GET /platform/tenant/{id}/licenses`
- **增量语义：** 读许可列表可能多出派生 `ip`；写时客户端可不传 `ip`
- **权限字：** `mes:ip:list`（壳）、`mes:ip:demo:list` / `query`

### Persistence Changes

- `sys_dict_data` 两行；`sys_menu` 9200 段
- 无新表

### Transaction Boundaries

- 沿用 `saveLicenses` 的 `masterTransactionManager`

### Risks

- 短前缀先匹配导致 `mes/ip/demo` 变成 `ip`，许可了壳却看不到子页（或相反）
- 只许可不勾角色却验收工厂侧栏出现「行业包」（违反 IP-D21）
- 未许可租户侧栏出现空「行业包」（违反 IP-D20）
- Flyway 改租户脚本把全局菜单打进专库
- 给 `selectValidModuleCodes` 过滤掉 `ip`
- `loadView` 路径与菜单 component 不一致导致白页

### Verification Strategy

- 单测：映射、派生 `ip`、许可过滤；**无 `ip.*` 时 9200 段被滤掉、其它 MES 菜单不变**
- 若有浏览器：平台勾选 `ip.demo` → 读 licenses 含 `ip`；工厂账号**已勾** 9200 后侧栏有行业包；去掉许可后刷新无该目录。工厂账号**未勾** 9200 时侧栏无行业包、MES 仍可用
- 负向：从未开 `ip.demo` 的工厂侧栏无「行业包」空目录
- 未实跑不得在第 4 节写通过
