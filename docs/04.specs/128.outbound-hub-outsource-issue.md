### 拆分决策（OH-G3）

| 选项 | 结论 |
| --- | --- |
| 一文件两臂（发料+采购退货） | **不采用** |
| **两文件 128 / 129** | **采用** |

**理由（对照只读，同 123/124/125 风格）：** 快格云为 **两套独立菜单/表/服务/API/Hub 类型**：

| 快格云 | 表（示意） | Hub `outbound_type` | 菜单域 | 本仓 NN |
| --- | --- | --- | --- | --- |
| `OutsourceMaterialIssue` | `apps_kuaizhizao_outsource_material_issues` | `outsource_issue` | 委外管理「委外发料」 | **128** |
| `PurchaseReturn` + `PurchaseReturnItem` | `…_purchase_returns` / `…_items` | `purchase_return` | 采购管理「采购退货」 | **129** |

业务方向不同（原料发给委外供应商 vs 采购物料退回供应商），能力策略亦不同（快格 Hub 对 `outsource_issue` 默认不在 Hub 内 confirm/update/delete/withdraw；采购退货可 confirm/withdraw）。**禁止**用一张 Startech 头表 + `outboundType` 列伪装两单；**禁止**塞进 112 其他出库/借料表。

### Business Goal

在 **委外工单已存在** 的前提下，仓管可建 **委外发料单**（关联委外工单、发原料出仓），过账 **扣减库存**，并在出库 Hub 按 `OUTSOURCE_ISSUE` 可见可执行；同时为入库 **124** 提供可汇总的发料真源（按发料可退上限）。

**现网事实（2026-09-18，`startech-mes-basic` 检索）：**

| 项 | 现网 | 128 假设 |
| --- | --- | --- |
| 委外发料表 / Java / Vue | **无** `wm_outsource_issue*`、**无** `OutsourceIssue*`（全仓空） | 新建头/行 + REST + Vue3 |
| 委外工单 | **已有**（123）：`wm_outsource_work_order` + `/mes/wm/outsourceworkorder` | 硬依赖；无 WO 停止 |
| 124 退料 | 已落；头 `outsource_issue_id` **可空**（注释：无发料表时不校验） | 本单元落地后，124 可按发料汇总可退（**124 加固另开或本会话点名**；本文件默认只交付发料，不强制改 124 代码） |
| 出库 Hub | **四臂**：`ISSUE` / `PRODUCT_SALSE` / `OTHER_ISSUE` / `MATERIAL_BORROW`（`WmOutboundHubMapper.xml`） | +`OUTSOURCE_ISSUE`（与 129 落地顺序决定五/六臂；编码时读现网 UNION） |
| 菜单 | 入库委外已用 **9390–9414**；出库 9310–934x | 本单元 **9420–9424** |
| OQC/金额/打印 | 115–117 仅挂既有臂 | 本类型 **默认无** OQC；金额/打印不强制扩展 |

**对照只读：**

- 表：`OutsourceMaterialIssue` — 快格为 **一物料一行单据**（flat；`quantity` 在头级），状态 `draft/completed/cancelled`；创建时锁 WO、`push_outsource_issue` 能力校验；支持 preview（BOM 需求/已发/待发/可用库存）与 batch 创建。
- Hub：`mapOutsourceIssueToOutbound` → `outbound_type: 'outsource_issue'`；Hub 内 confirm/update/delete/withdraw **不允许**（文案：不在此确认/编辑/删除/撤回）。
- API：`GET/POST /outsource-material-issues`、`POST …/batch`、`GET …/{id}`、`POST …/{id}/complete`；拉单属 Hub `outbound.pull_from_outsource_work_order`（Startech **OH-G6**，本单元 OUT）。
- Startech **默认头+行**（对齐 112/123），不拷 flat 一物料一单；过账一步 `PREPARE`→`FINISHED`（对齐 112），库存 **−1**。

### Scope

In scope:

- tenant：`wm_outsource_issue` / `wm_outsource_issue_line`（命名可微调，禁止快格表名）
- master：菜单 **9420–9424**
