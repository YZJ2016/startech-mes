### Business Goal

每个租户在 `ai_provider` / `ai_model` 上有自己的 apiKey（及 host / 模型名）。对话与 embedding **出站必须使用当前租户、当前 `modelId` 那一行的凭证**，不能用进程级全局 Key。模型目录**不**搬进 yml，也不用 LangChain4j starter 的全局 `ChatModel` Bean。产品**不**把「租户之间密钥互不可见」当作本决策的验收项；请求路由隔离才是验收项。

### Scope

In scope:

- 锁定配置源：厂商/模型/apiKey **只**在库表（现有 `ai_provider`、`ai_model`）。yml 不写按 `tenantId` 展开的模型目录，不写 `langchain4j.open-ai.chat-model.api-key` 这类全局模型凭证
- 锁定实例生命周期：按 `(tenantId, modelId)` **懒建 + 缓存**；请求时用 `TenantContext` + 已校验的 `modelId` get 实例；**禁止**启动时 `select *` 为每个租户各造一个实例；**禁止** `tenantId → 唯一 ChatModel`（一租户多模型会打错上游）
- 锁定出站：get 到的实例上的 apiKey 必须来自该行（解密或平台租户 0 的既有回退规则）；他租户 `modelId` 失败且不 get、不调上游
- 缓存失效：该行改 Key / 改 host / 改模型名 / 删除后必须丢掉对应缓存键（实现时可 TTL 或写路径显式 evict）
- 文档同步：设计 06、缺口 03/04、总控 48、50/51/57/58/60 引用本决策

Out of scope:

- 本单元改 `ktg-ai` Java、`ktg-ai/pom.xml`、SQL、Vue
- 把模型配置改写进 yml 或环境变量映射表
- 启动全量预热所有租户的 ChatModel
- 废止 A3 落库加密、A20 列表/options 不下发明文 Key（API 契约不变）
- MCP / 受控写 Tools / 工作流 / 短剧 / Harness（Agent 生命周期见 `62`；B/MCP/工作流见 `docs/04.specs/64.ai-tools-mcp-workflow.md`，本单元不实现）
- 改 `/ai/**` HTTP 契约、Sa-Token、第二套 `SecurityFilterChain`、MyBatis-Plus、默认 `uploadMinio`

### Rules and Constraints

Tenant isolation:

- 只信 JWT / `TenantContext`；禁止请求体传 `tenantId` 或明文 `apiKey` 来换钥匙
- `modelId` / `sessionId` / `knowledgeId` 必须属于当前租户，否则 404/403，且不调上游、不创建缓存项
- `DATABASE` 专库：懒建时读的是当前租户数据源上的 `ai_model`，因此启动全量扫描主库本来就不完备

Security and masking:

- A3 / P1-D8：库内仍加密存放；A20 / options 仍不回明文 Key（浏览器契约不变）
- 本决策不把「A 厂管理员看见 B 厂 Key」列为产品需求，也不列为要实现的功能
- 日志仍不打印 apiKey / cipher（I-A5 / P1-I4）；与「租户互不可见」不是同一件事
- 不启用 LangChain4j starter 全局 `chat-model.api-key` Bean

Audit and lineage:

- 无新表；沿用 57 的 `ai_provider` / `ai_model`
- 本单元不改 SQL

AI/rule-engine rules:

- Chat / embedding 出站都走同一套键：`(tenantId, modelId)`（embedding 模型行同样）
- 后续改写 LangChain4j 时：动态 `OpenAiStreamingChatModel.builder()`（或等价），**不要** `@Autowired ChatModel`
- Agent/AiService 凭证必须复用本文件的 `(tenantId, modelId)` 工厂，不得另建全局模型；细节见 62
- 白名单 MCP 见 64（A27）；禁止本单元借机引入 MCP 全家桶

Database rules:

- 根键仍 `ruoyi:`；yml 仅平台占位（cipher、默认 Key、向量集群），不含租户模型清单
- 平台默认 Key 回退仍只允许既有规则（如仅 `tenantId == 0`）；工厂缺 Key 不得 silently 用别人的 Key
