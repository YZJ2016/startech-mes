## 1. Spec

### Capability

- Name: 新增只读 Tool `query_engineering_bom`、`query_process_route`（后者为 spec 200 `query_process_routes` 的 P2 补充视图时按实际目录并轨，T1 核对是否已存在同名 Tool，避免重复登记）。
- Module: `riveredge-backend/src/apps/kuaiai/services`（tools 适配层）、manifest `ai_tools`。
- Priority: P2（S24 BOM/工艺问答）。
- Related requirement/design documents: 需求 25 SC-D1、SC-D5、SC-D7；设计 26 §4、§5.2；前置 spec 189、190、200、212（where-used）。

### Business Goal

工艺/生产问“产品 P-3301 的 BOM 有哪些层级和替代料”“这道工序的工艺参数是什么”，助手基于工程 BOM 与工艺路线的真实结构回答。

### Scope

In scope:

| Tool | 参数 | 底层 service | 权限码 |
| --- | --- | --- | --- |
| `query_engineering_bom` | `material_id` 或 `bom_id`（二选一必填）、`view=tree\|flat\|substitutes`、`level≤5` | master_data 工程 BOM service（T1 核对签名） | `master-data:process:engineering-bom:read` |
| `query_process_route`（若 spec 200 已建则本单元只补视图） | `material_id` 或 `route_id`、`view=nodes\|parameters` | master_data 工艺路线 service（spec 200 已用） | `master-data:process:process-route:read`（T1 核对） |

- BOM 树形输出按层级缩进列出（物料编码、名称、用量、单位、损耗率）；节点超过上限时截断并注明总节点数。
- `view=substitutes` 输出替代料组明细；无替代关系时如实返回空。
- 数据范围：service 不接收 `current_user` 的，适配层补行级范围；物料主数据一般全厂可见，范围键 T1 定。

Out of scope:

- BOM/工艺的新建、变更、版本切换（写操作走 ECN 流程，见 spec 212）。
- 图纸文件正文。

### Acceptance Criteria

1. BOM 树输出与工程 BOM 页结构一致；层级/截断正确。
2. `query_process_route` 参数视图输出工序参数（如适用）；若 spec 200 已建同名 Tool，本单元只做增量，不重复登记 manifest 条目。
3. 非法 `view`/`level` 返回固定错误文案；物料不存在按“不存在”回复。
4. 新增 Tool 登记于 manifest（`label`、`kind=read`）。

### Rules and Constraints

Tenant isolation:

- 传 `ctx.tenant_id`。

Security and masking:

- 不输出供应商进价、客户专属信息。

Audit and lineage:

- 沿用 Tool 级审计。

AI/rule-engine rules:

- 结构、用量、参数来自业务记录（SC-D5）。

Database rules:

- 无表结构变更。

### 场景模板（Y3=a）

本单元交付时同步登记场景模板 `bom-process`（BOM 工艺助手）：预置档案 `enabled_tools` 为本单元 Tool 集合，停用 + 空授权（Y4=a）；模板 key 即能力矩阵场景卡，默认绑定同 key 预置实例（spec 191，Y1/Y2=a）。system_prompt 只引用本单元 Tool，插画按 spec 201 T2 约定。
