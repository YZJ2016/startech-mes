## 1. Spec

### Capability

- Name: 用 springboot2 内容替换 `ktg-quartz`
- Module: `ktg-quartz`
- Priority: P0
- Related requirement/design documents:
  - `docs/04.specs/11.backend-shell-swap-program.md`
  - 抽出确认：`09`/`10` 已认定 quartz 无 MES 额外业务类型

### Business Goal

定时任务模块与若依 3.9.2 `springboot2` 的 `ruoyi-quartz` 文件集对齐，仍以 Maven 模块 `ktg-quartz`、包名 `com.ktg.quartz` 对外。不碰 `ktg-mes`，不做五项中的 admin/security 接线。

### Scope

In scope:

- 对照树：`RuoYi-Vue-springboot2/ruoyi-quartz/`（HEAD 必须是 `913524b1525a0e374774afbb54c452d8f68a5a8f`）
- 覆盖 nested：`startech-mes-basic/backend/ktg-quartz/` 的 `src/` 与该模块 `pom.xml`
- 机械替换：`com.ruoyi` → `com.ktg`；pom `ruoyi-quartz` → `ktg-quartz`；parent 保持 `com.ktg:ktg`（版本用 nested 现有 parent，当前 `3.8.2`）
- 含 Java 与 `src/main/resources/mapper/quartz/*.xml`

Out of scope:

- 改模块名为 `ruoyi-quartz` 或包名为 `com.ruoyi.quartz`
- 换 `ktg-common` / 其它模块
- Java 17、Boot 3/4、jakarta、前端
- 改调度业务语义、改 `sys_job` 表结构
- 五项接线（本块没有）

### Acceptance Criteria

- `ktg-quartz` 源码来自上述对照 commit 的 `ruoyi-quartz`，包名为 `com.ktg.quartz`
- 目录与 `artifactId` 仍为 `ktg-quartz`
- XML namespace 为 `com.ktg.quartz.mapper.*`
- JDK 8 下本模块（及 `-am` 依赖）`compiler:compile` 成功后再开始 `13`
- `ktg-mes` 无本单元 diff

### Rules and Constraints

- 不涉及

Security and masking:

- 不在文档写作业调用的内部主机

Audit and lineage:

- 不改历史 SQL；不借机改 MES 任务

AI/rule-engine rules:

- 不涉及

Database rules:

- 不改 `sys_job` / `sys_job_log` 结构

## 2. Plan

### Implementation Approach

1. 确认 nested toplevel 是 `startech-mes-basic`；对照 worktree HEAD 等于总控 hash
2. 备份意识：覆盖前看 `git status`，不要盖掉用户未提交修改
3. 将对照 `ruoyi-quartz/src` 拷入 `ktg-quartz/src`（替换 Java + mapper XML）
4. 按对照 `ruoyi-quartz/pom.xml` 更新依赖声明，但 **artifactId/parent/groupId 按机械替换规则留在 ktg 坐标系**
5. 全模块替换 `com.ruoyi` → `com.ktg`
6. 若编译失败是因为引用了尚未换入的 3.9.2 common 新类型：**停止**，不要把 common 文件提前拷进本块；回报总控，必要时先做 `14`

对照与 nested 的 Java 文件名集合当前一致（18 个类型）。以对照树为准覆盖内容，不要只挑几个文件改。

### Affected Modules

- `ktg-quartz`
- 根 POM：仅当本块编译明确需要 2.5.15 / 其它 springboot2 属性时才改；能在现有 2.5.12 上编过则本块不碰根 POM

### Public Contracts

- HTTP：`SysJobController` / `SysJobLogController` 路径保持若依定时任务那套（换入后与 3.9.2 springboot2 一致）
- 不改管理端 Vue2 路由

### Persistence Changes

- 无

### Transaction Boundaries

- 沿用换入源码既有事务，不扩大

### Risks

- 对照用了 `master` 导致 jakarta 进 quartz
- parent 误写成 `com.ruoyi:ruoyi:3.9.2` 使聚合解析失败

### Verification Strategy

- `rg "com\\.ruoyi" backend/ktg-quartz` 应为 0
- `rg "com\\.ktg\\.mes" backend/ktg-quartz` 应为 0
- Maven compile（JDK 8 + antrun skip）
