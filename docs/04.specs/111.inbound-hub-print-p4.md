## 1. Spec

### Capability

- Name: 入库 Hub P4 — Hub 打印（IH-G6）
- Module: `startech-mes-front` 入库 Hub 打印入口（浏览器 `window.print`）。**禁止**改 Vue2。本单元已编码。不改 UReport。
- Priority: P4（入库切片后续；**不**改 105 范围）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/14.mes-inbound-hub-iqc-gaps.md`（**IH-G6**、INV-F08 打印支、INV-A04）
  - 设计：`docs/03.design/14.mes-inbound-hub-iqc-plan.md`（§7）
  - 切片总控：`docs/04.specs/104.mes-inbound-hub-iqc-program.md`
  - P0：`docs/04.specs/105.inbound-hub-iqc-p0.md`（已规定无打印按钮，保持）
  - 出库打印不是本单元：缺口 15 **OH-G4**

### Business Goal

仓管在入库 Hub 能打印当前单据（浏览器打印页）。105 明确无打印按钮。本单元才加 Hub 打印。不搬快格云打印框架 / `capabilities.print` 对象模型。不改 UReport（CAT-W06 禁止混进）。

### Scope

In scope（**仅当编码门禁满足**）:

- Hub 页打印入口（浏览器打印或现网已有打印手段的薄封装）
- 权限与 Hub list / 单据 query 对齐；无权限不展示
- UI-A：只动 Hub；不重排旧入库 CRUD

Out of scope:

- 把打印塞进 105 范围声明；改旧 `itemrecpt`/`productrecpt` 布局
- 快格云打印模板引擎、自定义字段附件管道（INV-F07）
- 出库 Hub 打印（OH-G4）、仓储其余块 CAT-W01/W04–W07
- 改 UReport 当本单元「库存报表」（CAT-W06 禁止混进）
- 改 Vue2、扩 permitAll

### Acceptance Criteria

- **编码门禁（已满足）：** 点名 111。
- 角色能进 Hub 时可打印本租户当前抽屉单据；无 `mes:wm:inboundhub:list` 不展示打印按钮；无新 HTTP、不改 UReport
- 第 4 节未跑命令不得写绿

### Rules and Constraints

Tenant isolation:

- 打印数据查询带 `tenant_id`；禁止拼他厂单号
- 只信 JWT

Security and masking:

- 打印接口须登录 + `@PreAuthorize`（若新增 GET）
- 不进 `MesPermitAllProvider`；不打印内部路径

Audit and lineage:

- 若新增 API：旧 list/执行 URL 不变
- 模板若不进库则不要为打印新建业务头表

AI/rule-engine rules:

- 不涉及

Database rules:

- 默认无新业务列；禁止借打印加金额列（金额走 110）
