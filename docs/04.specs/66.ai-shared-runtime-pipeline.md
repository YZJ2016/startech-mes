### Business Goal

消除 chat、agent、workflow run 三条入口在会话准备、SSE 推送、异常翻译与异步租户上下文上的重复实现，统一为可复用运行时组件。工厂用户仍走冻结的三条 HTTP；纯对话行为不得削弱。

Goal：三条口共用同一套 session-prepare / SSE / error / `TenantContext` 装饰；path 与基础 SSE 信封不变。

### Scope

In scope:

- 抽出内部组件（名随实现）：**session-prepare**（校验 modelId/sessionId 属本租户、续会话、chat/agent 先落 user 消息）、**SSE writer**（`data:` JSON，A17 同一信封：基础 `content`/`done`；扩展白名单 `error` / `reasoning` / `status` / `tool` / `step`）、**error mapper**（上游/租户/许可失败 → 安全文案；日志无密钥）、**async tenant wrapper**（统一 `TenantTaskDecorator` 或等价）
- `AiChatServiceImpl.send`、`AiAgentServiceImpl.send`、`AiWorkflowServiceImpl.run`（或等价）改为调用上述组件，**删除重复逻辑**
- **冻结不变：**
  - `POST /ai/chat/send`
  - `POST /ai/agent/send`
  - `POST /ai/workflow/run`
- 单测：Mock 上游；断言 SSE 无 `[NODE_CHUNK_*]`；空 `TenantContext` 失败关闭；跨租户 modelId/sessionId 不调上游

Out of scope:

- Agent 记忆 Store（67）、profile（68）、RAG 参数（69）、workflow chat 步（70）、Tool 审计（71）
- 改 HTTP path、method、认证、许可闸
- ruoyi `[NODE_CHUNK_*]`、langgraph、MCP 新能力
- Vue3 / Vue2、新表（可无 DDL）
- 真实地址、凭据、Token

Non-goals:

- 不为抽公共层改 chat/agent/workflow 契约
- 不引入第二套 SSE 协议

### Acceptance Criteria

- 三条 HTTP path 与 58/61/64 冻结一致；`MesPermitAllProvider` 仍无 `/ai`
- 三条口同一 A17 信封：基础 `{content, done}`；扩展白名单 `error` / `reasoning` / `status` / `tool` / `step`（工作流用其中的 `step`/`error`，不另搞一套）；无 `[NODE_CHUNK_*]`
- 空上下文 / 跨租户 session 或 model：404/403 或既有租户异常，不调上游、不写消息
- 异步线程均有 `TenantContext`（I-A4/I-A7）
- 日志/SSE/异常不打印 apiKey、cipher、MCP token
- 第 4 节未编码前不得写「测试通过」

### Rules and Constraints

Tenant isolation:

- 只信 JWT / `TenantContext`；禁止请求体传 `tenantId`
- sessionId / modelId 必须属当前租户

Security and masking:

- `/ai/**` 必须登录；不进 `MesPermitAllProvider`
- 错误响应对前端不回密钥（I-A5）

Audit and lineage:

- 本单元可无新审计表；行为与 61/64 一致

AI/rule-engine rules:

- A17/A28 SSE 自定；禁止 ruoyi 工作流帧
- 纯 chat 路径仍可无 Tool

Database rules:

- 可无 DDL；若改消息落库时序须与 51/58 一致

## 2. Plan

### Implementation Approach

1. 梳理三处重复：session 校验、SSE 写入、异常 catch、异步装饰。
2. 新增 runtime 包内 facade / helper（保持薄 Controller）。
3. 逐条迁移 chat → agent → workflow run；每步跑单测。
4. 静态断言无 `[NODE_CHUNK_` 字符串进 SSE 路径。

### Affected Modules

- `ktg-ai`：`AiChatServiceImpl`、`AiAgentServiceImpl`、工作流 run service、新增 runtime 类、测试
- 不改：`ktg-admin` 映射、Vue、`MesPermitAllProviderImpl`、62–65 Tool/MCP 语义

### Public Contracts

APIs, facades, DTOs, events, or database contracts:

- **冻结：** 三条 POST path 与既有 body/SSE（见 58/61/64）
- 内部 facade API 由实现定，不新增对外 HTTP

### Persistence Changes

Tables, indexes, migrations, mapper XML, and lifecycle rules:

- 无必须新表

### Transaction Boundaries

- user 消息先落库再流式；assistant 流结束落库（与 51 一致）
- workflow run 状态更新仍短事务

### Risks

- 重构导致 chat/agent SSE 行为漂移
- workflow 丢 `step` 字段
- 漏装饰异步线程导致空租户写库

### Verification Strategy

- `mvn -pl ktg-ai -am test`（实现后）
- 单测覆盖三入口 facade 调用与 SSE 帧
- 不跑 live 模型 / Vue
