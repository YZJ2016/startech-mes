### Business Goal

让工厂管理员配置本租户 Agent 档案（学 ruoyi `agent_info`，**不要** Supervisor）：模型、系统提示、绑定知识库、启用哪些 Tools、勾选哪些 MCP server。A24 工厂按档案组装 `modelId`、`systemPrompt`、`knowledgeIds`、`enabledTools`、`mcpServerIds`。**默认**不开启受控写与 MCP；`mcpServerIds` 仅为租户白名单子集，非全量挂载。

Goal：CRUD `/ai/agent/profile`；`agent/send` 可选 `agentId`；写 Tool / MCP 默认 OFF、按需 ON；未列出 Tool 不出现在模型 tool list；无 Supervisor。

### Scope

In scope:

- 表 `ai_agent`：`tenant_id`、`name`、`system_prompt`、`default_model_id`、`knowledge_ids`（JSON 数组）、`enabled_tools`（JSON 数组）、`mcp_server_ids`（JSON 数组）、状态、审计列
- HTTP **`/ai/agent/profile`**：列表/详情/新增/修改/删除；`code/msg/data`；权限如 `ai:agent:profile:*`
- 档案字段：`defaultModelId`、`systemPrompt`、`knowledgeIds`、`enabledTools`、`mcpServerIds`（与 A31 / 设计 07 §5.3 一致）
- `enabledTools` 枚举：`searchKnowledge` | `submitProductionFeedback` | `updateWorkorderStatus`（与 62 对齐；**不含** `mcp` 开关）
- `mcpServerIds`：本租户 MCP 白名单（63）server id 子集；非空时仅挂载列表内且通过 `AiMcpGuard` 的 server
- `knowledgeIds`：本租户 `ai_knowledge.id` 列表；`searchKnowledge` / RAG 路径仍复核 tenant 归属
- **默认 profile：** seed 时 `enabledTools` 为空或仅 `searchKnowledge`；`mcpServerIds` 为空；**不含**写 Tool
- 无 profile 或未传 `agentId`：写 Tool 与 MCP **均 OFF**（未传 `agentId` 时取 seed 默认 profile，其本身亦不含写/MCP）
- `POST /ai/agent/send` 可选 `agentId`；未传用租户默认 profile 全字段组装 Assistant
- AiService 构建时**按 profile 过滤** Tools；MCP 按 `mcpServerIds` 子集挂载（63 白名单 + guard 仍生效）
- include + 专库 catalog + 增量 SQL + 菜单/权限 seed（若需要）
- 单测：默认 profile 无写 Tool / 无 MCP；仅列出的 mcpServerIds 挂载；跨租户 agentId / knowledgeId / mcpServerId 404

Out of scope:

- Supervisor / 子 Agent / SQL Tool
- Vue3 profile 管理页（可后续单元）
- 改 chat/send path；独立 Agent 聊天页
- 真实地址、凭据

Non-goals:

- 不做「任意 Tool 名」配置
- 不默认开启 MCP / 受控写

### Acceptance Criteria

- 默认 profile（或无 profile / 未传 agentId）的 Agent 调用不含写 Tool / MCP
- 未列入 `enabledTools` 的写 Tool **不得**出现在 LangChain4j tool list
- `mcpServerIds` 非空时仅挂载列表内 server；未列 server 不得挂载
- `agentId` / `knowledgeIds` / `mcpServerIds` / `defaultModelId` 跨租户 → 404/403
- CRUD 仅本租户；列表/options 不回 MCP cipher（A20 对齐）
- `POST /ai/agent/send` SSE 与 61 冻结一致
- 第 4 节未编码前不得写「测试通过」

### Rules and Constraints

Tenant isolation:

- 只信 JWT；禁止 body `tenantId`
- `agentId` / `default_model_id` / `knowledgeIds` / `mcpServerIds` 须本租户；保存与发送路径均校验

Security and masking:

- 写 Tool 仍须 62 权限字；不因 profile 绕过
- MCP 配置列表不打明文（63 规则）

Audit and lineage:

- 新表 DDL + include + catalog

AI/rule-engine rules:

- A25 一份 Tool 单例；profile 只控制**挂载子集**（Tools + MCP server 列表）
- 禁止 Supervisor

Database rules:

- `ai_agent` 唯一键 `(tenant_id, name)` 或 `(tenant_id, id)`

## 2. Plan

### Implementation Approach

1. DDL `ai_agent` + include + catalog + 权限 seed。
2. CRUD Controller/Service。
3. Agent 发送路径：解析 agentId → 加载 profile → 校验 knowledgeIds/mcpServerIds 租户 → 按 enabledTools + mcpServerIds 过滤挂载 → 应用 systemPrompt + modelId。
4. 单测默认 OFF 与按需 ON。

### Affected Modules

- `ktg-ai`：domain、mapper、profile service、Agent 装配、测试
- SQL、include、catalog

### Public Contracts

APIs, facades, DTOs, events, or database contracts:

- `/ai/agent/profile` CRUD
- `POST /ai/agent/send` body 增加可选 `agentId`；其余与 61 一致
- Profile body / VO：`defaultModelId`、`systemPrompt`、`knowledgeIds`、`enabledTools`、`mcpServerIds`

### Persistence Changes

Tables, indexes, migrations, mapper XML, and lifecycle rules:

- `ai_agent`；增量 `YYYYMMDD_NN_ai_agent.sql`

### Transaction Boundaries

- profile CRUD 短事务
- Agent 发送：读 profile 无长事务

### Risks

- 默认误开写 Tool
- profile modelId 与他租户模型混淆

### Verification Strategy

- `mvn -pl ktg-ai -am test`
- Mock Tools / 权限
- 不跑 live MCP
