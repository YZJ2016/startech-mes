### Business Goal

工厂管理员在内嵌管理端维护本租户 Agent 档案：名称、系统提示、默认模型、绑定知识库、启用 Tools 子集、勾选 MCP server 子集、启停状态。配置生效于 `POST /ai/agent/send`（对话接线见 73）。

Goal：Vue3 可完成 profile CRUD；菜单 9107 可见且非死链；写 Tool / MCP 默认不勾；不引入新 UI 栈。

### Scope

In scope:

- API：`src/api/ai/agent.js` → `GET/POST/PUT/DELETE /ai/agent/profile`（风格对齐 `src/api/ai/mcp.js`）
- 页面：`src/views/ai/agent/index.vue`（组件路径 `ai/agent/index`）
  - 列表：分页、按名称查询、状态列、Tools/知识库/MCP 摘要（可选简洁展示）
  - 表单对话框：`name`、`systemPrompt`、`defaultModelId`、`knowledgeIds`、`enabledTools`、`mcpServerIds`、`status`、`remark`
  - `enabledTools` 仅三值：`searchKnowledge` | `submitProductionFeedback` | `updateWorkorderStatus`（可用中文标签）
  - 模型 / 知识库 / MCP 下拉或多选：消费既有 options 接口（本租户）；MCP **不展示** token / cipher
- 菜单：增量 SQL 将 `menu_id=9107` 的 `visible` 设为 `'0'`（显示）；不改写 `20260825_30_ai_agent_menu.sql` / `20260826_32_ai_agent_menu_hide.sql` 历史文件正文
- 按钮：`v-hasPermi` 对齐 `ai:agent:profile:list|query|add|edit|remove`
- 仅 Element Plus + 现有 Vue3 栈；axios 走 `request.js`

Out of scope:

- 独立 Agent 聊天 SPA / 新开聊天菜单（A36 / 73 只改既有 `/ai/chat`）
- 改 `/ai/agent/profile` Java 契约或加 Supervisor
- 改 Vue2；引入 `vue-element-plus-x`、UnoCSS、`hook-fetch`、Vben、TypeScript 工程形态
- 提交 lockfile；为局部需求升级 Vue / Vite / Element Plus
- Tool 审计列表页；health 页
- 真实地址、凭据写入前端 env

Non-goals:

- 不默认勾选写 Tool / MCP
- 不做「任意 Tool 名」自由输入
- 不在本页触发 SSE 对话

### Acceptance Criteria

- 有 `ai:agent:profile:*` 权限的用户可见菜单并可完成增删改查
- 保存体字段与 68 对齐；不传 `tenantId`
- 新建默认不勾写 Tool、不选 MCP；可选仅 `searchKnowledge`
- 详情/列表无 MCP 明文、无模型 apiKey
- `frontend/` git diff 为空；无新禁用依赖；`npm run build:prod` exit 0 后才写第 4 节通过
- 菜单 9107 对授权角色可见且路由到真实页面（非死链）

### Rules and Constraints

Tenant isolation:

- 不传客户端 `tenantId` 头或 body；跨租户 id 由后端 404/403，前端不猜测切租户

Security and masking:

- toast / 控制台不打印凭据、cipher、内部路径
- 不把 Key / MCP token 放进 `.env.*`

Audit and lineage:

- 菜单可见性用**新增量** SQL；不原地改历史 hide/seed 脚本

AI/rule-engine rules:

- profile 只配置挂载子集；写 Tool 仍须 MES 权限字（62），本页不冒充授权

Database rules:

- 无新业务表；仅可选 `sys_menu.visible` 更新
