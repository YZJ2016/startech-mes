### Scope

In scope:

- **tenant Flyway（Alt-B 默认）：** `wm_product_recpt.recpt_kind` varchar NOT NULL default `FINISHED`（或可空 + 回填后 NOT NULL）；既有行 **回填 `FINISHED`**；`PRODUCT_RECPT` Hub 臂 `AND (recpt_kind IS NULL OR recpt_kind = 'FINISHED')`（实现选一，须单测）；`SEMI_PRODUCT_RECPT` 臂 `AND recpt_kind = 'SEMI'`
- **（若产品改选 Alt-A）：** 新两表 + tenant include + **`qc_ipqc.recpt_doc_type`**（`PRODUCT_RECPT`/`SEMI_PRODUCT_RECPT`；存量默认成品）— 见 T0 停写条件
- **Hub 加法：** `GET /mes/wm/inboundhub/list` UNION **第七臂**；`receiptType=SEMI_PRODUCT_RECPT` 单臂筛选；未传类型默认 **七臂**；筛选省略未用臂（禁止 `AND 1=0`）
- **FQC 闸延伸（强制）：**
  - 真源仍 `qc_ipqc` + `ipqc_type=FQC`；合格仍 `ACCEPT` 且非 `PREPARE`；无 FQC 模板不挡
  - **复用** `mes.wm.inbound.fqc.gate.confirm` / `.execute`（默认 off/on 与 108 同；**禁止**新造第二套 FQC 键，除非产品明示隔离——本会话默认 **不隔离**）
  - 预览 GET：半成品抽屉可调闸预览（路径见附录 B）；执行 `PUT` 前 `requireExecute` 与 108 同规则
  - Binder：创建/更新 `ipqc_type=FQC` 时，`recpt_id` 只落本租户已加载、且 **`recpt_kind=SEMI`（Alt-B）或半成品头（Alt-A）** 的单据；不信客户端裸 ID
- **业务 CRUD：**
  - Alt-B：优先 **复用** `/mes/wm/productrecpt`（body/查询加法 `recptKind`）；Hub/菜单可筛半成品；可选薄页 `semiproductrecpt` 仅定死 `recptKind=SEMI` 调同一 API（**不**复制过账逻辑）
  - 状态机对齐现网产品入库（一步执行过账；无独立 confirm 步，除非编码时读 Controller 推翻）
  - 库存事务：默认仍走 **`processProductRecpt`**（同一 `PRODUCT_RECPT_IN/OUT`）；若产品要求独立事务类型，见 T0 开放项（默认 **不** 新事务常量）
- **Vue3 UI-A：** **仅** `inboundhub` 类型筛/抽屉分支（半成品头行 + FQC 预览 + 新建终检深链带 `recptId`）；**最小**旧 `productrecpt` 水合（查询默认排除 `SEMI`，避免旧页混单）或新建薄页；**不重排** 其他入库/退货/还料布局
- **master Flyway：** 可选菜单 **9370–9374**（半成品入库 CRUD）；**不占** 9300–9364；不自动 `sys_role_menu`
- **单测：** Hub 七臂 tenant rewrite；`SEMI_PRODUCT_RECPT` 单臂不含成品行；成品臂不含 `SEMI`；FQC Evaluator 复用；Binder 拒错种单据；outbound Hub **无** `SEMI_PRODUCT_RECPT`

### Acceptance Criteria

1. **编码门禁：** 用户在同一会话 **点名 121**；108 FQC 真源与 120 六臂 **不重开**其范围声明；持久化方案按 T0 锁定（默认 Alt-B）。
2. Hub：`mes:wm:inboundhub:list` 下可分页 **七类型**混合 list；`receiptType=SEMI_PRODUCT_RECPT` 仅半成品；`PRODUCT_RECPT` **不含** `recpt_kind=SEMI`（Alt-B）或半成品表行（Alt-A）。
3. 半成品执行：有 FQC 模板的行在 execute 闸 on 时未合格不得过账；无模板不挡；过程检验 FIRST/PATROL/FINAL 不当 FQC。
4. 闸匹配按 **`(qc_ipqc.recpt_id, item_id, ipqc_type=FQC)`**（Alt-A 另加 doc_type）；禁止只按 `itemId` 挂他单终检；`recpt_id` NULL 失败关闭（与 108 同）。
5. **`GET/PUT /mes/wm/productrecpt/**` 对成品路径 URL/method/`code/msg/data` 不变**（仅加法字段/默认过滤，禁止破坏成品契约）。
6. 出库 Hub / `OTHER_INBOUND` / 退货臂 **不出现** `SEMI_PRODUCT_RECPT`。
7. 无密钥进 yml/文档；Flyway 只进 `db/migration`；第 4 节未跑命令不得写绿。
8. 文档与代码不得把客供/委外/盘盈描述为本单元能力。
