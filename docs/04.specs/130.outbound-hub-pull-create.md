### Business Goal

仓管在出库 Hub 工具栏可 **从源单据拉单**：工单 **BOM 用料** → 生产领料 `ISSUE` 草稿；销售订单行 → 销售出库 `PRODUCT_SALSE` 草稿。服务端算剩余可拉量并生成草稿，禁止前端假分页拼单、禁止 Hub 改数量。拉单只建 `PREPARE`；过账仍走现网 PUT。**禁止**用工单成品行（那是入库 126 `work_order` → `PRODUCT_RECPT`）。

### Rules and Constraints

Tenant isolation:

- 无 `TenantContext` 不得访问租户表（工单、销售订单、领料、销售出库）
- SQL 永不跳过 `tenant_id`（含现网 `admin` / `user_id=1`）；`isAdmin()` 不得关拦截器
- 只信 JWT / `LoginUser`；禁止客户端租户头

Security and masking:

- 新路径 `@PreAuthorize`（目标 `add` 或组合）；不进 `MesPermitAllProvider`
- 日志 / toast / API 不打印凭据、cipher、内部路径；403/错误不泄漏他厂源单存在性

Audit and lineage:

- `@Log` 记拉单创建；无新业务头表
- 新 DDL 若有（本单元默认无）只进 Flyway `{master,tenant}`；不改 `backend/sql/`

AI/rule-engine rules:

- 拉单服务 **不得** 直连任意 SQL / AI；不进 `/ai/**`

Database rules:

- 只写入既有出库草稿表；不写 yml 业务开关；不拷快格包名/表名
- 可运行时项若日后需要走 `sys_config`，本单元 **不必须** 新键
