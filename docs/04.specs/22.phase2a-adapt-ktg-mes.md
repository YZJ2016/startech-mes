# Development Unit Template

Use this template before each implementation unit.

## 1. Spec

### Capability

- Name: 阶段 2a 适配 `ktg-mes`（jakarta、SpringDoc、UReport、Minio、WebSocket、FieldMeta）
- Module: `ktg-mes`（仅编译闭合与命名空间；不改 MES 业务语义）
- Priority: P0
- Related requirement/design documents:
  - `docs/04.specs/19.backend-shell-swap-phase2-program.md`
  - `docs/04.specs/21.phase2a-swap-platform-springboot3.md`（平台已换入 jakarta）
  - UReport 抽出：`07`；Minio：`04`；WebSocket/公告：`05`；FieldMeta 运行时：`10` 第 7 节第 3 条
  - 纯度：`09`（本单元不得把 mes 类型搬回平台）

### Business Goal

让 **MES 模块在 JDK 17 + Boot 3.5.16 + jakarta 平台上编译通过**，并尽量保持现有 URL 与行为。不能假设 721 个文件「平台换完就自动过」。第三方（尤其 UReport）兼容性未知的，**先编再记，不要猜 fork、不要猜必须换实现**。

### Scope

In scope:

- 对照：无上游 `ruoyi-mes`。行为对照是阶段 1 收口后的 nested `ktg-mes`，栈对照是 springboot3 平台 API
- 机械替换 mes 源码中的 EE 包（实测规模，2026-08-20，在 `startech-mes-basic/backend`）：
  - `javax.servlet`：约 **124** 个 Java 文件 → `jakarta.servlet`
  - `javax.annotation`：约 **23** 个文件 → `jakarta.annotation`（`javax.sql.DataSource` **保持**）
  - `javax.websocket`：约 **2** 个文件（`WebSocketServer` 等）→ `jakarta.websocket`
  - 合计命中 `javax.(servlet|annotation|validation|persistence)` 约 **140** 文件；以实施时 `rg` 为准，不要只改示例几个 Controller
- Springfox / Swagger 1.x → 若依所用 **SpringDoc / `io.swagger.v3.oas.annotations`**：
  - 平台已去掉 `springfox-boot-starter`（`20`/`21`）
  - mes 约 **10** 个文件使用 `io.swagger.annotations.*`；另有 `ProWorkorder` 使用 `io.swagger.models.auth.In`（像误 import，**先编，按编译器错误改，不要猜业务含义**）
  - `ktg-mes/pom.xml` 的 `io.swagger:swagger-models:1.6.2` 在编不过时删除或改为 OAS3 坐标；不要为了「文档还能扫到 mes API」去新建一套 Swagger 配置
- 编译闭合所必需的 pom 调整（版本以 **实际编译错误** 为准，写进第 4 节）：Minio、UReport、WebSocket starter 传递依赖、MyBatis 拦截器 API
- 下列热点 **必须点名处理或记录失败**，禁止跳过装「mes 自动能编」：
  1. `com.ktg.mes.report.config.UReportConfig`：`UReportServlet` + `ServletRegistrationBean` + `@ImportResource("classpath:ureport-console-context.xml")`；现依赖 `ureport2-console:2.2.9`（javax 时代产物）
  2. `MesMinioUploadController` / `io.minio:minio:8.2.1`
  3. `WebSocketServer` `@ServerEndpoint("/websocket/message/{token}")` + `WebSocketConfig` 的 `ServerEndpointExporter`
  4. `FieldMetaObjectHandler`：MyBatis `Interceptor` + `@Intercepts` + `Plugin.wrap`（不是 Spring MVC 拦截器）
- 保留：`MesPermitAllProviderImpl` 路径数组原文；`GET /system/notice/list`；`POST /common/uploadMinio`；admin 依赖关系

Out of scope:

- 改工单/库存/质检状态机，改 URL，改已读模型
- 把 FieldMeta、UReport、Minio、WebSocket **搬回** admin/common/framework（纯度回潮）
- 为 UReport 换产品或手写替代设计器（除非编译证明 2.2.9 无法在 jakarta 下解析 **且** 产品另批替代方案）
- 升级全部 mes 第三方「顺便到最新」（Jasper 6.18.1、EasyExcel 3.1.2、hutool、PDFBox、阿里 OSS：无错误则不动）
- Boot 4.1（`24`）
- 前端 Vue3
- 运行时连真实 Minio/库（记入 `26` 未验证）

### Acceptance Criteria

- `rg "javax\\.servlet|javax\\.websocket|javax\\.annotation\\.Resource" backend/ktg-mes/src --glob "*.java"` 为 0
- `rg "io\\.swagger\\.annotations|springfox" backend/ktg-mes/src --glob "*.java"` 为 0（若留下 `io.swagger.v3` 则允许）
- `mvn -pl ktg-admin -am compiler:compile "-DskipTests" "-Dmaven.antrun.skip=true"` 在 **JDK 17** 下 BUILD SUCCESS（含 `ktg-mes`）
- 纯度：`FieldMetaObjectHandler`、`UReportConfig`、`WebSocketServer`、`MesMinioUploadController`、`MesPermitAllProviderImpl` 仍只在 `ktg-mes`
- 路径契约未改
- 未知依赖若编译失败：第 4 节写 **完整坐标 + 首个错误类型**，标 `[ ]` 开放；**禁止**在文档里写「应已兼容」却无 SUCCESS

### Rules and Constraints

Tenant isolation:

- FieldMeta 仍只填 `BaseEntity` 的创建人/时间，不引入租户列

Security and masking:

- 不在日志或文档打印 Minio/OSS 密钥、Token
- 不扩大 `MesPermitAllProviderImpl` 匿名面

Audit and lineage:

- 不改 `ureport_file_tbl` 结构；不改 Minio 对象键规则

AI/rule-engine rules:

- 不涉及

Database rules:

- 不改 MES 业务表；FieldMeta 只动插入/更新时的内存字段

## 2. Plan

### Implementation Approach

1. 确认 `21` 平台六模块已换入；对照平台 hash 仍是 springboot3 锁定值
2. 先做 **无争议机械替换**（servlet/annotation/websocket 包名），再编
3. 按编译错误处理 Swagger 注解：优先 `io.swagger.annotations.Api` → `io.swagger.v3.oas.annotations.tags.Tag` 等 **对照 admin `TestController` 已用的 OAS3 注解**；一对一替换即可，不要补写缺失的 description
4. 再编。第三方错误分类：

| 热点 | 现状（nested） | 策略 |
| ---- | -------------- | ---- |
| jakarta servlet | 124 文件 javax | 机械替换；`ServletRegistrationBean` 跟 Spring Boot 3 API |
| Springfox | 10 文件 + pom `swagger-models` | 改 OAS3 注解；去掉对 springfox 的编译依赖 |
| UReport | `ureport2-console:2.2.9`，`UReportConfig` 引用 `com.bstek.ureport.console.UReportServlet` | **先编**。若报 `javax.servlet` 在 ureport jar 内：记录为已知缺口，**不要**在本单元猜换 fork / 换 Jasper 顶替。产品要替代方案时另开 spec |
| Minio | `io.minio:minio:8.2.1` | 先编。只在 API 编译错误时升 patch/minor，不无故跳大版本 |
| WebSocket | `javax.websocket.*` + `ServerEndpointExporter` | 改 jakarta 包；确认 `spring-boot-starter-websocket` 由 framework/admin 传递。Exporter 类找不到再补依赖 |
| FieldMeta | MyBatis `Interceptor`，`mybatis-spring-boot` 2a 为 **3.0.5** | 先编。若 `Plugin.wrap` / `@Intercepts` 签名变了，按编译器改 **最小** 实现，不改填充语义（createTime/createBy；updateTime 仍按现网注释掉的逻辑） |
| fastjson1 | 若干 mes 类仍 `com.alibaba.fastjson` | **只保 pom**，本单元不迁 fastjson2，除非类在 jakarta 替换后无法解析 |

5. 不要修改 `MesPermitAllProviderImpl` 字符串表去「适应 PathPattern」——那是 `23`/`26` 有环境再探测
6. 覆盖前 `git status`，不要夹带无关格式化

### Affected Modules

- 必改：`ktg-mes` src + 其 `pom.xml`（仅编译所需）
- 禁止改：四平台模块再塞 mes 类型；`frontend/`

### Public Contracts

- HTTP 路径不变
- WebSocket 路径仍 `/websocket/message/{token}`
- UReport 控制台仍 `/ureport/*`；业务 `/ureportM` 仍 mes

### Persistence Changes

- 无

### Transaction Boundaries

### Risks

- 假装 mes 不用改
- 为 UReport 猜一个 github fork 写进主仓
- 把 140 个文件的 jakarta 替换做成业务重构
- `ProWorkorder` 的 `io.swagger.models.auth.In` 被改成错误类型导致领域字段损坏——**只根据编译错误改 import**
- MyBatis 3 插件注册方式变化导致 FieldMeta 静默不生效（编译过但运行时不填）：列入 `26` 未验证，不要在无环境时声称已测
