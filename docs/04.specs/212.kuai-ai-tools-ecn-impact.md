# KU-AI 场景 Tool：ECN/ECR 变更影响分析

从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：待实施；§1 决策已于 2026-10-23 选定。

## 1. Spec

### Capability

- Name: 新增只读 Tool `query_ecn`、`analyze_ecn_impact`、`query_material_where_used`。
- Module: `riveredge-backend/src/apps/kuaiai/services`（tools 适配层）、manifest `ai_tools`。
- Priority: P2（S23 ECN 影响分析；`query_material_where_used` 同时服务 S24）。
- Related requirement/design documents: 需求 25 SC-D1、SC-D5、SC-D7；设计 26 §4、§5.2；前置 spec 189、190；kuaiplm 为可选应用。

### Business Goal

工艺/计划问“ECN-2024-058 影响哪些在制工单和库存物料”“这个物料被哪些 BOM 和工艺引用”，助手基于 kuaiplm 变更记录与 master_data 反查给出影响面清单。

### Scope

In scope:

| Tool | 参数 | 底层 service | 权限码 |
| --- | --- | --- | --- |
| `query_ecn` | `keyword?`、`status?`、`date_start?`、`date_end?`、`limit≤20` | kuaiplm ECN 列表 service（T1 核对类名/签名） | `kuaiplm:ecn:read` |
| `analyze_ecn_impact` | `ecn_id`（必填） | kuaiplm ECN 影响/关联 service + master_data 反查（T1 核对 kuaiplm 是否已有影响分析接口） | `kuaiplm:ecn:read`（若需跨权限见 X4） |
| `query_material_where_used` | `material_id`（必填）、`view=bom\|process\|drawing`（按权限可得的视图过滤） | master_data BOM/工艺反查 service（T1 核对） | `master-data:process:drawing-where-used:read` 与 `master-data:process:engineering-bom:read` 为不同权限码，见 X4 |

- kuaiplm 未安装时：`query_ecn`、`analyze_ecn_impact` 在 manifest 中须声明依赖应用（T1 核对 manifest 是否支持 `requires_app` 字段；不支持则 Tool 调用时返回固定文案“PLM 应用未启用”而非错误）。
- 源单 by-ID 先做数据范围复核。

Out of scope:

- 创建/审批/下发 ECN（写操作）。
- 文档/图纸正文内容检索。

### 决策（2026-10-23 已选定）

选定：**X4=a** —— where-used 拆为 `query_material_where_used`（BOM）与 `query_drawing_where_used`（图纸）两个 Tool，各挂一个权限码（SC-D7）。

| 编号 | 场景 | 选项 | 推荐与理由 |
| --- | --- | --- | --- |
| X4 | `query_material_where_used` 的 BOM 反查用 `engineering-bom:read`，图纸反查用 `drawing-where-used:read`，是两个权限码。工艺工程师通常两者都有；仓库管理员可能只有 BOM 权限 | a. 拆两个 Tool（`query_material_where_used` 仅 BOM、`query_drawing_where_used` 仅图纸），一 Tool 一权限；b. 一个 Tool、视图按当前用户权限动态裁剪，权限挂 BOM 读权限 | **a**：SC-D7 一 Tool 一权限码；b 的“挂一个权限、放行另一权限的视图”违反该原则 |

### Acceptance Criteria

1. `query_ecn` 输出 ECN 编号、标题、状态、涉及物料数、创建/生效时间。
2. `analyze_ecn_impact` 输出受影响的在制工单、库存批次、BOM/工艺引用清单（各自计数 + 前 N 条），均来自真实关联数据；无关联时如实输出。
3. kuaiplm 未安装时返回固定文案，不报错、不返回空列表伪装成“无数据”。
4. X4=a 时三个 Tool 各自登记权限码。

### Rules and Constraints

Tenant isolation:

- 传 `ctx.tenant_id`；kuaiplm 与 kuaizhizao 跨应用调用只传 tenant_id 与已判权后的参数。

Security and masking:

- ECN 内容可能含未发布设计：输出限于编号、标题、状态与影响清单，不输出变更前后明细全文。

Audit and lineage:

- 沿用 Tool 级审计。

AI/rule-engine rules:

- 影响面来自关联数据（SC-D5）；建议话术由 LLM 生成但不得新增事实。

Database rules:

- 无表结构变更。

### 场景模板（Y3=a）

本单元交付时同步登记场景模板 `ecn-impact`（工程变更助手）：预置档案 `enabled_tools` 为本单元 Tool 集合，停用 + 空授权（Y4=a）；模板 key 即能力矩阵场景卡，默认绑定同 key 预置实例（spec 191，Y1/Y2=a）。system_prompt 只引用本单元 Tool，插画按 spec 201 T2 约定。
