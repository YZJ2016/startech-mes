从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：待实施。

## 1. Spec

### Capability

- Name: 新增只读 Tool `query_stocktakings`、`analyze_stocktaking_variance`。
- Module: `riveredge-backend/src/apps/kuaiai/services`（tools 适配层）、manifest `ai_tools`。
- Priority: P3（S22 盘点差异解读）。
- Related requirement/design documents: 需求 25 SC-D1、SC-D5、SC-D7；设计 26 §4、§5.2；前置 spec 189、190、196（库存 Tool）。

### Business Goal

仓库主管问“这次盘点差异有哪些、主要是哪些物料差”“历史盘点差异率高的是哪些库位”，助手基于盘点单与盘点历史报表回答差异构成，并给出排查方向话术（引用真实出入库记录）。

### Scope

In scope:

| Tool | 参数 | 底层 service | 权限码 |
| --- | --- | --- | --- |
| `query_stocktakings` | `keyword?`、`status?`、`warehouse_id?`、`date_start?`、`date_end?`、`limit≤20` | `StocktakingService.list_stocktakings`（已核实存在） | `kuaizhizao:warehouse-management-stocktaking:read` |
| `analyze_stocktaking_variance` | `stocktaking_id`（必填）或 `view=history` + `date_start?`/`date_end?` | 盘点明细差异 + 盘点历史报表 service（T1 核对方法名） | `kuaizhizao:warehouse-management-reports-stocktaking-history:read`（T1 核对明细与历史是否同权限码；不同则拆 Tool） |

- `analyze_stocktaking_variance`（按单）：输出账存/实盘/差异数量金额 TopN 物料、差异率、按物料类别聚合；判定由 service/确定性聚合完成（SC-D5），LLM 只负责解释与排查建议话术。
- `view=history`：输出各盘点单差异率趋势与库位汇总。
- 差异口径（数量差/金额差、盘盈盘亏）T1 从 service 返回字段定，输出标注口径。

Out of scope:

- 创建盘点单、录入盘点数、盘盈盘亏过账（写操作）。

### Acceptance Criteria

1. `query_stocktakings` 输出盘点单号、仓库、范围、状态、时间。
2. `analyze_stocktaking_variance` 输出差异 TopN（物料、账存、实盘、差异、差异率）与汇总，数值与明细一致可复算。
3. 无差异时如实输出“账实一致”；权限/范围外按不存在回复。
4. 两个 Tool 登记于 manifest（`label`、`kind=read`）。

### Rules and Constraints

Tenant isolation:

- 传 `ctx.tenant_id`。

Security and masking:

- 差异金额可见（盘点业务需要），不输出操作员个人信息。

Audit and lineage:

- 沿用 Tool 级审计；`route` 业务键记录盘点单号。

AI/rule-engine rules:

- 差异数值与归类来自业务数据与确定性聚合；排查建议为话术，不得新增事实（SC-D5）。

Database rules:

- 无表结构变更。

### 场景模板（Y3=a）

本单元交付时同步登记场景模板 `stocktaking`（盘点分析助手）：预置档案 `enabled_tools` 为本单元 Tool 集合，停用 + 空授权（Y4=a）；模板 key 即能力矩阵场景卡，默认绑定同 key 预置实例（spec 191，Y1/Y2=a）。system_prompt 只引用本单元 Tool，插画按 spec 201 T2 约定。
