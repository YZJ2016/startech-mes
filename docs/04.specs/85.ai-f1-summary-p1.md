- Related requirement/design documents:

  - 只读包装红线：`docs/04.specs/83.ai-workshop-demo-read-tools.md`（A7；本单元是发送前拼句，**不是**新 Tool）

### Business Goal

抽屉提问时，后端按当前单的 `resourceKey + recordId` 补一段**只读**短摘要（状态、数量；**本期无缺料句**，见 **S-G1**），工作台 AI 卡打开**同一抽屉**并预填固定问题。`/` 只开菜单搜索，F1 只开助手；输入框里的 `/` 仍是字符。

### Scope

In scope:

- `ktg-ai` 发送 prepare（chat 与 agent 共用）：若 `context.resourceKey` 与 `recordId` 齐全，白名单路由到现有 MES **service**（第一批 `mes.pro.workorder` → `IProWorkorderService` 按 `workorderId`）
- 摘要字段白名单：**状态、数量**。缺料句**本期不做**（S-G1）。禁止整单 JSON、禁止新 KPI 接口
- 复核业务权限（工单：现网 list/query 字，至少 `mes:pro:workorder:list`）。无权限 / 未知 key / 跨租户：不加摘要，**不阻断**对话、不 500
- 摘要短段接在 P0 标签句之后，限长（建议 ≤ 500 字）
- `FactoryHome.vue` AI 卡：有 `ai:chat:list` 时 `dispatchEvent(new CustomEvent('mes-ai-assistant-open', { detail: { preset: '帮我看看当前工作台的待办和工单' } }))`，**不再** `router.push('/ai/chat')`，**不回退**
- 布局监听 `mes-ai-assistant-open`：打开 84 的同一抽屉，把 `preset` 写入输入框，**不自动发送**
- HeaderSearch：焦点不在 input / textarea / contenteditable / Element 输入时，`/` 打开搜索并 `preventDefault`；上述控件内 `/` 保持字符。F1 逻辑仍只认 F1（84 已锁）

Out of scope:

- 重做 84 的 F1 / Drawer / `aiContext` / 可选 `context` 字段（只消费）
- 写库 Agent、`confirmToken`、受控写 Tool、SQL / JDBC、任意 Mapper
- 新 HTTP path（**不**做 `GET /ai/context/summary`）
- 新造缺料/齐套算法；把摘要做成 LangChain4j `@Tool`（83 已有只读 Tools，不要重复）
- 改 Vue2；平台回家嵌 AI；扫全站第二批 `resourceKey`
- 改对话 URL / SSE 信封；把 `/ai/**` 写入 `MesPermitAllProvider`

### Acceptance Criteria

- 工单详情已写入 `resourceKey+recordId` 且用户有工单 list/query：发送后模型侧 system（或等价）含状态、数量短句，**不含**缺料/齐套句；响应/SSE **不含**整单 JSON
- 无工单权限：对话仍成功，system **无**该单业务字段
- 未知 `resourceKey`：同「无摘要」
- 跨租户 `recordId`：无他厂字段
- 工作台点「AI 对话」：当前页**不**跳到 `/ai/chat`，抽屉打开且输入框为 `帮我看看当前工作台的待办和工单`，未自动出现 user/assistant 新消息
- 非输入焦点按 `/`：HeaderSearch 打开；按 F1：抽屉打开，HeaderSearch 不因此打开
- 输入框（含抽屉 textarea、工单查询框）内按 `/`：只插入 `/`，两弹层都不开
- 无 `ai:chat:list`：工作台仍无 AI 卡（现网）；F1 仍不拦截（84）
- `ktg-ai` 单测 Mock MES service；`npm run build:prod` 实跑后写入第 4 节
- 文档无密钥、无生产地址

### Rules and Constraints

Tenant isolation:

- 只信 JWT / `TenantContext`；`context` 禁止 `tenantId`
- 工单必须经现有 service + 行级拦截器再读；空上下文不得调 MES

Security and masking:

- `/ai/**` 必须登录；不进 `MesPermitAllProvider`
- 摘要路径复核业务权限字，禁止「有 AI 许可即可读任意工单」
- 日志只记 tenantId / userId / resourceKey / recordId；禁止 apiKey、cipher、JDBC、整单 dump

Audit and lineage:

- 无新表亦可；若要记摘要命中，不得落密钥或整单
- 不改历史 Flyway / 菜单脚本

AI/rule-engine rules:

- 摘要是服务端拼句，不是模型 SQL
- 不替换档案 `systemPrompt`；接在 P0 标签句后
- 不把 P1 做成新 `@Tool` 以免与 83 双通道打架（档案 Tool 仍按 A31 勾选）

Database rules:

- 禁止为本单元新增查询 SQL / 新 Mapper
- 不把摘要开关写入 yml；若以后要关，走 `sys_config`（本期不做该键）

## 2. Plan

### Implementation Approach

- 后端：`AiContextSummaryService`（名可微调）`Optional<String> summarize(MesAiContext)`；switch `resourceKey`；工单调 `IProWorkorderService` 已有按 id 查询。`ktg-ai` 已能依赖 MES service 的方式对齐 62/83（不要新 DataSource）
- 拼句模板示例（实现可微调，不得加未授权字段）：`工单 {code} 状态 {status}，数量 {qty}`。**不加**缺料短句（S-G1）
- 前端：`FactoryHome` 点击改事件；layout 已有抽屉则 `addEventListener('mes-ai-assistant-open', …)`
- `/`：优先写在 `HeaderSearch/index.vue` 的 `onMounted`/`onUnmounted` 全局 keydown，与 84 的 F1 监听分开，避免一个 handler 处理两种键导致互抢

### Affected Modules

- 可改：`backend/ktg-ai` 发送 prepare、新 summary 类、单测；必要时 `ktg-ai/pom` 已有的 mes 依赖（不新开模块）
- 可改：`startech-mes-front/src/views/dashboard/FactoryHome.vue`、`src/components/HeaderSearch/index.vue`、84 的 Drawer/layout 监听
- 不可改：`frontend/`、对话 path、`MesPermitAllProvider`、首页其它卡片权限逻辑

### Public Contracts

APIs, facades, DTOs, events, or database contracts:

- HTTP：仍只是 84 的可选 `context`；**无**新 URL
- 事件：`mes-ai-assistant-open`，`detail.preset?: string`
- `resourceKey` 第一批冻结：`mes.pro.workorder`
- 权限：AI 仍 `ai:chat:list` / `ai:chat:send`；工单摘要另核 MES 字

### Persistence Changes

Tables, indexes, migrations, mapper XML, and lifecycle rules:

- 无（禁止新业务查询 XML）

### Transaction Boundaries

- 摘要只读，不包进 Agent 循环大事务；失败不影响已落 user 消息的现网策略

### Risks

- 把整单 toString 进 prompt 撑爆上下文或泄密
- 只核 AI 许可、不核工单权限
- `dispatchEvent` 在抽屉未挂载时空操作：依赖 84 先落地；壳监听须先 `open` 再填，**禁止**回退 `/ai/chat`
- `/` 全局 preventDefault 导致输入框无法输入斜杠
- 新造缺料计算，与 H-D5 冲突
- 把摘要做成 Tool，与 83 重复且改变默认档案行为

### Verification Strategy

- 后端单测：有权限工单 → 摘要含状态/数量；无权限 / 错租户 / 未知 key → empty
- 前端：工作台点击开抽屉+预填；`/` 与 F1 分工；输入框 `/` 不弹层
- `build:prod` + `mvn -pl ktg-ai -am test` 实跑
- 未实跑不得写通过
