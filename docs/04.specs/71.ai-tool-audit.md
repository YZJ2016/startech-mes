### Business Goal

统一记录每次 Tool 调用（受控写、MCP、知识检索、工作流节点），便于运营追溯与用量统计，且日志与落库均不含密钥。

Goal：审计含 user/tenant/tool/businessKey/latency/tokens；无 apiKey/cipher；不用 `ruoyi-common-trace`。

### Scope

In scope:

- 表 `ai_tool_audit`（名可微调）：`tenant_id`、`user_id`、`tool_name`、`business_key`（nullable）、`latency_ms`、`prompt_tokens`、`completion_tokens`、`status`（success/fail）、`error_summary`（nullable，无密钥）、`create_time`
- 钩子：包装 61–70 已注册 Tool 执行、63 MCP connector、64/70 workflow executor 节点
- 记录时机：调用前记开始，完成后写 latency；token 若上游返回则记，否则 nullable
- **禁止**写入：apiKey、MCP cipher、Authorization、完整 SQL、请求/响应原文（可存 businessKey 如 workorderId）
- include + 专库 catalog + 增量 SQL
- 单测：Mock Tool；断言审计行字段；日志 appender 不含 `sk-` 类夹具（若项目有 log 测试）

Out of scope:

- `ruoyi-common-trace`、OpenTelemetry 第二套链路
- Vue3 审计页（可后续）
- 计费扣费钱包
- 改 Tool 业务语义
- 真实凭据

Non-goals:

- 不做全链路 HTTP trace
- 审计表不存密钥

### Acceptance Criteria

- 受控写 / MCP / searchKnowledge / workflow 步执行后均有审计行（成功或 fail）
- 审计行与日志无 apiKey、cipher、MCP token
- 跨租户 Tool 参数失败时仍有 fail 审计（不含他租户 businessKey 详情泄露）
- 第 4 节未编码前不得写「测试通过」

### Rules and Constraints

Tenant isolation:

- 审计 insert 须当前 `tenant_id` / `user_id`
- 查询 API 若做须仅本租户（首期可无查询 HTTP）

Security and masking:

- I-A8 字段白名单
- 异常 message 对前端脱敏（I-A5）

Audit and lineage:

- 增量 SQL；不改历史脚本

AI/rule-engine rules:

- 钩子不得改变 Tool 权限语义（62/63）
- 异步审计须拷贝 TenantContext 或同步写（避免空租户）

Database rules:

- `ai_tool_audit.tenant_id NOT NULL`；索引 `(tenant_id, create_time)`

## 2. Plan

### Implementation Approach

1. DDL `ai_tool_audit` + include + catalog。
2. 实现 `ToolAuditAspect` 或 executor 装饰器（统一入口）。
3. 接到各 Tool / MCP / workflow 执行路径。
4. 单测成功/fail、latency、无密钥字段。

### Affected Modules

- `ktg-ai`：audit domain、mapper、aspect/decorator、测试
- 轻触：62/63 Tool 类、workflow executor（仅加审计调用）

### Public Contracts

APIs, facades, DTOs, events, or database contracts:

- 首期**可无**对外 HTTP；若加 `GET /ai/tool/audit/list` 须另在 spec 冻结权限
- 内部审计 DTO 字段见 Scope

### Persistence Changes

Tables, indexes, migrations, mapper XML, and lifecycle rules:

- `ai_tool_audit`；`YYYYMMDD_NN_ai_tool_audit.sql`

### Transaction Boundaries

- 审计写与 Tool 业务写**分离**短事务；Tool 失败仍写 fail 审计
- 禁止 audit 失败回滚业务（可 log warn）

### Risks

- 钩子遗漏某 Tool 路径
- 异步丢 TenantContext 写错 tenant_id
- 误把 MCP 配置写入 audit

### Verification Strategy

- `mvn -pl ktg-ai -am test`
- 不跑 live MCP/写 MES
