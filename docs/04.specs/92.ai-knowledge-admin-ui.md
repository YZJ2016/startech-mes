### Business Goal

工厂管理员在现网 `/ai/knowledge` 能：**显式选择**本厂 embedding 模型（空则仍用后端「第一条启用 vector」）；在同一对话框填写切块 size / overlap（及已有 topK / minScore / 分隔符，空则系统默认）；在附件旁**只读浏览**已切片段；本单元第 4 节用浏览器把「建库 → 上传 → 解析 → 看切块」走通，或写明环境不足未点选。

### Scope

In scope:

- 知识库新增/修改对话框：`embeddingModelId` 下拉。数据源现网 `GET /ai/model/options`（`listModelOptions`），**前端过滤** `category === 'vector'`（或 `vector` 等价）。空选项文案：「空则用本厂第一条启用的 vector 模型」。提交空/清选择 = JSON `null` 或不传，对齐后端空则回落。VO **不回显** apiKey / cipher。
- **同一对话框切块/检索字段（PR-D19）：** 保留现网 `topK` / `minScore` / `chunkSeparator`；**新增** `chunkSize`、`chunkOverlap`（`el-input-number`，可空）。placeholder 一律说明「空则用系统默认」（参数设置 `ai.rag.*`，**不是** yml / `AI_RAG_*`）。提交规则与现网 topK 相同：空则不传/传 null，不覆盖。
- **校验（两字段都填时）：** `chunkOverlap > 0` 且 `chunkOverlap < chunkSize`（对齐 `AiKnowledgeChunker`：overlap≤0 非法；overlap≥size 后端夹到 `size-1`）。只填一项时：overlap 若填则须 > 0；size 若填则须 ≥ 2。不必在前端读 `sys_config` 展示数字。
- 权限：下拉失败或无 `ai:model:list|ai:chat:list` 时选项为空，**不**新开匿名 options、**不**改 `MesPermitAllProvider`。保存知识库仍 `ai:knowledge:add|edit`。
- 片段浏览：附件对话框（或同页只读抽屉）调现网 `GET /ai/knowledge/{id}/fragments`（`ai:knowledge:query`，后端已 `startPage`）。`src/api/ai/knowledge.js` 增 `listKnowledgeFragments`。列：序号 `chunkIndex`、正文（可展开）、可选 `source_ref`。只读，无编辑/删除片段按钮。
- 解析失败行展示现网 `parse_msg`（PR-F2）。
- 浏览器点选（有已登录 Vue3 + 后端时必做并记第 4 节）：新建知识库 →（可选）选 vector 模型 →（可选）填切块参数 → 上传 `.txt` 或 `.md` → 点解析 → 状态成功或失败可见 → 打开片段列表能看到至少一块正文。无会话则第 4 节写「未点选」，**不得**写成通过。
- `npm run build:prod`（有前端改动）

Out of scope:

- 新 HTTP path、改 parse / fragments 契约、改 fragment 可写
- 改 `POST /ai/chat/send` / `POST /ai/agent/send`
- Flyway 列与 `sys_config` 种子、拆除 yml rag（**90**）；检索 Augmentor（**91**）
- 向量集群 type / Weaviate host / DashVector endpoint / 向量 API Key（**93** 平台默认页与租户表单绑定；**禁止**进本对话框，工厂不可自改指向）
- 对话页、Agent 页
- 浏览器测 live Weaviate / 真实 PDF（可记为未验；txt 足够本单元点选）
- 改 Vue2、引入 x/UnoCSS/hook-fetch、提交 lockfile

### Acceptance Criteria

- 表单能绑 `embeddingModelId`；空保存后解析仍走后端回落（不在本单元改 Java）
- 表单能绑 `chunkSize` / `chunkOverlap` / `topK` / `minScore` / `chunkSeparator`；空保存 = 不覆盖（回落属 90/91 的 `sys_config`）。两字段都填时 overlap 非法则拦提交
- 片段列表只打 `GET .../fragments`，跨租户仍 404（后端已有，前端不传 `tenantId`）
- 第 4 节区分：`build:prod` / 浏览器点选；未点选不得写 UI 已验收
- 文档无真实主机/凭据/账号口令

### Rules and Constraints

Tenant isolation:

- 不传客户端租户头；options / fragments 只信 JWT

Security and masking:

- 模型下拉无 Key；片段正文是本厂知识，日志不打对象存储凭据

Audit and lineage:

- 无新表。`chunk_size` / `chunk_overlap` 列由 **90** Flyway tenant；本单元不写 SQL

AI/rule-engine rules:

- 不在本页触发检索 Augmentor

Database rules:

- 本单元不写 Flyway；不改 `backend/sql/` 历史脚本

## 2. Plan

### Implementation Approach

1. API：`listKnowledgeFragments(knowledgeId, query)` → `GET /ai/knowledge/{id}/fragments`。
2. 表单：`el-select` 可清空，绑 `form.embeddingModelId`；options 来自 `listModelOptions` 过滤 vector。
3. 同对话框：`form.chunkSize` / `form.chunkOverlap`（可空 number）；保留 topK / minScore / chunkSeparator；提交 payload 与现网 optionalNumber 相同。
4. 附件区加「片段」入口，分页表格只读。
5. 有环境则按 Acceptance 点选；无则据实记录。

### Affected Modules

- `startech-mes-front/src/api/ai/knowledge.js`
- `startech-mes-front/src/views/ai/knowledge/index.vue`

### Public Contracts

- **冻结：** `GET /ai/knowledge/{id}/fragments`、`GET /ai/model/options`；知识库 PUT/POST 已有 `embeddingModelId` / `topK` / `minScore` / `chunkSeparator`
- 增量可选 JSON：`chunkSize` / `chunkOverlap`（不新 path）。列未落地前（90）不得声称已落库
- 不新增 path；不改 parse / chat/send

### Persistence Changes

- 无本单元 SQL。保存 `chunkSize` / `chunkOverlap` 依赖 90 的列与 Mapper

### Transaction Boundaries

- 无（只读列表 + 既有 CRUD）

### Risks

- 知识库编辑权限无模型 options 权限 → 下拉空，管理员不知回落规则（用 placeholder 说明）
- 片段 `mediumtext` 撑爆表格（单元格截断 + 展开）
- 与 90 并行：后端尚未加列时多传 JSON 字段可能被忽略；点选验收以 90 列落地后为准，txt 路径仍可测下拉/片段

### Verification Strategy

- `npm run build:prod`
- 浏览器点选路径见 Scope；无环境写第 4 节缺口
- 不改 Java 则不必为了本单元跑全量 `mvn test`
