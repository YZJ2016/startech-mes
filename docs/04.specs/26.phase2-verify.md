## 1. Spec

### Capability

- Name: 换壳阶段 2 全量门禁（JDK 17 编译、五项回归、未验证运行时）
- Module: `startech-mes-basic/backend` 聚合
- Priority: P0
- Related requirement/design documents:
  - `docs/04.specs/19.backend-shell-swap-phase2-program.md`
  - 2a：`20`–`23`；2b：`24`；可选：`25`（默认跳过）
  - 阶段 1 门禁形态对齐：`18`（栈换成 JDK 17；**不要**把阶段 1 抽出项再列为未做）

### Business Goal

在 2a 或 2b 代码落地后，做一次 **可重复的静态门禁**：JDK 17 聚合编译、纯度未回潮、五项在新 Security API 上齐全。运行时单独列为未验证，避免把「编过」写成「测过」。2a 与 2b 各做一次本文件第 4 节（或分段记录），不要用 Boot 3 的 SUCCESS 冒充 Boot 4。

### Scope

In scope:

- `java -version` 为 17
- 对照 hash：2a 段必须仍能说明平台内容来自 `9e3fb55f46d9998c6cecefd04fcf55c5d17158af`；2b 段来自 `a6ea55ecf74ae6cdb063f2b413d66a33f29bf828`
- 聚合 `mvn -pl ktg-admin -am compiler:compile "-DskipTests" "-Dmaven.antrun.skip=true"`
- 纯度回归（清单对齐 `09` / `18`，阶段 2 不得回潮）
- 五项勾选（对齐 `19` / `23`；2b 后再勾一次）
- 确认默认未执行 `25`：模块名 `ktg-*`、包名 `com.ktg`；`ktg-mes` 仍在 `<modules>`
- 记录运行时未验证清单（条数不减少）

Out of scope:

- 本单元内再换一块模块或升 Boot
- 前端 Vue3 / `RuoYi-Vue3-front`
- 执行 `25` 改名
- 启动应用、连真实库/Minio（若有人做了，把命令摘要写入第 4 节，**未做则明确未验证**）
- 无命令输出时写「阶段 2 通过」

### Acceptance Criteria

- `20`–`23`（2a）或再加 `24`（2b）各文件第 4 节已有成功编译摘要；本文件不得替它们「补勾」
- 本文件第 4 节有一次（2a）或两次（2a+2b）全量 `compiler:compile` 的真实输出摘要后，才能写对应波次「编译通过」
- 纯度检索与五项表全部 `[x]` 或书面豁免
- `25` 默认跳过已确认
- 未跑的测试/启动不得写通过

### Rules and Constraints

Tenant isolation:

- 不涉及

Security and masking:

- 第 4 节不粘贴密钥、连接串、Token
- 401 探测不写内网主机

Audit and lineage:

- 对照 hash 漂移则本门禁失败，先改 `19`

AI/rule-engine rules:

- 不涉及

Database rules:

- 不执行 DROP；不把上游 `sql/` 整包打进现网
