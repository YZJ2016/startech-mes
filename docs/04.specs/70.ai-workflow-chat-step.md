### Business Goal

让已登录工作流除 Tool 步外，可插入 LLM **chat** 步：经 A24 `(tenantId, modelId)` 生成内容，进度经自定 SSE（`content`/`done`/`step`）推送，便于「先检索再总结」类编排。

Goal：步骤 `toolName=chat` 可用；SSE 无 langgraph / `[NODE_CHUNK_*]`；不改 chat/agent 口。

### Scope

In scope:

- 扩展工作流步骤 JSON：`toolName=chat`，必填 `modelId`（本租户），可选 `prompt` 模板 / 引用 run `input`
- `AiWorkflowStepExecutor`（或等价）新增分支：经 A24 取 `ChatModel` → 单轮/短轮生成 → 结果写入 run 上下文供后续步
- SSE：复用 66 runtime writer；推送 `step`（步骤名）、`content` 片段、结束 `done`
- 定义 CRUD 校验：`toolName=chat` 时必须有合法 `modelId`；禁止与 `execute_sql_query` 等混用
- 单测：Mock ChatModel；SSE 无 `[NODE_CHUNK_*]`；跨租户 modelId 拒绝

Out of scope:

- langgraph、状态图、NODE_CHUNK 兼容
- 改 `POST /ai/workflow/run` path 或 JWT 要求
- 改 `POST /ai/chat/send`、`POST /ai/agent/send`
- workflow 内 Agent Tools 循环（chat 步为单次 LLM 调用，非完整 Agent）
- Vue3 runner 改 UI（65 页可后续补步类型展示）
- 真实模型 Key、地址

Non-goals:

- 不做多 Agent 编排
- 不把 chat 步做成第二条 agent/send

### Acceptance Criteria

- 含 `chat` 步的工作流可 run；SSE 含 `content`/`done`，可选 `step`
- 无 `[NODE_CHUNK_*]`；无 langgraph 依赖
- 他租户 modelId → 该步失败关闭，不调用上游
- chat/agent HTTP 信封不变
- 第 4 节未编码前不得写「测试通过」

### Rules and Constraints

Tenant isolation:

- modelId 须本租户；run 仍只信 JWT

Security and masking:

- `/ai/workflow/run` 须登录；日志无 apiKey

Audit and lineage:

- run 行可记步骤名；详细审计见 71

AI/rule-engine rules:

- A24 出站 Key；A17/A28 SSE 自定
- chat 步不自动挂载 Tools（除非后续单独立项）

Database rules:

- 可无新表；步骤 JSON 存既有 `ai_workflow`
