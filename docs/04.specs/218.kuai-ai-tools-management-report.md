# KU-AI 场景能力：管理层日报/周报问数

从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：待实施；§1 决策已于 2026-10-23 选定。

## 1. Spec

### Capability

- Name: 管理层问数场景（S25）：不新增通用报表 Tool，由已建业务 Tool 组合 + 新增 `get_management_brief` 聚合 Tool。
- Module: `riveredge-backend/src/apps/kuaiai/services`（tools 适配层）、manifest `ai_tools`；场景模板 1 个（管理层助手）。
- Priority: P3（S25 管理层日报/周报）。
- Related requirement/design documents: 需求 25 SC-D10（报表数据集暂不开放）；设计 26 §4、§5.2；前置 spec 189、190、195–199、210、211、217。

### Business Goal

厂长问“昨天生产情况怎么样”“本周质量异常有什么变化”，助手按确定性口径汇总产量、工单、异常、质量、设备、库存等关键指标，输出一段结构化简报（数据来自各业务 Tool 同源 service）。

### Scope

In scope:

- `get_management_brief(period=today|yesterday|this_week|last_week, focus?=production|quality|equipment|inventory|all)`：适配层并行调用各领域只读聚合（T1 列出各领域可用 service 聚合方法），输出各域指标小节；每个小节标注数据口径与统计期间。
- 域权限按调用者各自校验：无某域权限时该小节显示“无 XX 权限”，不静默省略（管理员一眼能看出数据不全）。
- 新增预置场景模板 `management-brief`“管理层助手”（模板定义级，沿用 spec 201 T1=a 规则；Y3=a 随本单元登记）：启用 Tool 为本单元聚合 Tool + 相关读 Tool；停用 + 空授权（Y4=a）；模板 key 即能力矩阵场景卡，默认绑定同 key 预置实例（spec 191）。

Out of scope:

- 报表中心系统数据集（SC-D10，待用户级数据范围落地后才可另立）。
- 定时推送/订阅日报（另立）。
- 自由维度任意问数（超出闭集 focus 的追问走各领域 Tool，模型自行选择）。

### 决策（2026-10-23 已选定）

选定：**X6=a** —— 聚合 Tool 只输出各域现有确定性指标，不发明跨域指标；跨域指标（如交付达成率）待业务口径定义后另立补充。

| 编号 | 场景 | 选项 | 推荐与理由 |
| --- | --- | --- | --- |
| X6 | 厂长问“这个月交付达成率多少”，这类跨域指标没有现成单一 service；要么聚合 Tool 现算，要么接受“分域小节” | a. 聚合 Tool 只输出各域现有确定性指标（产量、异常数、合格率、OEE 摘要），不发明跨域指标；b. 在聚合 Tool 内补跨域确定性计算（如交付达成率=按期交付单数/应交付单数，口径需设计定义） | **a** 起步：跨域指标口径需要业务定义（何为“按期”、统计范围），未经定义的计算会给出看似精确的错误数。各域指标已覆盖日报主体需求；跨域指标如确需，先在设计 26 定口径再补 |

### Acceptance Criteria

1. `get_management_brief` 输出分域小节（期间、口径标注），数值与各领域 Tool 同源一致。
2. 无权限域显示“无 XX 权限”小节而非省略；全部无权限时返回固定提示。
3. `focus`/`period` 非闭集值返回固定错误文案。
4. 登记于 manifest（`label`、`kind=read`）；新模板登记默认停用。

### Rules and Constraints

Tenant isolation:

- 传 `ctx.tenant_id`。

Security and masking:

- 汇总指标不含个人敏感信息；域内明细不出现。

Audit and lineage:

- 沿用 Tool 级审计。

AI/rule-engine rules:

- 所有数值来自各领域确定性口径（SC-D5、SC-D10）；LLM 只做解读与建议话术。

Database rules:

- 无表结构变更。
