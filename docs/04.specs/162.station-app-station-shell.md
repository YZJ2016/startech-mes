# 触屏工位机 — Electron 壳

本文件可实施。代码落在 `kuaigeyun-mes/kuaigeyun-client/riveredge-app-station` 的 Electron 主进程。外层仓库与 `kuaigeyun-mes` 不产生 `.exe`。验收在私仓。

## 1. Spec

### Capability

- Name: 工位 Electron 主进程
- Module: `kuaigeyun-mes/kuaigeyun-client/riveredge-app-station`。窗口加载 spec 157 已拍板的服务器工位入口。业务 UI 留在 `kuaigeyun-mes/riveredge-frontend`。
- Priority: STN-D2、STN-D4、STN-D5、STN-D6。依赖 157 的入口可访问。
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/20.station-terminal-gaps.md`（**STN-D2**、**STN-D4**、**STN-D5**、**STN-D6**、**STN-D11**）
  - 设计：`docs/03.design/20.station-terminal-plan.md`（§2、§4、§5）
  - 入口：`docs/04.specs/157.station-terminal-entry.md`

### Business Goal

车间 Windows 触屏电脑开机后全屏常亮，记住自己是哪一个工位，接上扫码枪，窗口打开服务器上的工位入口。安装包只含壳。界面随服务器上的前端发布更新。

### Scope

In scope:

- Electron 主进程：全屏、保持常亮、当前用户登录后开机自启、本机记住工位、窗口加载服务器上的工位入口。
- 入口地址来自本机配置。配置不进仓库，不写生产地址、口令或密钥。窗口加载的路径字面量是 `/apps/kuaizhizao/production-execution/station`（157 **STN-S1**）。
- 安装包只含壳。业务页面从服务器加载，不烤进安装包（**STN-D4**、**STN-D5**）。
- 本机工位取值是星制造已有工位。与 157 页面上的绑定指向同一工位（**STN-D6**）。交接方式见 **STN-S3**。
- 扫码枪见 **STN-S2**。
- 158–161 的端到端冒烟以本壳打开 157 入口为场景：开工到结束、快捷报工、安灯、刷脸与交接班能在该窗口里走通现有接口。

Out of scope:

- 壳内的工单、报工、安灯、文档页面
- 在本仓或 `kuaigeyun-mes` 产出 `.exe`、安装向导或便携包
- 为工位另开一条编译业务代码的流水线
- 标签工位、电视看板、小程序、企业微信、移动端复制页面
- 新后端表；开工 API 内嵌 SOP 或资质；改 `startech-mes-basic`
- 终端设备登记表。身份来自本机配置

### 部署后置

`fast-deploy` 托管工位静态页，以及仓外打好的 exe 分发，见 `docs/04.specs/163.station-terminal-deploy.md`。本单元不改 `fast-deploy`，不新增工位编译脚本。现状仍是：`fast-deploy` 现有脚本覆盖手机端 Web，工位机 exe 的打包不在这些脚本里（**STN-D11**）。

### 已拍板 STN-S2

扫码枪当作键盘输入。字符进入页面当前焦点。157 的工位入口提供可聚焦的扫码输入，接收键盘楔入的条码，由页面解释业务条码。壳不解析工单、物料或人员条码。壳升级因此不必跟随条码规则。

### 已拍板 STN-S3

壳打开的工位入口 URL 带查询参数 `workstationId`。这是 URL query，不是 Electron 额外启动参数。页面把它作为 157 绑定的初值。页面绑定成功后，调用壳暴露的窄接口 `stationShell.setWorkstationId`，只传入工位 ID，回写壳的本机配置 `station-shell.json`。页面用 `stationShell.getWorkstationId()` 读回已保存的工位 ID，不解析条码，不改 `loadURL` 的路径。下次开机仍是这一工位，窗口再次以同一查询参数打开入口。壳不提供工位主数据维护界面。`window.stationShell` 本身标明这是工位端，前端在看路径之前据此把渠道定为 `station`（见 spec 157）。

### Acceptance Criteria

1. 私仓主进程在 Windows 上全屏、保持常亮，并在当前用户登录后自启。窗口加载的是配置中的服务器工位入口，路径为 `/apps/kuaizhizao/production-execution/station`。安装包内没有工位业务页面。
2. 本机配置保存一个工位 ID。壳加载入口时 URL 带查询参数 `workstationId`，与 157 页面绑定的是同一个工位。页面绑定成功后经 `stationShell.setWorkstationId` 回写，下次开机仍是该工位。
3. 扫码枪作为键盘输入到达页面焦点。壳的代码里没有业务条码解析。
4. 外层仓库与 `kuaigeyun-mes` 的构建不产生 `.exe`。
5. 本单元不修改 `fast-deploy`。

### Rules and Constraints

Tenant isolation:

- 壳不保存租户数据。租户由页面上的终端账号登录会话决定。

Security and masking:

- 本机配置、日志、仓库不写入口令、令牌、密钥或生产地址。
- 入口地址由现场配置提供。

Audit and lineage:

- 壳不另写业务审计。执行记录仍在现有后端。

AI/rule-engine rules:

- 不涉及。

Database rules:

- 无新表，无「终端设备」登记。工位 ID 存在私仓定义的本机配置里。

## 2. Plan

### Implementation Approach

1. 私仓主进程创建全屏窗口，阻止休眠，并用 Electron 登录项在当前用户登录后启动。
2. 窗口 `loadURL` 指向本机配置的服务器地址，路径字面量为 `/apps/kuaizhizao/production-execution/station`，并带 URL 查询参数 `workstationId`。
3. 扫码枪输入作为键盘事件交给页面焦点，壳不解析业务条码。页面调用 `stationShell.setWorkstationId` 时，壳把工位 ID 写入本机配置，下次启动仍用该值拼进上述查询参数。

### 依赖

- 依赖 157 的入口已经可从服务器访问。158–161 可在壳之前合入前端；端到端冒烟在本单元的窗口里做。
- 158–161 彼此可先后，不阻塞壳的窗口与自启。

### Affected Modules

- `kuaigeyun-mes/kuaigeyun-client/riveredge-app-station` 的 Electron 主进程与 preload（该目录独立 `git init`，`kuaigeyun-mes/.gitignore` 忽略 `kuaigeyun-client/`）
- 页面侧的绑定初值与扫码焦点在 157 入口，参数名与本文件 **STN-S2**、**STN-S3** 一致
- 不改 `kuaigeyun-mes/fast-deploy/`，不在 `riveredge-frontend` 增加壳内静态打包

### Public Contracts

- **STN-S1**：窗口加载路径 `/apps/kuaizhizao/production-execution/station`。不使用 `/apps/kuaizhizao/station`。不启用 `production-execution/terminal`。
- **STN-S2**：扫码枪是键盘输入。页面焦点接收。壳不解析业务条码。
- **STN-S3**：URL 查询参数名 `workstationId`（URL query，不是 Electron 额外启动参数），作为 157 绑定初值。回写窄接口名 `stationShell.setWorkstationId`，只接收工位 ID，写入本机 `station-shell.json`。读回窄接口名 `stationShell.getWorkstationId`，只返回已保存的工位 ID。下次开机仍带同一查询参数。`loadURL` 路径不变。
- 业务 API 仍是 158–161 列出的现有接口。壳不调用这些接口。

### Persistence Changes

- 本机配置保存入口地址与工位 ID。无数据库迁移。

### Transaction Boundaries

- 壳不参与业务事务。

### Risks

- 把前端构建产物打进 exe 后，改一个按钮就要重装产线电脑，离开 **STN-D4**。
- 壳解析业务条码后，条码规则变更会要求升级 exe。壳只把键盘输入交给页面焦点。
- 页面绑定成功后必须调用 `stationShell.setWorkstationId`。否则下次开机仍打开旧工位。

### Verification Strategy

- 验收在私仓：启动壳，确认全屏、常亮、登录后自启，窗口打开配置的入口，URL 路径为 `/apps/kuaizhizao/production-execution/station` 且带 `workstationId`。
- 外层仓库本文件写下时未跑私仓构建，也未产生 exe。
- 158–161 的端到端冒烟在该窗口内手工走一遍现有接口。§4 在实跑后填写。
