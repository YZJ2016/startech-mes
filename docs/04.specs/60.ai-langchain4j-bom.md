- Priority: P8（依赖版本管理；不交付对话/RAG 改写）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/03.mes-ai-platform-gaps.md`（A23、V3）
  - 缺口：`docs/02.requirements/04.mes-ai-phase1-gaps.md`（P1-D7、P1-X4）
  - 设计：`docs/03.design/06.mes-ai-platform-plan.md` §6、§10
  - 总控：`docs/04.specs/48.mes-ai-platform-program.md`
  - Phase 1 运行时仍 JDK HTTP：`docs/04.specs/57.ai-phase1-provider-model.md`、`58.ai-phase1-session-chat.md`
  - 向量：`docs/04.specs/54.ai-vector-oss-p5.md`、`56.ai-dashvector-p7.md`
  - 上一单元（Phase 1 UI）：`docs/04.specs/59.ai-phase1-vue3-ui.md`
  - 下一单元（ChatModel 生命周期，仅文档）：`docs/04.specs/61.ai-chatmodel-factory.md`
  - 运行时改写（落实 61+62）：`docs/04.specs/63.ai-langchain4j-runtime.md`
  - Community 仓库（只读坐标，不拷代码）：https://github.com/langchain4j/langchain4j-community

### Business Goal

父 POM 锁定 LangChain4j 版本，供后续把 `ktg-ai` 从自定义 JDK `HttpClient` 迁到官方 API 时不再手写版本。本单元不改变对话、embedding、向量、Agent 行为。

### Scope

In scope:

- 父 POM properties：`langchain4j.bom.version` = `1.19.0`；`langchain4j.community.bom.version` = `1.19.0-beta29`
- `dependencyManagement` 在 Spring Boot BOM **之后** import（type `pom`、scope `import`）：
  - `dev.langchain4j:langchain4j-bom:${langchain4j.bom.version}`（核心 `langchain4j-*`；内部管理 Boot 4 starters `1.19.0-beta29`）
  - `dev.langchain4j:langchain4j-community-bom:${langchain4j.community.bom.version}`（community `langchain4j-community-*`：DashScope/Qwen、额外 store、boot4 starters）
- 双 BOM 有意并存：核心与 community 的 artifact GA **不重叠**

Out of scope:

- 在 `ktg-ai`（或其它模块）增加任何 `langchain4j-*` / `langchain4j-community-*` 运行时依赖
- 用 LangChain4j 替换 `OpenAiCompatChatClient` / embedding 客户端 / 向量 HTTP
- Agent、MCP、workflow
- 用 community 冒充 DashVector（community **有 DashScope，无 DashVector**；DashVector 仍 56 自定义 HTTP）
- 引入或推荐已过期的 `langchain4j-spring-bom`（Central 末次有用快照约 `1.0.0-beta5`）
- Sa-Token、第二套 `SecurityFilterChain`、MyBatis-Plus、改 `/ai/**` HTTP 契约、改默认 `uploadMinio`、改 Vue2、写真实主机/密钥

### Acceptance Criteria

- 父 `pom.xml` 含上述两个 BOM import 与两个 version 属性
- `cd startech-mes-basic/backend && mvn -N help:effective-pom` BUILD SUCCESS，effective POM 能解析两个 BOM
- `ktg-ai/pom.xml` **没有** LangChain4j 依赖；chat/embedding/vector 仍为自定义 JDK HTTP
- 文档不推荐 `langchain4j-spring-bom`；不把 chat/RAG 标成「已迁 LangChain4j」
- 文档无真实服务地址、凭据

### Rules and Constraints

Tenant isolation:

- 本单元不改表、不改租户拦截器

Security and masking:

- 不引入第二套认证；`/ai/**` 契约不变；不扩大 `MesPermitAllProvider`
- 文档不写 API Key、endpoint 真值

Audit and lineage:

- 只改父 POM 依赖管理；不改历史 SQL

AI/rule-engine rules:

- P1-D7 对 **依赖管理** 的「禁止引入 LangChain4j」已废止；对 **运行时改写** 仍未开工
- 禁止借 BOM 引入 Agent/MCP 全家桶
- DashScope ≠ DashVector

Database rules:

- 无表变更；根键仍 `ruoyi:`
