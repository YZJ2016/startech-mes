# KU-AI Pulse：接入 kuaiiot 设备告警

从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：待实施；§1 决策已于 2026-10-23 选定。

## 1. Spec

### Capability

- Name: Pulse 设备领域升级为多来源：MES 故障单 + kuaiiot 设备告警（传感器越限、离线等）。
- Module: `apps/kuaiai/services/pulse/`（detector、registry 部分语义）、kuaiiot `alert_service`/`trend_service` 调用封装；前端 Pulse 部分失败提示（如需）。
- Priority: P3 跟进项（spec 203 E1=a 遗留缺口；也是 S17 完整形态的前置）。
- Related requirement/design documents: 需求 25；设计 26 §4；前置 spec 203。

### Business Goal

注塑机温度超限已产生 5 条 IoT 告警但没人报修时，Pulse 能立刻提示“设备 X 有 N 条未处理告警”，而不是等故障单出现。

### Scope

In scope:

- 设备 detector 增加 kuaiiot 数据源：未处理告警按设备聚合（告警数、最新告警级别、最新告警时间），与 MES 故障单并列展示为不同信号类型。
- 应用可用性：kuaiiot 未安装时该来源整体跳过，不影响 MES 故障单部分。
- 权限语义：见 X8（关键决策）。
- 同设备同时有故障单与告警时：两条信号并列展示，内容各自准确，不做合并去重（两者是不同事实：有人报修 vs 传感器告警）。

Out of scope:

- IoT 告警的确认/处理动作（写）。
- 告警趋势图（`trend_service`）接入 AI Tool——如需另立。
- spec 203 已交付的 MES 故障单逻辑改动最小化。

### 决策（2026-10-23 已选定）

选定：**X8=a** —— 领域内来源级权限：无权限来源显示“无 XX 权限”占位小节，与 spec 218 分域小节同语义。

| 编号 | 场景 | 选项 | 推荐与理由 |
| --- | --- | --- | --- |
| X8 | 用户有设备故障权限但没有 `kuaiiot:alert:read`（或反之）时：现有 Pulse 框架是“一领域一权限，无权限整领域隐藏”，没有“领域内部分数据源不可用”的语义 | a. 引入“来源级权限”：领域内各数据源独立判权，无权限的来源显示“无 IoT 告警权限”占位小节（参考 spec 218 的分域小节语义）；b. 权限取并集：有任一权限才显示该来源，两者都无则整领域隐藏；c. 权限取交集：只有两个权限都有才显示设备领域 | **a**：信息不静默丢失，用户知道“存在但我看不到”；b 会让无 IoT 权限用户永远看不到告警却不知道原因；c 会把原本有故障权限的用户也挡掉。需要给 registry/前端补“来源级无权限”语义，改动可控 |

### Acceptance Criteria

1. kuaiiot 未安装：设备领域仅显示 MES 故障单信号，无报错。
2. kuaiiot 已安装且有权限：设备信号包含故障单与告警两类，各自计数与最新时间准确。
3. X8=a：单权限用户看到有权来源 + 无权来源的占位小节；无权来源不泄露数据。
4. 与 spec 203 的信号格式兼容，前端正常渲染。

### Rules and Constraints

Tenant isolation:

- 传 `ctx.tenant_id`；跨应用调用只传 tenant_id 与已判权参数。

Security and masking:

- 告警原文（传感器读数等）按 kuaiiot 权限控制，不外泄。

Audit and lineage:

- Pulse 查询沿用现有审计。

AI/rule-engine rules:

- 信号生成沿用 detector 确定性规则；告警级别沿用 kuaiiot 数据。

Database rules:

- 无表结构变更。

## 2. Plan

### Implementation Approach

- detector 内并行拉两源（各自超时）；可用性判断用延迟 import + 应用安装检查；X8=a 时在 detector 返回结构增加 `sources: [{key, status: ok|no_permission|unavailable, signals}]` 语义并同步前端渲染。

### Affected Modules

- Modify: `apps/kuaiai/services/pulse/equipment` detector、`registry.py`（来源级权限语义）、前端 Pulse 渲染（占位小节）。
- Test: `tests/apps/kuaiai/test_spec220_pulse_iot.py`。

### Public Contracts

- Pulse 接口响应结构新增来源级状态字段（向后兼容：旧前端忽略新字段仍可用，但显示退化——部署说明中注明）。

### Persistence Changes

- 无。

### Transaction Boundaries

- 只读。

### Risks

- 跨应用 service 签名变化：T1 核对 kuaiiot `alert_service` 方法签名。

### Verification Strategy

- 单测：未安装/无权/超时/双源并存各分支；前端占位渲染核对。
