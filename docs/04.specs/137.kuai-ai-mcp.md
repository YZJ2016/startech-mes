## 1. Spec

### Capability

- Name: S4 — MCP 白名单 + `MultiServerMCPClient`
- Module: **仅** `kuaigeyun-mes` 的 `apps/kuaiai`（`mcp_servers` 表/服务/REST）+ 装配时并入档案 tools。**禁止**改快格仓其它目录；**禁止**扩改白名单外 `core/ai`。
- Priority: P1（KR-X4；依赖 S2 档案装配与 runtime）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/16.kuai-ai-rebuild-gaps.md`（KR-D11、KR-X4）
  - 设计：`docs/03.design/16.kuai-ai-rebuild-plan.md`（§10、§6 路径 D、§15 S4）
  - 上一单元：`135`（装配点）；知识非硬依赖，可与 `136` 并行但装配合并在 S2 钩子上完成

### Business Goal

租户可维护 MCP 服务器白名单（连接密文**打码 + 服务端解析 seam**，口径同 KR-D5/`api_key`）；档案勾选子集后，发送时经 `langchain-mcp-adapters==0.3.2` 的 `MultiServerMCPClient(tool_interceptors=...)` + `get_tools()` 并入 Agent tools（**与代码对齐**：契约原文 `load_mcp_tools(tool_interceptors=...)` 的 0.3.2 实测等价形态），禁止任意远程与 SQL MCP。

### Scope

In scope:

- 表 `apps_kuaiai_mcp_servers`（`tenant_id` + 连接配置；**与代码对齐**：token 列存 + `decrypt_token()` seam，出参打码复用 IntegrationConfig `_mask_config_password` / `masked_api_key_fields` 口径；**不新建**第二套 at-rest cipher、不复用库口令密钥——与目录 `api_key`/`decrypt_api_key` 同轨）
- REST：mcp-servers CRUD + options（契约表）
- `mcp_client_service`：按档案 `mcp_server_ids` 子集建连；`MultiServerMCPClient(tool_interceptors=...)`（0.3.2）做权限+审计+超时，再 `await client.get_tools()`
- 装配挂钩：`agent_assembler.assemble` 并入 mcp tools（S2 已留 `mcp_server_ids` 字段）+ `build_mcp_aware_tool_guard`
- 依赖包 `langchain-mcp-adapters==0.3.2`（已钉 pyproject/uv.lock）

Out of scope:

- 任意远程 MCP、SQL MCP、**未登记/非白名单** MCP（**与代码对齐**：「禁匿名」= 禁未登记 server 建连；白名单行 token 可空的免认证 server 合法）
- 密钥轮换；确认闸；工作流
- 知识/前端/`structured_draft`（S3/S5/S6）——前端 MCP 管理页属 **S5（138）**，本单元不验收页面
- 审计查询页；改网关信封或 `/ai/**`

### Acceptance Criteria

1. MCP CRUD/options：token 不回详情明文/options/日志/SSE（打码 `****` + `token_configured`；options 仅 `{id,name,code}`）。
2. 仅档案 `mcp_server_ids` ∩ 本租户启用未删白名单行可连；**与代码对齐**：装配侧跨租户/停用/已删/不存在 id **静默过滤**不建连（同 knowledge_ids）；管理 REST 跨租户/软删 → **404**；请求 schema `extra=forbid`（禁 body `tenantId`）；响应不回 `tenant_id`。
3. **与代码对齐**：`MultiServerMCPClient(..., tool_interceptors=[...])` + `get_tools()`（0.3.2 实测；契约 `load_mcp_tools(tool_interceptors=...)` 的等价落地）；工具错误回 `CallToolResult(isError=True)` → adapters `handle_tool_errors` → `ToolMessage`，不 500 抛穿。
4. 禁 SQL MCP（保存 + 调用侧黑名单）、禁未登记/非白名单远程、transport 仅 `http`→`streamable_http`。
5. MCP **工具调用**经 interceptor 读 `AiRuntimeContext`；空上下文失败关闭（KR-I6）；审计 `ai/mcp/{tool}` 不落 token/参数。

### Rules and Constraints

Tenant isolation:

- 表与查询全 `tenant_id`；装配前按本租户启用未删行解析 `mcp_server_ids`。

Security and masking:

- 连接密文同 KR-D5 打码惯例（IntegrationConfig `_mask_config_password`）；不新建第二套 cipher、不复用数据库口令密钥。**与代码对齐**：当前无 at-rest cipher，列存原值 + `decrypt_token` seam（同 `decrypt_api_key`）。

Audit and lineage:

- MCP 工具调用经 interceptors 审计；不落 token。

AI/rule-engine rules:

- MCP tools 与五值闭集并列进档案 tools；不替代闭集写 Tool；撞闭集名/跨 server 同名一律丢弃。

Database rules:

- 新建 `apps_kuaiai_mcp_servers`；轮换不进本期。
