# Development Unit Template

Use this template before each implementation unit.

## 1. Spec

### Capability

- Name: S4 — MCP 白名单 + `MultiServerMCPClient`
- Module: **仅** `kuaigeyun-mes` 的 `apps/kuaiai`（`mcp_servers` 表/服务/REST）+ 装配时并入档案 tools。**禁止**改快格仓其它目录；**禁止**扩改白名单外 `core/ai`。
- Priority: P1（KR-X4；依赖 S2 档案装配与 runtime）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/16.kuai-ai-rebuild-gaps.md`（KR-D11、KR-X4）
  - 设计：`docs/03.design/16.kuai-ai-rebuild-plan.md`（§10、§6 路径 D、§15 S4）
  - 上一单元：`135`（装配点）；知识非硬依赖，可与 `136` 并行但装配合并在 S2 钩子上完成

### Business Goal

租户可维护 MCP 服务器白名单（连接密文加密/打码）；档案勾选子集后，发送时经 `langchain-mcp-adapters` 的 `MultiServerMCPClient` + `load_mcp_tools(tool_interceptors=...)` 并入 Agent tools，禁止任意远程与 SQL MCP。

### Scope

In scope:

- 表 `apps_kuaiai_mcp_servers`（`tenant_id` + 加密连接配置；复用 IntegrationConfig 加密/打码）
- REST：mcp-servers CRUD + options（契约表）
- `mcp_client_service`：按档案 `mcp_server_ids` 子集建连；`tool_interceptors` 做权限+审计+超时
- 装配挂钩：`agent_assembler` 并入 mcp tools（S2 已留 `mcp_server_ids` 字段）
- 依赖包 `langchain-mcp-adapters==0.3.2`（若尚未安装）

Out of scope:

- 任意远程 MCP、SQL MCP、匿名 MCP
- 密钥轮换；确认闸；工作流
- 知识/前端/`structured_draft`（S3/S5/S6）
- 审计查询页；改网关信封或 `/ai/**`

### Acceptance Criteria

1. MCP CRUD/options：密文不回详情/options/日志/SSE。
2. 仅档案白名单子集可连；跨租户 server id → 404/403，不建缓存项。
3. `load_mcp_tools` 带 interceptors；工具错误回 ToolMessage（适配器默认 `handle_tool_errors`）。
4. 禁 SQL MCP、禁匿名、禁非白名单远程。
5. 异步/MCP 调用拷贝租户用户上下文；空上下文失败关闭（KR-I6）。

### Rules and Constraints

Tenant isolation:

- 表与查询全 `tenant_id`；装配前复核 `mcp_server_ids` 归属。

Security and masking:

- 连接密文同 KR-D5 加密惯例；不新建第二套 cipher、不复用数据库口令密钥。

Audit and lineage:

- MCP 工具调用经 interceptors 审计；不落 token。

AI/rule-engine rules:

- MCP tools 与五值闭集并列进档案 tools；不替代闭集写 Tool。

Database rules:

- 新建 `apps_kuaiai_mcp_servers`；轮换不进本期。
