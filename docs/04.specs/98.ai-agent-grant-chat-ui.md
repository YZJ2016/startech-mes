### Business Goal

对话窗口只展示当前用户被授权的启用档案。旧会话上的档案若已无权则清空选择，发送未选时仍走纯对话。不在前端复制一套授权算法。

### Scope

In scope:

- 继续 `listAgentProfileOptions()`；选择器显示条件不重开 73（`ai:chat:list` 或 `profile:list|query`）
- 会话恢复：`agentId` 不在本次 options → `currentAgentId` 清空，不得带入 `agent/send`
- 无可用档案：选择器空列表；发送走 `chat/send`
- send 403：现网错误通道提示（如「无权使用该助手」），不重试改 agentId
- F1 `Panel.vue` 与全宽页同一套恢复/清空规则
- axios / fetch 惯例不变

Out of scope:

- 在前端按角色 id 自己过滤全量 list
- 改 96 Java
- 档案管理页（**97**）
- 改 Vue2；新权限字

Non-goals:

- 不把「无档案」自动选默认助手（默认助手也必须出现在 options 里才可选）

### Acceptance Criteria

- options 返回空时不能对隐藏 agentId 调 `agent/send`
- 无权的历史 `agentId` 不残留在发送体
- 未选档案仍 `chat/send`
- `npm run build:prod` exit 0 后才写第 4 节通过
- `frontend/` git diff 为空
- 浏览器未点选不得写 UI 已验收

### Rules and Constraints

Tenant isolation:

- 不传客户端 `tenantId`

Security and masking:

- 前端不把「被过滤掉的档案」缓存后再发

Audit and lineage:

- 无新菜单

AI/rule-engine rules:

- 未选 = 无 Tool（A36）

Database rules:

- 无
