## 2. Plan

### Implementation Approach

先 96 落表、命中规则、options 过滤、send 403、存量 ROLE 迁移；97 档案页授权 UI 与 98 对话/F1 恢复逻辑可并行，均依赖 96 HTTP 增量。

### Affected Modules

- 文档：本文件与 96/97/98；缺口 11；设计 12；总控 48；加固缺口 05 / F1 缺口 08 指针
- 编码：`ktg-ai` + Flyway tenant（96）；Vue3 档案页（97）；对话页与 F1 抽屉（98）

### Public Contracts

- **冻结：** `/ai/agent/profile` CRUD path；`GET /ai/agent/profile/options`；`POST /ai/agent/send`；SSE `{content, done}`
- **增量：** profile 的 `grantMode` / `roleIds` / `userIds`；options 结果集按使用权过滤；send 无授权 403

### Persistence Changes

- `ai_agent.grant_mode`；`ai_agent_grant`；存量启用档案绑本租户全部正常角色

### Transaction Boundaries

- 保存档案：档案行 + 授权行覆盖写同一事务
- send：校验失败不写 assistant、不调上游

### Risks

- 迁移绑「全部正常角色」仍接近全员可见，直到管理员收紧
- 只改下拉不改 send 会留下 agentId 绕过
- `isAdmin()` 误跳过 grant

### Verification Strategy

- 以 96/97/98 第 4 节为准；本总控不跑 Maven
