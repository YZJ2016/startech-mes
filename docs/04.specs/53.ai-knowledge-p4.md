## 1. Spec

### Capability

- Name: P4 知识库元数据与 MinIO 附件
- Module: `ktg-ai` knowledge；`startech-mes-front` 知识库页（可本单元补）
- Priority: P4
- Related requirement/design documents:
  - 设计：`docs/03.design/06.mes-ai-platform-plan.md` §4、§7
  - 缺口：`docs/02.requirements/03.mes-ai-platform-gaps.md`（A5、A16、I2 租户文件前缀）
  - 总控：`docs/04.specs/48.mes-ai-platform-program.md`
  - 上一单元：`docs/04.specs/52.ai-frontend-p3.md`
  - 下一单元：`docs/04.specs/54.ai-vector-oss-p5.md`

### Business Goal

工厂可建知识库、上传附件到 MinIO、登记附件行。本单元**不**做向量写入与对话检索（54/55）。解析状态可先「待解析」。

### Scope

In scope:

- 表 `ai_knowledge`、`ai_knowledge_attach`、`ai_knowledge_fragment`（片段表可先建空，54 再写行）
- `/ai/knowledge` CRUD；附件登记（对象键必须 `tenant/{id}/` 前缀，否则 403）
- 上传走既有 `POST /common/uploadMinio`，本模块只收对象键/文件名
- Vue3 知识库列表/上传页（F-A4）

Out of scope:

- 向量策略、embedding、RAG
- OSS 默认上传
- 三种向量 SDK

### Acceptance Criteria

- 知识库/附件无上下文失败关闭
- 跨租户 knowledgeId 404
- 对象键前缀不匹配当前租户 → 403
- 不引入 `/resource/oss`

### Rules and Constraints

Tenant isolation:

- 三表 include + 专库 catalog
- 文件键规则对齐 I2

Security and masking:

- API 不回存储凭据
- 不扩大匿名下载 `tenant/`

Audit and lineage:

- 增量 SQL 新文件

AI/rule-engine rules:

- 无模型调用（解析可 54 再做）

Database rules:

- 附件表存对象键，不存 blob
