## 1. Spec

### Capability

- Name: 星数采公共连接关联与可靠性补齐。
- Module: `kuaigeyun-mes` 的 core、kuaiiot 云端/Agent/Web，以及 kuaizhizao OEE。
- Priority: KIO-R06–R08 为 P0；R01–R05、R09–R12 为 P1；R13 为 P2。
- Related requirement/design documents: `docs/02.requirements/19.kuaiiot-selfdev-gaps.md`（R01–R13、D9/D10）；`docs/03.design/19.kuaiiot-selfdev-plan.md` §5。150–156 为历史实现参照，不重写其验证记录。

### Business Goal

core 管连接与凭据，kuaiiot 管数采映射和设备绑定；网络、PLC、配置及回执异常时数据可信且可诊断。入口、配置、任务注册不冒充已完成的现场能力。

### Scope

In scope:

- R01 按方案 A 关联同租户公共配置；R02 公共测试语义；R03 公共通知接入；R04/R05 真实通信、健康与留存。
- R06–R09 快照、采样身份、补传、心跳、配置、坏点和指令回执可靠性；R10 自动趋势；R11 OEE；R12/R13 接入诊断与真实协议范围。

Out of scope:

- 凭据加密、token/嵌套脱敏扩展、关闭已有脱敏；新建认证/ORM/通知系统/设备台账；内置 Broker；PG 趋势替身；换栈升级；遗留仓和未点名部署脚本。

### Acceptance Criteria

- R01：同租户 core 为连接/凭据单一来源；拒绝跨租户关联；迁移、启停及删除遵循用户选定策略。
- R02：配置校验、可达、认证和业务读写可区分；401/403/404 不证明认证或业务成功；Influx 配置校验不冒充读写实证。
- R03：复用公共通知；未配置、派发失败及恢复/确认/处置行为可观察，不仅落告警行。
- R04/R05：模拟/真实服务验证通信；健康和清理不是占位；保留既有任务入口，策略待选。
- R06/R07：先新后旧不倒退快照；同次采样首次发送至重试身份一致；响应丢失不重复副作用；质量和历史状态遵循选定语义；补传不挤占采集。
- R08/R09：PLC 失败仍有 Agent 心跳，坏点不拖累可用点；配置失败恢复按选定策略；写成功但回执失败不冒充执行失败，回执重试不重复执行。
- R10：采集数据进入租户 Influx 并可查询，外部故障按选定投递策略处理；无 Influx 不以 PG 历史顶替。
- R11：理想节拍、班次窗口、断采、窗口前状态和缺失质量有明确口径，两端一致；不把两因子指标当完整 OEE。
- R12/R13：单设备接入、试读、转换校验、发布验收和诊断可验证，协议声明与 Agent 可执行范围一致。

### Rules and Constraints

Tenant isolation:

- 关联、配置读取、通知、后台扫描和回执沿用既有租户机制；显式跨租户扫描保持 scope 与审计。

Security and masking:

- D10：普通 JSON 明文存储、运行时原值读取；已有顶层脱敏及占位符编辑行为保持；不扩展脱敏、不新增加密。凭据不进日志、错误、toast、仓库；采集不能拿管理 API 的 `****` 去连接。

Audit and lineage:

- 同次采样身份贯穿重试；区分采样/接收时间与设备执行/回执送达，具体字段见本节 Persistence Changes。

AI/rule-engine rules:

- 不涉及 AI；沿用领域告警及公共通知。

Database rules:

- 先核对 Web 与 aerich。新迁移放 `migrations/models/`，首段为 14 位时间戳，大于已有最大时间戳；不接开源最大序号，不改已执行迁移。
