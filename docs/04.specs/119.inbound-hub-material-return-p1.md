### Business Goal

仓管在 Vue3 可 **新建还料单**（必须关联已执行借料单），录入归还行并 **一步执行过账** 加回库存；同时在 **同一入库 Hub**（菜单 9300）按类型筛选看到还料单，点单号打开抽屉读头/行并执行，无需在 Hub 与散页之间切换。旧借料单（112）与出库 Hub `MATERIAL_BORROW` 臂 **不变**；还料 **不进** 出库 Hub。

### Scope

- **tenant Flyway**：新建 **`wm_material_return` / `wm_material_return_line`**（命名镜像 112；见附录 D DDL 草案）；表进 `TenantDedicatedSchema.WM_TABLES` 与 tenant line include（实现时对齐 112 四表做法）

- **REST CRUD**（镜像 112 借料形态）：
  - 头：`WmMaterialReturnController` **`/mes/wm/materialreturn`**

### Acceptance Criteria

1. **编码门禁：** 用户在同一会话 **点名 119**；112 借料代码已存在；118 四臂 Hub **不重开**其范围；114/112 出库结论不变。
2. 角色具备 `mes:wm:materialreturn:list` 可 CRUD 还料单；无权限 403；只信 JWT，无客户端租户头。
3. 还料头 **无 `borrow_id` 不得保存**；`borrow_id` 指向他厂或 **非 `FINISHED`** 借料单时保存/执行拒绝（明确 `AjaxResult.error` 文案）。
4. 执行：`PREPARE` + 有行 → `PUT /{returnId}` → `FINISHED` 且库存 **增加**（`processMaterialReturn`）；重复执行拒绝。
5. Hub：`mes:wm:inboundhub:list` 下 **可分页** 五类型混合 list；`receiptType=MATERIAL_RETURN` 仅查还料臂；每臂 SQL 带 `tenant_id`。
6. Hub 抽屉：还料可读可执行；关联借料单号可跳转；**不**渲染 IQC/FQC 块。
7. **`GET/PUT /mes/wm/materialborrow/**`、出库 Hub、`rtissue`/`rtsalse` URL/method/`code/msg/data` 不变**。
8. 出库 Hub list / Vue 类型枚举 **不含** `MATERIAL_RETURN`（还料是入库方向）。
9. 无金额列；无密钥进 yml/文档；Flyway 只进 `db/migration`；实跑命令后写入第 4 节；**未跑不得写绿**。

### Rules and Constraints

Tenant isolation:

- 无 `TenantContext` 不得访问 `wm_material_return*` / 借料表 / Hub UNION。
- 还料头 `borrow_id` 所指向借料单必须 **同 `tenant_id`**。
- Hub 五臂 **每一臂** 独立 `tenant_id`；禁止内存合并后再滤租户作为唯一隔离。

Security and masking:

- 新路径 `@PreAuthorize`；`/mes/wm/materialreturn/**`、`/mes/wm/inboundhub/**` 不进 `MesPermitAllProvider`。
- 403/404 不泄漏他厂是否存在该 `returnId`/`borrowId`。
- toast/API 不打印 JDBC、cipher、内部路径。

Audit and lineage:

- 新 DDL：**tenant** 业务表；**master** 菜单；不改 `backend/sql/`。
- 菜单 **9350–9354**；不占用 9300–9309（Hub）、9310–9349（出库/送货）。

AI/rule-engine rules:

- 不涉及；`/ai/**` 无变更。

Database rules:

- **无金额列**（对齐 112 / IH-G5 无价目）。
- **不写 yml** 业务键；还料是否允许部分归还不做全局开关（业务规则写死在 service）。
- 还料 **不得** secret 写入 `wm_item_recpt` / 借料表。
