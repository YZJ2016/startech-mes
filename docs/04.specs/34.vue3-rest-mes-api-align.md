## 1. Spec

### Capability

- Name: Vue3 MES 剩余域 API 对齐（tm / edu / report / camera / contract / sale）
- Module: `startech-mes-front/src/api/mes/{tm,edu,report,camera,contract,sale}`
- Priority: P0
- Related requirement/design documents:

### Business Goal

收口 29–33 未覆盖的 MES 封装：工装、培训评价、报表、摄像头、合同、售后。URL+method 跟现有 Controller；报表预览地址只来自环境变量。

### Scope

In scope:

- 上列 api 目录与对应 ktg-mes Controller（含 `/md/evaluation`、`/md/assessment`、`/md/salse`、`/ureportM`、`/pro/sales/order`）
- 评价导出 method、PUT 去尾斜杠
- `reportSelect` 预览走 `getUreportBaseUrl()`，不硬编码主机

Out of scope:

- 改 Vue2；改 Java；改 autocode 目录（只核对）
- 改 lock/notice/login/md/pro/wm/qc/cal/dv api 目录
- 把 `/jasper-report/previewPrint` 补成后端接口
- 提交 lockfile

### Acceptance Criteria

- 可对齐的 rest 封装落到 Controller
- `/ureportM/**` 仍走 mes；预览 URL 来自 env
- Vue2 同样缺失的路径只记缺口
- 第 4 节有库存；无 live 不写通过

### Rules and Constraints

Tenant isolation:

- 不改数据隔离

Security and masking:

- 不写真实报表主机、Token、口令

Audit and lineage:

- 对齐是接契约

AI/rule-engine rules:

- 不涉及

Database rules:

- 不改表
