### Business Goal

仓管在 Vue3 可 **登记客户/代工来料**（选客户 + 物料行 + 仓库），对需检物料在确认/执行前卡 **IQC**（对齐 105 双闸键思路），合格后过账加库存；同时在 **同一入库 Hub**（菜单 9300）按类型筛选看到客供单，点单号打开抽屉看闸预览与关联 IQC。旧物料入库 / 成品入库契约不变。

### Scope

In scope:

- **tenant Flyway**：`wm_customer_material` / `wm_customer_material_line`；注册 `TenantDedicatedSchema.WM_TABLES` + tenant include
- **master Flyway**：菜单 **9380–9384**；不自动 `INSERT sys_role_menu`
- **REST**：`/mes/wm/customermaterial` + `/mes/wm/customermaterialline`；权限 `mes:wm:customermaterial:*`
- **状态机（T0 默认）**：`PREPARE` →（可选 `CONFIRMED`）→ `FINISHED`；若走两步，确认/执行各自吃 IQC 双闸键（同 105 默认：confirm=`off`、execute=`on`）
- **IQC**：必检行未合格则对应步骤拒绝；闸预览 `GET /mes/wm/customermaterial/{id}/iqc-gate`；Hub 抽屉展示闸 + 只读 `qc_iqc_line`（对齐 IH-D21）
- **Hub**：UNION 第八臂；`receiptType=CUSTOMER_MATERIAL` 单臂筛选；省略未用臂（禁止 `AND 1=0`）
- **Vue3 UI-A**：新建 CRUD 页；**仅**改 Hub 类型筛/抽屉；不重排 `itemrecpt`/`iqc`/`client`
- **单测**：CRUD/过账/闸；Hub 八臂 tenant rewrite；负向：出库 Hub 无本类型

Out of scope:

- 快格云 **条码映射规则**主档、扫码自动建行、附件、审核流、Demand
- **IH-G11 拉单**、**IH-G12 撤回**、**IH-G13 委外三类**（123–125）
- 108–111 抛光语义重开；110/111 金额/打印不强制扩到客供
- 替换 `GET /mes/wm/itemrecpt/list`；前端假分页；Vue2；`MesPermitAllProvider` 扩面；yml 业务开关；第二套认证/ORM

### Acceptance Criteria

1. **编码门禁：** 会话点名 **122**；105 IQC 真源已落地；121 七臂 Hub **不重开**其范围。
2. 角色具备 `mes:wm:customermaterial:list` 可 CRUD；无权限 403；只信 JWT。
3. 头 **无 `client_id` 不得保存**；客户须同租户；执行前须有行。
4. 必检行：闸键 `on` 时未 ACCEPT 不得过对应步骤；GET 预览不插 IQC；autoDraft 默认 off。
5. 执行后库存 **+1**；重复执行拒绝；Hub 可筛 `CUSTOMER_MATERIAL` 且每臂带 `tenant_id`。
6. 旧 `itemrecpt`/`productrecpt`/`iqc` URL/method/`code/msg/data` 不变。
7. 出库 Hub **不含** `CUSTOMER_MATERIAL`。
8. 实跑命令后写 §4；**编码未开**前 §4 保持未跑。

### Rules and Constraints

Tenant isolation:

- 无 `TenantContext` 不得访问客供表 / IQC / Hub UNION。
- `client_id`、挂接 IQC、Hub 每一臂均须同 `tenant_id`。

Security and masking:

- 新路径 `@PreAuthorize`；不进 `MesPermitAllProvider`。
- toast/API 不打印 JDBC、cipher、内部路径。

Audit and lineage:

- DDL 只进 Flyway `db/migration/{master,tenant}`；不改 `backend/sql/`。

AI/rule-engine rules:

- 不涉及；`/ai/**` 无变更。

Database rules:

- 不写 yml 业务键；密钥禁止进文档/参数表明文。
- 行可空合格量/不合格量/序列号（对齐 IH-D19 加法习惯，**可选**；不强制本单元交付金额列）。
