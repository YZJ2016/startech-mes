### Business Goal

Vue3 角色勾选 9300 后出现入库 Hub：物料入库与成品入库一张表（可按仓库筛）、抽屉看明细与合格量/序列号/只读 IQC 项目；有检测模板的物料行未 `ACCEPT` 时，默认 `PUT /mes/wm/itemrecpt/{recptId}` 不得过账（确认步默认不卡）。旧菜单与旧 URL 仍可用。无 `ip` 等他轨行为变化。

### Scope

In scope:

- Flyway **master**：`sys_menu` 9300 段（仓储目录下，`parent_id` 取现网物料入库单之父）；`sys_config` 全局 `mes.wm.inbound.iqc.gate.confirm`=`off`、`mes.wm.inbound.iqc.gate.execute`=`on`、`mes.wm.inbound.iqc.autoDraft`=`off`（不种子旧单键）
- Flyway **tenant**：`qc_iqc.recpt_id` BIGINT NULL + `(tenant_id, recpt_id)` 索引；`wm_item_recpt_line` / `wm_product_recpt_line` 可空 `quantity_qualified`、`quantity_unqualified`、`serial_numbers` TEXT（IH-D19）。不加金额列
- `GET /mes/wm/inboundhub/list`：服务端合并 `wm_item_recpt` 与 `wm_product_recpt`，`TableDataInfo`，可筛 `warehouseId`，`@PreAuthorize mes:wm:inboundhub:list`
- `GET /mes/wm/itemrecpt/{recptId}/iqc-gate`：只读预览（IH-I3）；含 `canConfirm` / `canExecute` 与两闸是否启用
- `PUT /mes/wm/itemrecpt/confirm`：仅当 `gate.confirm=on` 时按行校验；键缺失/非法当 `off`。`autoDraft=on` 时先为缺草稿必检行建 `PREPARE` IQC（GET 预览不建）
- `PUT /mes/wm/itemrecpt/{recptId}`：仅当 `gate.execute=on` 时闸在 `processItemRecpt` 前；键缺失/非法当 `on`
- `POST /mes/qc/iqc`：现有 `recptCode` 回头逻辑保留，并写入 `recpt_id`；请求可带可选 `recptId`
- Mapper：IQC 按 `recptId`/`recpt_id` + `itemId` 可查；历史无 `recpt_id` 时回退头 `iqc_id` 或 `purchase_code=poCode`（IH-D7）
- Vue3：`inboundhub/index.vue` — 类型/仓库筛 + `el-table` + `el-drawer`；明细可编合格量/不合格量/序列号（现有行 API 加法）；闸表 + 只读 `GET /mes/qc/iqcline/list` 仅物料入库；关联单深链（现有 iqc/purchase/workorder 页 `route.query` 水合，不改布局）；执行/确认调现有 API；无打印按钮
- 单测：默认（confirm off / execute on）：未 ACCEPT 执行拒绝、确认仍过；无模板两步都放行；execute=`off` 执行放行；confirm=`on` 未 ACCEPT 确认拒绝；两键都 `on` 两步都拒
- **负向：** 不改 `itemrecpt/index.vue`、`productrecpt/index.vue`、`iqc.vue` 布局；不改出库/领料页；不自动 `sys_role_menu`；不扩 permitAll；不引入 Ant Design

Out of scope:

- 成品 FQC 闸（**IH-G2**）

### Acceptance Criteria

- 字典/菜单：`getRouters` 在角色勾 9300 且许可含 `wm` 时出现 path `mes/wm/inboundhub`；未勾则无；其它 MES 菜单不变
- Hub list 只返回本租户 `ITEM_RECPT`/`PRODUCT_RECPT`；分页 `total` 与页大小一致（不是前端切片假分页）
- 抽屉打开物料入库：可见行（含合格量/序列号）、闸预览、只读检验项目；默认 `canExecute=false` 时执行返回错误且库存不变；默认确认仍成功（confirm=`off`）
- Hub 可按 `warehouseId` 过滤；关联 IQC 可跳到现有质检路由
- 无模板绑定的入库确认与执行仍成功（与今日一致）
- 本厂 overlay `mes.wm.inbound.iqc.gate.execute=off` 后执行不校验 IQC；`gate.confirm=on` 后未 ACCEPT 确认失败
- `GET /mes/wm/itemrecpt/list` 与 IQC CRUD URL/method 不变；首页待入库仍可打旧 list
- `npm run build:prod`（有前端改动）与 `mvn -pl ktg-mes,ktg-system -am test`（或至少 compiler:compile）实跑后写入第 4 节
- 文档与代码无密钥；无按租户 INSERT `sys_menu`
- **编码门禁：** 对照清单无未处理待确认（已满足）。待补全已分类。本单元已在业务仓 `feature/mes-kuaige-capability` 编码。

### Rules and Constraints

Tenant isolation:

- 无 `TenantContext` 不得访问 wm/qc 表
- Hub UNION/合并查询每侧都带租户条件；禁止先查全表再在内存滤租户作为唯一隔离
- `recpt_id` 指向的入库单 `tenant_id` 必须与 IQC 行相同，否则视为未关联

Security and masking:

- 新路径须登录 + `@PreAuthorize`；403 不泄漏他厂是否存在该 id
- toast/API 不打印 JDBC、cipher、内部路径

Audit and lineage:

- Flyway 版本号实现时按目录现网最大号顺延（master 大于 `V20260909.02` 一类；tenant 大于 `V20260909.05` 一类，以当时目录为准）
- 菜单 id 冻结 9300–9309

AI/rule-engine rules:

- 不涉及

Database rules:

- 只加 `qc_iqc.recpt_id` 与行上三列（合格/不合格/序列号），不加第二套入库表、不加金额列
- 配置不进 yml

## 2. Plan

### Implementation Approach

- 先 Flyway（列 + 菜单 + 配置），再服务闸与 Hub list，最后 Vue3 Hub 页调附加 GET + 现有执行 API。
- 闸规则只实现一处（领域 service），预览与 confirm/execute 共用，禁止只在前端判断。

### Affected Modules

- `ktg-mes`：`WmItemRecptController` 增加 iqc-gate；confirm 与 execute 调同一闸；新增 inboundhub Controller 或同包接口；`QcIqc` 字段与 Mapper XML
- `ktg-system`：Flyway 脚本
- `startech-mes-front`：`src/views/mes/wm/inboundhub/`、`src/api/mes/wm/inboundhub.js`
- 不改：`frontend/`、layout 壳、dashboard、qc/iqc 页皮肤

### Public Contracts

- 保持：见设计 14 §3.1
- 新增：见设计 14 §3.2
- `POST /mes/qc/iqc` body 加法 `recptId`（可选）

### Persistence Changes

- `qc_iqc.recpt_id` NULL
- `wm_item_recpt_line` / `wm_product_recpt_line`：`quantity_qualified`、`quantity_unqualified`、`serial_numbers` 可空
- `sys_menu` 9300 段
- `sys_config` `mes.wm.inbound.iqc.gate.confirm` / `.execute` / `.autoDraft`

### Transaction Boundaries

- confirm：`autoDraft=on` 时先插草稿；闸失败不改 `CONFIRMED`
- execute：闸失败整段不进库存事务
- IQC add：insert 检验单与回写入库头 `iqc_id` + `recpt_id` 同一事务（现网 add 已 `@Transactional`）

### Risks

- PageHelper 对 UNION 分页行为：须在一条 SQL 或等价服务端分页上测 `total`
- 现网 `productrecpt/list` 注解被注释：Hub **自己的** list 必须有注解，不在本单元大规模恢复其它注释掉的 `@PreAuthorize`
- IQC 确认仍可能自动建另一张入库单：不改；闸只约束「执行已有单」

### Verification Strategy

- 单测闸：默认执行拒绝 / 默认确认放行 / 无模板放行 / execute off / confirm on
- 静态：旧 Vue API 文件 URL 未改；Hub 新 api 文件存在
- 命令：见第 4 节，未跑不得写绿
