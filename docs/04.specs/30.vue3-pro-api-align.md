## 1. Spec

### Capability

- Name: Vue3 MES 生产（pro）领域 API 对齐
- Module: `startech-mes-basic/startech-mes-front/src/api/mes/pro`（只读对照 `ktg-mes` pro Controller）；`dashboard.js` 的 `getIndexNum`；`contract.js` 中 `/pro/sales/order/**`
- Priority: P0
- Related requirement/design documents:
  - 总控：`docs/04.specs/27.vue3-backend-api-align-program.md`
  - 缺口：`docs/02.requirements/01.vue3-backend-api-gaps.md`（**D-pro**）
  - 调研：`docs/03.design/03.vue3-backend-api-align-survey.md`

### Business Goal

让 Vue3 生产封装的 URL+method 对上换壳后 ktg-mes pro Controller，避免工装领取记录打到不存在的 `/mes/tm/log` 列表路径。Vue2 同样未封装的销售发票/订单明细不补 Java。

### Scope

In scope:

- `src/api/mes/pro/**`、`src/api/mes/dashboard.js`（`GET /mes/pro/workorder/getIndexNum`）
- `contract.js` 里无前缀的 `/pro/sales/order/**`（pro `ProSalesOrderController`）
- `holder.js` 内嵌 tm 路径改接到真实 `TmToolLogController`

Out of scope:

- 改 Vue2；改 Java；锁屏/公告/登录
- 改 wm/qc/md 等其他 api 目录
- `/pro/sales/invoice`、`/pro/order/item`、`/mobile/pro/**`（Vue2 同样未封装）
- 提交 lockfile

### Acceptance Criteria

- 归一后 Vue3 pro/dashboard/sales-order 调用能落到 pro 或已声明的 tm mapping
- `holder.js` 为 `GET /mes/tm/log/list` 与 `POST /mes/tm/log`
- 第 4 节有库存；无 live 则不写运行时通过

### Rules and Constraints

Tenant isolation:

- 不改数据隔离

Security and masking:

- 文档无凭据、内网地址

Audit and lineage:

- 对齐是接契约，不改工单状态机

AI/rule-engine rules:

- 不涉及

Database rules:

- 不改表
