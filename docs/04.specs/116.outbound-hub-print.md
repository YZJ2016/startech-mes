## 1. Spec

### Capability

- Name: 出库 Hub 抛光 — Hub 打印（OH-G4）
- Module: `startech-mes-front` 出库 Hub 打印入口（浏览器 `window.print`）。**禁止**改 Vue2。本单元已编码。不改 UReport。
- Priority: Hub 抛光（出库切片后续；**不**改 107 范围声明）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/15.mes-outbound-hub-gaps.md`（**OH-G4**、OUT-F07 打印支、OUT-A04 print）
  - 设计：`docs/03.design/15.mes-outbound-hub-plan.md`（§7.4）
  - 切片总控：`docs/04.specs/106.mes-outbound-hub-program.md`
  - P0：`docs/04.specs/107.outbound-hub-p0.md`（已规定无打印按钮，保持；打印只加在本单元）
  - 入库打印不是本单元：`111.inbound-hub-print-p4.md` / IH-G6

### Business Goal

仓管在出库 Hub 能打印当前单据。107 明确无打印按钮。本单元才加 Hub 打印。不搬快格云打印框架 / `capabilities.print` 对象模型。不改 UReport（CAT-W06 禁止混进）。

**现网事实（编码后）：** 出库 Hub 抽屉「打印」按钮 = 浏览器 `window.print` + `mes:wm:outboundhub:list`，无新 HTTP。对齐入库 111。

**本会话拍板（T0 已开）：** 同样浏览器打印；权限复用 `mes:wm:outboundhub:list`；无新 GET。

### Scope

In scope:

- Hub 页打印入口（浏览器 `window.print` 薄封装）
- 权限与 Hub list 对齐；无权限不展示（`v-hasPermi`）
- UI-A：只动 Hub；不重排旧领料/销售出库 CRUD

Out of scope:

- 把打印塞进 107 范围声明；改旧 `issue`/`productsalse` 布局
- 快格云打印模板引擎、自定义字段附件（OUT-F06）
- 入库 Hub 打印（IH-G6 / 111）、仓储其余块 CAT-W01/W04–W07
- 改 UReport 当本单元「库存报表」
- OQC（115）、金额（117）、拉单/撤回（OH-G6/G7）
- 改 Vue2、扩 permitAll

### Acceptance Criteria

- **编码门禁（已满足）：** 点名 116。设计 §7.4 打印拍板项已确认（浏览器打印 / 复用 list 权限 / 无新 GET）。
- 角色能进 Hub 时可打印本租户当前抽屉单据；无 `mes:wm:outboundhub:list` 不展示打印按钮；不改 UReport
- 第 4 节未跑命令不得写绿

### Rules and Constraints

Tenant isolation:

- 打印数据查询带 `tenant_id`；禁止拼他厂单号
- 只信 JWT

Security and masking:

- 无新增 GET；沿用抽屉已有头/行查询
- 不进 `MesPermitAllProvider`
- 不打印内部路径

Audit and lineage:

- 旧 list/执行 URL 不变
- 不为打印新建业务头表

AI/rule-engine rules:

- 不涉及

Database rules:

- 无新业务列；禁止借打印加金额列（金额走 117）
