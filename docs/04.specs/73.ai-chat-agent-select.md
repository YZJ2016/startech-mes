- Priority: P10（建议 **72** 档案页可用之后；依赖 68 `POST /ai/agent/send`）
- Related requirement/design documents:

  - 前端先例：`docs/04.specs/59.ai-phase1-vue3-ui.md`
  - 上一单元：`docs/04.specs/72.ai-agent-profile-ui.md`
  - 链：`72` → **`73`（本文件）**

### Business Goal

用户在既有「智能对话」页可选择本租户 Agent 档案；选中后走带 Tools/MCP/档案提示的 Agent 发送；未选择时保持纯对话（无 Tool），不破坏 58/59 契约。

Goal：`/ai/chat` 一页两路径；**不新开** Agent 聊天路由。

### Scope

In scope:

- `/ai/chat` UI：增加可选「Agent 档案」选择器（数据源 **`GET /ai/agent/profile/options`**，封装 `listAgentProfileOptions()`；**不再** `listAgentProfile({ pageSize: 100 })`；仅本租户启用 `status=0`；不分页、不截断 100）
- 发送分支：
  - **未选档案** → 仍 `POST /ai/chat/send`（path、body、SSE `{content, done}` 与 58/59 一致；可继续挂 `knowledgeId`）
  - **已选档案** → `POST /ai/agent/send`，body 含 `agentId`（及既有 session/message 字段按 61/68）；SSE 同信封
- API：在 `chat.js` 增补 agent send，或 `agent.js` 增加 `send` 流式方法（与现网 chat SSE 相同 Bearer / `fetch` 模式；**不要** `hook-fetch`）
- 已选档案时：页内「模型」下拉与档案 `defaultModelId` 冲突规则——**以档案为准**（下拉只读或隐藏，细节任选一种，第 4 节写明）
- 权限：发送仍 `ai:chat:send`；下拉显示与 options 一致：有 `ai:chat:list` **或** `ai:agent:profile:list` **或** `ai:agent:profile:query` 才显示（无则隐藏选择器，不报错成可匿名，不阻断 chat/send）
- **覆盖（另立 95–98，不改本单元发送分支）：** options **内容**按档案使用权过滤（角色或人员二选一）；无授权的启用档案不出现在下拉，`agent/send` 无授权 403。选择器「是否渲染」仍用上一句权限字。见 `docs/02.requirements/11.mes-ai-agent-grant-gaps.md`

Out of scope:

- 新菜单 / 新路由 `/ai/agent/chat`
- 改 `POST /ai/chat/send` / `POST /ai/agent/send` 后端 path 或基础信封
- 改 72 档案 CRUD 页
- 改 Vue2；引入禁用前端栈；提交 lockfile
- 把未选档案静默改为 `agent/send`
- 工作流 runner、审计页

Non-goals:

- 不做独立 Agent 对话端
- 不在 chat 页编辑 profile 字段（跳转 72 即可）

### Acceptance Criteria

- 未选档案：网络请求仍为 `/ai/chat/send`；行为与改前一致
- 选中档案：请求为 `/ai/agent/send` 且带 `agentId`；SSE 可收 `content`/`done`
- 无 `ai:chat:list` 且无 `ai:agent:profile:list|query` 时选择器隐藏，chat/send 仍可用
- 无新 Agent 聊天菜单；`frontend/` diff 为空
- `npm run build:prod` exit 0 后才写第 4 节通过

### Rules and Constraints

Tenant isolation:

- 不传客户端 `tenantId`；跨租户 `agentId` 以后端 404/403 为准

Security and masking:

- SSE / toast 不打印密钥、cipher、内部路径

Audit and lineage:

- 无新表

AI/rule-engine rules:

- 选中档案后 Tools/MCP 完全由后端 profile 装配；前端不得拼造 Tool 名列表发送

Database rules:

- 无
