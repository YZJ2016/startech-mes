# KU-AI 能力矩阵：场景分类分组 + 收起展开 + 检索

从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：待实施；决策已于 2026-10-23 选定。

## 1. Spec

### Capability

- Name: 能力矩阵页场景卡按业务分类分组展示，各分类可收起/展开（记住状态），页头提供场景检索。
- Module: `riveredge-backend/src/apps/kuaiai/services/agent_scene_service.py`（模板 `category` 字段）、`schemas/operations.py`、hub 响应；`riveredge-frontend/src/apps/kuaiai/pages/hub/index.tsx`。
- Priority: P2（场景数 ≥9 后页面的可浏览性）。
- Related requirement/design documents: 需求 25 §7；设计 26 §8（Y1=a 每场景一卡）；前置 spec 191（场景卡渲染与绑定）。

### 决策（2026-10-23 已选定）

- **Z1=a**：`SCENE_TEMPLATES` 新增 `category` 闭集字段，按业务域分组；不复用 `capability_tags`（其值为能力族标签 KU-Ask/KU-Pulse 等，非业务分类）。
- **Z2=a**：默认全部展开，用户收起状态存 localStorage，跨会话记住。
- **Z3=a**：本单元独立交付（spec 191 只管卡片出现与就绪）。
- **Z4**（直接定）：页头搜索框按卡名/描述/分类名即时过滤；`ask` 卡不参与检索始终显示；命中所在分类自动展开；无命中显示空态。

### Business Goal

场景卡从 9 张涨到 20+ 张后，用户按“生产 / 质量 / 设备 …”分区浏览，可收起不关心的分类，也能直接搜场景名进入。

### Scope

In scope:

- `SCENE_TEMPLATES` 模板定义增加 `category`（闭集枚举，建议值：`plan`、`production`、`quality`、`inventory`、`purchase`、`equipment`、`engineering`、`management`、`general`；T1 定稿全量分类与每个已有/新增模板的归属）。
- 模板复制出的场景实例继承 `category`（存入实例 overrides 或模板查询时带出，T1 定数据通路）；hub `capabilities[]` 场景卡项下发 `category`。
- hub 前端：按 category 分组渲染场景卡（组头 = 分类名 + 卡数 + 展开/收起控件）；`ask` 卡独立成组或置顶不参与分组。
- 收起状态：`localStorage` 键 `kuaiai.hub.collapsed_categories`（存已收起的 category key 数组）；默认全展开。
- 检索框：即时过滤卡名/描述/分类名（大小写不敏感、前后空格裁剪）；命中卡所在分类强制展开展示；无命中显示“无匹配场景”空态；清空恢复分组视图。

Out of scope:

- 服务端搜索/分页（卡数规模上前端过滤足够）。
- 分类的管理端配置（category 为出厂闭集，不开放租户自定义）。
- `ask` 卡与 Pulse 区块的布局调整。

### Acceptance Criteria

1. 每个场景卡带 `category`，hub 按分类分组渲染；分类内卡序同 `SCENE_TEMPLATES` 顺序。
2. 点组头收起/展开；收起集合写入 localStorage，刷新后恢复；默认（无存储）全展开。
3. 检索命中仅显示匹配卡并强制展开其分类；`ask` 卡不受检索影响；无匹配时空态可见、不误判为加载失败。
4. 未登记的 category 值在模板/覆盖校验时拒绝（沿用 capability_tags 的闭集校验模式）。
5. 卡片就绪/未就绪状态、绑定解析行为不因分组改变（spec 191 逻辑不动）。

### Rules and Constraints

Tenant isolation:

- 分组与检索纯前端展示层；category 为模板定义数据，不涉及租户数据。

Security and masking:

- 无新增敏感面；localStorage 仅存 UI 偏好。

Audit and lineage:

- 无（纯展示行为不记审计）。

AI/rule-engine rules:

- 无。

Database rules:

- 无表结构变更；category 存于模板代码定义与实例 overrides JSON。

## 2. Plan

### Implementation Approach

- 后端：`SCENE_TEMPLATES` 元组加 `category` 字段 + `SCENE_CATEGORIES` 闭集常量；实例 overrides 允许 `category` 覆盖走既有白名单闭集校验；hub 项 schema 加 `category`。
- 前端：hub 页把场景卡数组按 category 分组渲染组头 + 卡网格；收起集合 `useState` + localStorage 同步；搜索框 `Input.Search` 受控过滤。

### Affected Modules

### Public Contracts

- hub capability 项新增 `category` 字段；模板 overrides 白名单新增 `category`（闭集校验）。

### Persistence Changes

- 无迁移；localStorage 为浏览器端偏好。

### Transaction Boundaries
