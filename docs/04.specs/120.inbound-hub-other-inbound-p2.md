### Business Goal

仓管在 Vue3 可 **新建其他入库单**（杂项入库：盘盈纠正以外的非采购/非成品/非退料/非还料入库），录入行并 **一步执行过账** 增加库存；同时在 **同一入库 Hub**（菜单 9300）按类型筛选看到其他入库单，点单号打开抽屉读头/行并执行。旧其他出库（112）与出库 Hub `OTHER_ISSUE` 臂 **不变**；其他入库 **不进** 出库 Hub。**禁止**用本单据承接盘点盈亏、仓库调拨、组装拆卸（那些属 CAT-W04）。

### Acceptance Criteria

1. **编码门禁：** 用户在同一会话 **点名 120**；112 其他出库代码已存在；119 五臂 Hub **不重开**其范围；CAT-W04 不并入。
2. 角色具备 `mes:wm:otherinbound:list` 可 CRUD 其他入库单；无权限 403；只信 JWT，无客户端租户头。
3. 执行：`PREPARE` + 有行 → `PUT /{otherId}` → `FINISHED` 且库存 **增加**（`processOtherInbound`）；重复执行拒绝；无行拒绝。
4. Hub：`mes:wm:inboundhub:list` 下 **可分页** 六类型混合 list；`receiptType=OTHER_INBOUND` 仅查其他入库臂；每臂 SQL 带 `tenant_id`。
5. Hub 抽屉：其他入库可读可执行；**不**渲染 IQC/FQC 块。
6. **`GET/PUT /mes/wm/otherissue/**`、出库 Hub、`rtissue`/`rtsalse`/`materialreturn` URL/method/`code/msg/data` 不变**。
7. 出库 Hub list / Vue 类型枚举 **不含** `OTHER_INBOUND`（其他入库是入库方向；对称的是 `OTHER_ISSUE`）。
8. 无金额列；无密钥进 yml/文档；Flyway 只进 `db/migration`；实跑命令后写入第 4 节；**未跑不得写绿**。
9. 文档与代码不得把盘盈/调拨描述为本单元能力。

### Rules and Constraints

Tenant isolation:

- 无 `TenantContext` 不得访问 `wm_other_inbound*` / Hub UNION。
- Hub 六臂 **每一臂** 独立 `tenant_id`；禁止内存合并后再滤租户作为唯一隔离。

Security and masking:

- 新路径 `@PreAuthorize`；`/mes/wm/otherinbound/**`、`/mes/wm/inboundhub/**` 不进 `MesPermitAllProvider`。
- 403/404 不泄漏他厂是否存在该 `otherId`。
- toast/API 不打印 JDBC、cipher、内部路径。

Audit and lineage:

- 新 DDL：**tenant** 业务表；**master** 菜单；不改 `backend/sql/`。
- 菜单 **9360–9364**；不占用 9300–9359。

AI/rule-engine rules:

- 不涉及；`/ai/**` 无变更。

Database rules:

- **无金额列**（对齐 112 / IH-G5 无价目对本余型）。
- **不写 yml** 业务键。
- 其他入库 **不得** secretly 写入 `wm_other_issue` / `wm_item_recpt` / 调拨表。
