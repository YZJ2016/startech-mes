### Business Goal

仓管可建 **采购退货单**（选供应商，可选关联物料入库/采购来源），校验可退数量后过账 **扣减库存**（物料退回供应商），并在出库 Hub 以 `PURCHASE_RETURN` 可见可执行。旧物料入库 / 其他出库契约不变。

**现网事实（2026-09-18，`startech-mes-basic` 检索）：**

| 项 | 现网 | 129 假设 |
| --- | --- | --- |
| 采购退货表 / Java / Vue | **无** `wm_purchase_return*`、**无** `PurchaseReturn*`、**无** `RtVendor*` / `wm_rt_vendor` | 新建头/行 + REST + Vue3 |
| 物料入库 | 现网 `wm_item_recpt` / `/mes/wm/itemrecpt`（入库 Hub `ITEM_RECPT`） | 可选关联 `item_recpt_id` 做可退上限；无关联时仅供应商+仓库手工退（T0） |
| 采购订单主档 | 若依 MES **无**完整快格式 PO 模块（以现网为准） | **`purchase_order_id` 默认 OUT 或不强制**；不以快格 PO 为硬依赖 |
| 出库 Hub | 四臂（+128 后五臂） | +`PURCHASE_RETURN` |

**对照只读：**

- 表：`PurchaseReturn` + `PurchaseReturnItem`（头行）；可空 `purchase_receipt_id` / `purchase_order_id`；必填 `supplier_id`、仓库；状态「待退货/已退货/…」+ 审核字段。
- API：`/purchase-returns` CRUD、`POST …/{id}/confirm` 过账、`POST …/{id}/withdraw`（Startech 撤回属 **OH-G7**，本单元 OUT）、拉单 `pull-from-purchase-order*`（Startech **OH-G6** / 采购拉单后置，本单元 OUT）。
- Hub：六类型之一 `purchase_return`；列表聚合独立源；可 confirm（与委外发料不同）。
- Startech：头+行；状态机 `PREPARE`→一步 `FINISHED`；**无**第二套审核流；库存 **−1**。

### Scope

In scope:

- tenant：`wm_purchase_return` / `wm_purchase_return_line`
- master：菜单 **9430–9434**
- REST：`/mes/wm/purchasereturn` (+ line)；权限 `mes:wm:purchasereturn:*`
- 规则：头 **`vendor_id`（供应商）必填**；仓库必填；可选 `item_recpt_id`（物料入库）；有入库关联则超量退拒绝；一步过账 `−1`
- Hub：`outboundType=PURCHASE_RETURN` 臂 + 抽屉执行
- Vue3 UI-A：新建页 + 出库 Hub 分支

Out of scope:

- **128** 委外发料；**112/113/114/115–117** 范围重开
- **OH-G6** 从采购订单/IQC 拉单套件；**OH-G7** 撤回（本单元 OUT；现挂 **133**）
- 快格审核流、附件 JSON、物流字段全集、金额价目（117 不强制扩本类型）、财务应付冲减/付款退款
- **CAT-W04**（盘点/调拨/组装）、**CAT-W06** 报表
- 与 **118** `RT_ISSUE`/`RT_SALSE`、**125** 委外退货混表；把采购退货塞进 **入库** Hub
- 改 Vue2；扩 PermitAll
