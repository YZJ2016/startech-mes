### Business Goal

工厂首页同一套待办数据用适合该数据的形态展示：工单四数为图标卡（80）加分组柱；质检三类、仓储两类用横向柱。不把不可加总的数画成饼图，不造按日折线。

### Scope

In scope:

- 本地封装（`import * as echarts from 'echarts'`，已在 `package.json` `echarts@5.6.0`）：
  - `views/dashboard/WorkorderCountBar.vue`：四类并排柱（全部 / 进行中 / 已完成 / 待确认），数据来自 80 已拉取的 `getIndexNum` props，**不再请求**
  - `views/dashboard/TodoHBar.vue`：通用横条，props 为 `{ label, value, to }[]`；点击柱/标签 `router.push` 与 80 同一套 path+query
- `FactoryHome.vue`：`role` 下图跟分区走；`single` 下工单卡+工单柱相邻，质检横条、仓储横条分块
- 无权限的系列不进图、不发请求（80 已保证；本单元只绑已有数据）
- 质检仅一类权限：仍用横条一根柱，不改回大数字卡
- 图初始化失败或空容器：按 H-F7 只藏该图，不崩整页
- `dispose` + `resize`；数字 0 仍画柱高 0，可点

Out of scope:

- 饼图 / 环形图 / 折线 / 雷达 / 时序接口 / 新 KPI
- 平台页任何图表
- 设备 / AI / 公告改成图（保持 80 入口与列表）
- 升级或新增 npm 依赖；改 `request.js`（静默已在 80）

### Acceptance Criteria

- 有工单权限：同时出现四张图标卡与工单柱；柱系列名与卡一致；**源码与 option 无 `pie`/`line` 作为该工单图 type**
- 有质检权限：IQC/IPQC/OQC 横条，不出现第二套与工单同款大数字卡
- 有仓储权限：入库/领料横条
- 平台回家仍无 echarts、无 `/mes/**`
- `npm run build:prod` 实跑通过；不改 `frontend/`
