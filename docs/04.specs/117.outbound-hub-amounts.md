### Business Goal

采购/财务对齐时，出库行可填单价、行金额，Hub 可见合计。金额可手工填，**不**要求先有价目主档（CAT-N3）。107 已明确不加金额列；本单元才允许加。

**现网事实（已核对 Java + Vue，禁止再标待补全）：** `WmIssueLine` / `WmProductSalseLine` 无 `unitPrice`/`lineAmount`。头表无合计金额。旧 `issue/line.vue`、`productsalse/line.vue` 与出库 Hub 抽屉均无金额列。行上有数量与 `batchCode`。

**编码前须拍板：** 加哪些可空列（对照入库 110，**本文不锁英文列名**）；是否仅 Hub 抽屉可编辑（UI-A）。不绑价目、不绑 IH-G5。

### Scope

In scope（**仅当编码门禁满足**）:

- tenant：出库行（及若需要则头）可空金额列；**不**建价目表
- Hub 抽屉可编辑加法字段；旧 `issue`/`productsalse` 页不重排（UI-A）
- 旧行 POST/PUT body 加法；URL/method 不变
