## 1. Spec

### Capability

- Name: 出库 Hub 抛光 — 出库金额列（OH-G5）
- Module: `startech-mes-basic/backend/ktg-mes`（出库行加法字段）+ Flyway tenant + Vue3 **仅**出库 Hub 抽屉展示/编辑。**禁止**改 Vue2。本单元已编码。
- Priority: Hub 抛光（挂采购/财务对齐；**不**改 107 范围声明）
- Related requirement/design documents:
  - 缺口：`docs/02.requirements/15.mes-outbound-hub-gaps.md`（**OH-G5**、OUT-F04）
  - 设计：`docs/03.design/15.mes-outbound-hub-plan.md`（§7.4）
  - 总览：`docs/02.requirements/13.mes-kuaige-capability-overview.md`（CAT-N3：不强制同开价目 CAT-M06）
  - 切片总控：`docs/04.specs/106.mes-outbound-hub-program.md`
  - 入库金额不是本单元：`110.inbound-hub-amounts-p3.md` / IH-G5（**禁止绑在一起**）

### Business Goal

采购/财务对齐时，出库行可填单价、行金额，Hub 可见合计。金额可手工填，**不**要求先有价目主档（CAT-N3）。107 已明确不加金额列；本单元才允许加。

**本会话拍板：** 行可空列与入库 110 对齐为 `unit_price` / `line_amount`（`WmIssueLine` / `WmProductSalseLine`）。头表**不**持久化合计；Hub 抽屉合计为整单行金额之和（拉全部分页，不是当前表页）。仅 Hub 抽屉可编辑（UI-A）。金额**不是**过账闸。

### Scope

In scope（编码门禁已满足）:

- tenant：出库行可空金额列；**不**建价目表；**不**加头合计列
- Hub 抽屉可编辑加法字段；头「合计」为**整单**行金额合计（拉全部分页行）；旧 `issue/line.vue`、`productsalse/line.vue` 不重排（UI-A）
- 旧行 POST/PUT body 加法；URL/method 不变

Out of scope:

- 在 107 范围声明里补金额列
- 价目主档（CAT-M06）、快财务（CAT-A01）、入库金额（IH-G5 / 110）
- Hub 打印（116）、OQC（115）
- 其他出库 / 借料行金额
- 改 Vue2、yml 开关、扩 permitAll

### Acceptance Criteria

- **编码门禁（已满足）：** 点名 117；用户明示落地 115–117；列名与 UI-A 已拍板。
- 新列可空，历史行不报错；Hub 能展示/编辑；无价目表也能手工填；旧 list URL 不变
- 第 4 节未跑命令不得写绿

### Rules and Constraints

Tenant isolation:

- 加列走 tenant Flyway；SQL 带 `tenant_id`（本单元只 ALTER 既有租户行表，不跳过隔离）
- 只信 JWT

Security and masking:

- 不把金额接口写入 `MesPermitAllProvider`
- 日志不打印凭据

Audit and lineage:

- 只进 `db/migration`；不改历史 `backend/sql/`
- 不占用 107/112/113 已用版本号；不与 110 同一脚本

AI/rule-engine rules:

- 不涉及

Database rules:

- 只加可空金额列；不建价目、不建第三张出库头表
- 不写 yml

## 2. Plan

### Implementation Approach

- tenant 加可空 `unit_price` / `line_amount`；Mapper 加法；Hub 抽屉列与合计。禁止把快格云金额模型拷进 SQL。不建价目表。

### Affected Modules

- `ktg-mes` 领料/销售出行实体/Mapper；Flyway tenant；`outboundhub` 抽屉
- 不改入库、不改快财务（无此模块）

### Public Contracts

- 旧出行 API 加法字段；无新必填
- 不加价目 REST

### Persistence Changes

- 可空单价/行金额；头合计不落库

### Transaction Boundaries

- 金额与现有行保存同一事务；无独立过账闸

### Risks

- 与 116 同改 `outboundhub/index.vue`（打印已占用 `fetchAllOutboundLines`）
- 顺手建价目表（CAT-N3）
- 与入库 110 绑同一迁移

### Verification Strategy

- 列 + Mapper + Hub 抽屉；npm / mvn 实跑后写第 4 节
