# KU-AI 场景 Tool：销售订单与采购到货预警

从 `docs/01.temlplates/01.development_unit_template.md` 复制，保留五章。状态：已实施。

## 1. Spec

### Capability

- Name: 新增只读 Tool `query_sales_orders`、`query_purchase_arrival_warnings`。
- Module: `riveredge-backend/src/apps/kuaiai/services/scene_tools.py`（或按领域拆分的新 tools 模块）、manifest `ai_tools`。
- Priority: P1（场景 S01 订单交期答复、S06 采购跟催）。
- Related requirement/design documents: 需求 25 SC-D1、SC-D5、SC-D7、SC-D12、§4.2；设计 26 §4、§5；前置 spec 189、190。

### Business Goal

计划/销售人员能问“某订单/某客户的订单交付进度如何”，采购能问“哪些采购单到货预警、逾期”，回答全部来自当前用户可见的真实单据。

### Scope

In scope:

| Tool | 视图/参数 | 底层 service（已读签名） | 权限码 | 数据范围 |
| --- | --- | --- | --- | --- |
| `query_sales_orders` | `view=summary\|lines`；`order_code?`、`customer_name?`、`status?`、`start_date?`、`end_date?`、`limit≤20` | `SalesOrderService.list_sales_orders(tenant_id, …, include_items, current_user)` | `kuaizhizao:sales-order:read` | service 内 `_apply_sales_order_list_scope(current_user)` |
| `query_purchase_arrival_warnings` | `warning_level?`、`supplier_id?`、`order_code?`、`processing_status?`、`limit≤20` | `PurchaseArrivalWarningService.list_warnings(tenant_id, …, current_user)` | `kuaizhizao:purchase-arrival-warning:read` | service 内 `_scoped_po_query(current_user)` |

- `view=summary`：单号、客户名称、状态、交期、交货进度（`delivery_progress`）；`view=lines`：每行物料编码/名称、数量、已交货数量（`delivered_quantity`）、行交期。
- 闭集参数值（status、warning_level、processing_status）在 T1 从 service/schema 读取后写死于 Tool 参数枚举。

Out of scope:

- 销售订单写操作、采购催货动作。
- 客户联系人、电话、地址、价格金额等敏感/商务字段不进返回。

### Acceptance Criteria

1. 两个 Tool 均传 `current_user=ctx.user`，返回仅当前用户数据范围内单据；越权单据不出现、不计数。
2. 返回为有界摘要文本，含总数与前 N 条；`limit` 超 20 截为 20。
3. 无数据返回真实空文案；底层异常返回固定失败文案，日志只记异常类型。
4. 不返回客户/供应商联系人、电话、地址、单价、金额。
5. 两个 Tool 登记于 manifest（`label`、`kind=read`、权限码），出现在 spec 189 目录接口。

### Rules and Constraints

Tenant isolation:

- 所有调用传 `ctx.tenant_id`；不接受客户端传 tenant。

Security and masking:

- 权限由 `tool_bridge` 按 manifest 权限码校验；数据范围由 service 现有 `current_user` 路径保证，不在适配层另写范围逻辑。

Audit and lineage:

- 沿用 `tool_bridge` Tool 级审计。

AI/rule-engine rules:

- 风险/预警级别取 service 结果，LLM 不判定。

Database rules:

- 无表结构变更。
