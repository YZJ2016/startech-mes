### Business Goal

工厂管理员为本租户登记**白名单** MCP server（地址与凭证加密落库），已登录用户的 Agent 只能连本租户已启用的条目，不能连任意远程、不能跑 SQL MCP 任意语句。管理端列表/options 不下发明文 token。

Goal：本租户 MCP 配置可 CRUD；Agent 只使用白名单内已启用 server；未登录 / 未许可 / 跨租户失败关闭。

### Scope

In scope:

- 表 `ai_mcp_server`（名可微调，列语义锁定）：`tenant_id bigint NOT NULL`、业务名、传输类型（本单元写死允许的取值，如 `http`；禁止开放任意 stdio 命令拼接）、endpoint、加密凭证列、启用状态、备注。唯一键 `(tenant_id, 业务键)`
- 加密：JDK AES-256-GCM，对齐模型密钥；主密钥只环境变量 `${AI_MODEL_CIPHER_KEY:}`，**不**复用 `TENANT_JDBC_CIPHER_KEY`。缺密钥且已有密文行 → 失败关闭（对齐 A4 风格）
- HTTP（均 `/ai` 前缀、须 JWT + `module_code=ai` 许可 + `@PreAuthorize`）：
  - 管理 CRUD：`/ai/mcp/server` 列表/详情/新增/修改/删除（精确 path 实现时与 Vue 65 对齐后冻结）
  - `GET /ai/mcp/server/options`：无 token / 无 cipher / 无解密明文（对齐 A20）
- `ktg-ai/pom.xml` 增加 `dev.langchain4j:langchain4j-mcp` **不写 version**。禁止借机上 A2A、禁止再引入过期 `langchain4j-spring-bom`、禁止全家桶匿名端点
- MCP 作为 Tool 后端：仅当该 `server id` 属于当前租户且启用；调用时带 `TenantContext`；禁止客户端传 `tenantId` 或明文 token 换连接
- 默认不开放「用户粘贴任意 URL 即连」。新增 server 必须落本租户表且管理员权限
- include 名单 + `DATABASE` 专库 catalog + 增量 `backend/sql/YYYYMMDD_NN_ai_mcp.sql`
- 单测 Mock MCP 传输；禁止 live 远程 MCP、禁止真实 token

Out of scope:

- Vue3 管理页（65）、Vue2 `frontend/`
- 受控写 Tools 实现（62）、已登录工作流编排 HTTP（64）——本单元不抢做
- 任意远程 MCP、内置 SQL MCP、`execute_sql_query`、匿名 MCP 口、`permitAll`
- 把 `/ai/**` 写入 `MesPermitAllProviderImpl`
- 改 `POST /ai/chat/send` / `POST /ai/agent/send` 信封
- Milvus / Qdrant、官方 EmbeddingStore、live 环境
- 短剧 / Harness / 匿名 `/workflow/run`（A22）
- 独立 Agent 聊天页（设计 §7 无独立 Agent 页）
- 真实 endpoint、凭据、Token 写入文档或 yml

Non-goals:

- 不做 MCP 应用市场、不做游客连接
- 不把 ruoyi-web MCP 卡片当可合并前端
- 不把 62 的 MES 写 Tool 重写成 MCP

### Acceptance Criteria

- 新表有 `tenant_id`、已进 include 与专库 catalog；无上下文访问失败关闭
- 跨租户 server id：404/403，不建连接、不调上游
- options/列表 VO 无 token、无 cipher、无解密明文
- 无 JWT → 401；未许可 `ai` → 403；不进 `MesPermitAllProvider`
- `ktg-ai/pom.xml` 含 `langchain4j-mcp` 且无手写 version；无匿名 `/mcp` 或 `/run`
- 第 4 节未编码前不得写「测试通过」

### Rules and Constraints

Tenant isolation:

- 只信 JWT / `TenantContext`；禁止请求体传 `tenantId`
- MCP server id 必须再查本租户
- 并行 MCP 调用拷贝 `TenantContext`（I-A4）；空上下文失败关闭

Security and masking:

- `/ai/**` 必须登录；MCP 口不进 `MesPermitAllProvider`
- 主密钥 `${AI_MODEL_CIPHER_KEY:}`，不复用 JDBC 密钥
- 日志、SSE、异常不打印 MCP token、apiKey、cipher

Audit and lineage:

- 增量 SQL 新文件；不改历史脚本
- `@Log` 可记 MCP 配置变更，不记明文 token

AI/rule-engine rules:

- A7：禁止 SQL MCP 跑任意语句
- 禁止全家桶匿名；禁止 A2A 借机引入
- 不改 61 已冻 Agent 信封；MCP Tool 是附加后端，不是新聊天协议

Database rules:

- 列约定与租户总控相同；新表必须 DDL + include + catalog + 单测
- yml 仅占位 `${AI_MODEL_CIPHER_KEY:}`，不写真实值、不写每租户 MCP URL 清单

## 2. Plan

### Implementation Approach

1. 增量 DDL + include + 专库 catalog。
2. 复用现网模型加密类风格（独立用法，同一 `AI_MODEL_CIPHER_KEY`），凭证列只存密文。
3. 薄 Controller + `ktg-ai` service：CRUD / options 打码。
4. `langchain4j-mcp` 无 version；运行时只对白名单行建客户端，懒建，改密文/删行 evict。
5. 挂到 Agent Tool 提供者：按 server id 解析本租户行。
6. Mock 单测；不连 live MCP。

### Affected Modules

- `ktg-ai`（domain/mapper/service/controller/tool 桥）
- `ktg-ai/pom.xml`（`langchain4j-mcp` 无 version）
- include 名单、专库 catalog、增量 SQL
- `ktg-admin` 仅当需要薄转发（优先 `ktg-ai` Controller 已挂 `/ai/**`）
- 不改：`frontend/`、本单元默认不改 `startech-mes-front/`、`MesPermitAllProviderImpl`、chat/agent 信封

### Public Contracts

APIs, facades, DTOs, events, or database contracts:

- 新增 `/ai/mcp/server` CRUD + `/options`（非 SSE，`code/msg/data` 与 `rows`/`total`）
- **冻结不变：** `POST /ai/chat/send`、`POST /ai/agent/send` 信封
- 禁止无前缀 MCP 匿名口；禁止 `/system/message`

### Persistence Changes

Tables, indexes, migrations, mapper XML, and lifecycle rules:

- 新建 `ai_mcp_server`（及若实现需要的附属表，必须同样 `tenant_id`）
- 增量 `YYYYMMDD_NN_ai_mcp.sql`；菜单种子若本单元就加，须 `module_code=ai`（Vue 接线仍 65）

### Transaction Boundaries

- 保存配置：校验 + 加密 + insert/update 同一短事务
- MCP 调用不包住整个 Agent 循环
- 改 token 成功后 evict 客户端缓存，不把 evict 放进长事务

### Risks

- 开放任意 URL / stdio 命令导致 SSRF 或本机命令执行
- SQL MCP 或「把用户语句转发给远程」绕过 A7
- 列表回明文 token；日志打印 cipher
- MCP 口进 `permitAll` 或匿名 `/run`
- 借机引入 A2A / agentic 全家桶
- 未进专库 catalog 的 `DATABASE` 租户写主库

### Verification Strategy

- `mvn -pl ktg-ai -am test`（实现后）
- 静态：pom 无 mcp version；yml 无真实 URL/token；permitAll 无 `/ai`
- 隔离单测：跨租户 404；options 无密文
- 不跑 live MCP、不跑 Vue `build:prod`（65 再跑）
