## 用户故事

平台运营给某工厂勾选一个行业模块许可后，该厂还须在「角色管理」勾选 9200 段，已登录 Vue3 管理端侧栏才出现**一个**「行业包」分组，下面是该模块自己的页（P0 为说明桩页）。仅许可、角色未勾 → 侧栏无行业包，MES 其余功能照常。关掉许可后分组与页消失。从未开通的工厂与今日一致（IP-D20）。通用 MES（工单 / BOM / 工艺）菜单不因本轨被改写或换组件。两家工厂互不影响。

- [x] **IP-D2** 壳怎么落地。**已拍板：全局 `sys_menu` 一棵「行业包」目录 + 许可过滤。** 启用模块的「重建菜单」在 MES 上等于：写 `sys_tenant_license` 之后，下一次 `GET /getRouters` 出现该目录。 **禁止**按租户 INSERT/UPDATE/DELETE `sys_menu` 行来「重建」。不重开 39。
- [x] **IP-D3** 谁启用。**已拍板：仅平台运营。** 沿用现网 `PUT /platform/tenant/{id}/licenses`。不给工厂做应用中心、不新开「启用行业包」HTTP。不重开 F3。
