## 用户故事

多家厂共用平台 Weaviate 时，检索只扫本厂分片，不因知识库数量把 class 堆到 Weaviate 的 collection 上限。不能出厂的厂仍走 DEDICATED 自建 Weaviate，同一套适配器，不维护两套 schema 规则。对话与解析的 HTTP 不变；工厂仍不能改集群地址。

## 现网事实（以代码为准，禁止臆造）

核对仓库：`startech-mes-basic/`（2026-09-10）。

| 项 | 现网 |
| --- | --- |
| 适配器 | `WeaviateHttpVectorStore`：JDK HTTP；`vectorizer: none`；**未**开 `multiTenancyConfig` |
| Class | `MesAiK{tenantId}_{knowledgeId}`（`VectorStoreSupport.collectionName`，**与 DashVector 共用**） |
| 过滤 | 对象属性 `tenant_id` / `kid` / `docId` / `fid`；GraphQL `where` 两条；无 tenant 请求头 |

| 验收 | Maven mock HTTP；**未连 live Weaviate** |
| DashVector | collection 仍 `MesAiK*` + partition `t{tenantId}`；本轨 **不得**改其命名 |

## WM-D — 产品决策

- [x] **WM-D1** 结合方式。**已拍板：Weaviate 库内用官方 multi-tenancy；不替代 A14。** SHARED 仍是平台 yml 那一台；DEDICATED 仍是专行 host/Key、禁止回落 yml。原生 MT 只解决「一台 Weaviate 里怎么分厂」，不让专库消失，也不新造第三档。
- [x] **WM-D2** tenant 名。**已拍板：`t{tenantId}`，只信 `TenantContext`。** 禁止客户端 / body / 知识库表单传入 Weaviate tenant。空上下文不得建 tenant、不得写、不得搜。
- [x] **WM-D3** collection。**已拍板：`MesAiD{dimension}`（如 `MesAiD1536`），按 embedding 维度，不按知识库。** 对齐 A13「维度创建 collection 时写死」。禁止再为每个 kid 建 class。同一厂、同一维度的多个知识库共用 class + 同一 Weaviate tenant，用 `kid` 区分。
- [x] **WM-D4** I-A3 不放松。**已拍板：** 对象仍写 `tenant_id`、`kid`、`docId`、`fid`；search / delete 的 `where` 仍 `tenant_id` **且** `kid`。原生 tenant **替换的是 class 网格**，不是属性过滤。禁止只靠 Weaviate tenant、禁止只靠 kid。
- [x] **WM-D5** 一适配器。**已拍板：`type=weaviate` 的 SHARED 与 DEDICATED 走同一 `WeaviateHttpVectorStore`。** 禁止 SHARED 开 MT、DEDICATED 仍 `MesAiK{tid}_{kid}` 双路径。专集群上仍创建 `t{tenantId}` tenant（单厂也一致）。
- [x] **WM-D6** 维度不一致失败关闭。**已拍板：** 写入 / 检索向量长度必须等于目标 class 的 dimension。对不上 → 失败，不静默写入其它 class，不建「兜底」class。
- [x] **WM-D7** 删除要带维度。**已拍板：** 内部 SPI `removeByDoc` 增加 `dimension`（调用方从该知识库 embedding 模型维度传入）。Weaviate 缺维度或 ≤0 失败关闭。DashVector **忽略**该参数，仍按现网 `MesAiK{tid}_{kid}` 删。不改对外删除附件 HTTP。
- [x] **WM-D8** 契约范围。**已拍板：不改** `/ai/knowledge/**`、`/ai/chat/send`、`/ai/agent/send`、`GET/PUT /platform/tenant/{id}/vector-store` 的 URL / method / 认证 / 信封。不改 93 字段（无 tenant 名、无 class 名给运营填）。不换 `langchain4j-weaviate`。
- [x] **WM-D9** DashVector / 其它引擎。**已拍板：本轨只改 Weaviate。** `collectionName(tenantId, kid)` 对 DashVector 保持 `MesAiK{tid}_{kid}`。不实现 Pinecone / Milvus / Qdrant；不把 Weaviate tenant 抄进 DashVector partition 以外的行为。
- [x] **WM-D10** 明确不做。**已拍板：本期不做** 旧 `MesAiK*` class 自动迁移（WM-G2）；Weaviate 按租户签发 API Key / RBAC（WM-G3）；hybrid BM25；官方 EmbeddingStore；知识库页 / 向导新字段；Vue2。

## WM-I — 隔离 / 权限

- [x] **WM-I1** 所有 Weaviate 写 / 搜 / 删必须带 tenant `t{TenantContext}`（REST 头或 GraphQL `tenant`，实现见 100）。漏带则不得落到「默认租户」或全 collection 扫描。
- [x] **WM-I2** 只信 JWT / `TenantContext`。`search` 的 `tenantId` 必须与上下文相等（现网 `VectorStoreSupport.requireTenantId` 保留）。
- [x] **WM-I3** SHARED 的 API Key 仍是集群级；原生 MT **不是**密钥隔离。文档与手册必须写明这一点，避免把 shard 当成专库。
- [x] **WM-I4** 日志 / 异常不打印 Weaviate API Key、host 口令、内部路径。`/ai/**` 不进 `MesPermitAllProvider`。

## WM-F — 前端

- [x] **WM-F1** **已拍板：本轨无产品 Vue。** 不改知识库表单、不开通向导字段、不改 `startech-mes-front` 业务页。手册文案见 **102**（`docs/05.manuals/02.ai-assistant-user-manual.md`）。不改 Vue2。
