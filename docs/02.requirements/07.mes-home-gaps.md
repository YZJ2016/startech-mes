- 轨道：Vue3 管理端登录后 `/index`。工厂工作台与平台回家工作台分开；工厂布局可由本厂参数覆盖。

- 开发单元：`docs/04.specs/79.mes-home-backend.md` → `80.mes-home-vue3-workbench.md` → `81.mes-home-vue3-charts.md`
- 业务代码：`startech-mes-basic`（`startech-mes-front/` + `backend/`）；本文只落在外层 `docs/`
- 状态：`[ ]` 开放 · `[x]` 已收口（产品决策类在本文件拍板后标 `[x]`；实现证据标 `[x]` 时须有对应 spec 第 4 节）
- 分类：`H-D` 产品决策 · `H-I` 隔离/权限 · `H-F` 前端 · `H-X` 实现证据
- 前提：多租户 D11（平台回家走角色菜单）、F1（只改 Vue3）、D1（`sys_config` 全局 + overlay）；`AGENTS.md` 红线 10（运营可改配置走参数设置，不写 yml）。成熟度评估见 `docs/03.design/01.mes-business-maturity-assessment.md`（单据型 MES，首页不假装已有驾驶舱指标）。

## H-D — 产品决策

- [x] **H-D1** 谁用首页。**已拍板：两套首页。** 平台回家（`tenant_id=0` 且非 runAs）一套；工厂会话与 runAs 进厂共用工厂工作台。不得把工单/库存/质检数字挂到平台回家。
- [x] **H-D2** 工厂布局如何选。**已拍板：本厂参数覆盖。** 键 `mes.index.layout`，值 `single`（一张厂页平铺）或 `role`（按生产/仓储/质检/设备分区）。未覆盖吃全局默认 `single`。走现有 `sys_config` overlay（D1），不开通租户时复制 `sys_config`。
- [x] **H-D3** `role` 如何认出岗位。**已拍板：按菜单权限自动归区。** 有对应 `list` 权限才出该区卡片。不新增首页画像、不按 `role_key` 写死、不在角色管理挂首页类型。一人多权限则多区叠在同一页。
- [x] **H-D4** 两种布局是否两套数据。**已拍板：同一套卡片、两种排法。** `single` 平铺；`role` 只加分区标题。不各写一套接口。
- [x] **H-D5** 首页是驾驶舱还是工作台。**已拍板：工作台。** 第一期只放已有或能从现有列表 `total` 数出来的待办与工单三态。不造 OEE、一次合格率、缺料、稼动等新 KPI。教育/合同/售后/摄像头不上首页。
- [x] **H-D6** 同厂没权限的人能否看见数字。**已拍板：不能（界面 + 接口）。** 无对应权限字则不渲染、不请求；首页打到的接口须 `@PreAuthorize`，无权限 403。不是部门/本人数据范围（MES 工单/库存仍按租户，不按部门裁）。
- [x] **H-D7** 厂与厂、平台与工厂。**已拍板：现有租户门禁不变。** A 厂看不见 B 厂。工厂进不了 `/platform/**`。平台回家不调 `/mes/**`。
- [x] **H-D8** 管理端。**已拍板：只改 Vue3**（`startech-mes-front/`）。不改遗留 `frontend/`。不新增首页路由（仍 `/index`）。
- [x] **H-D9** 是否新建首页汇总 API。**已拍板：不建大一统驾驶舱接口。** 工单三态沿用并扩展 `GET /mes/pro/workorder/getIndexNum`；其它待办用现有 list 的 `total`（`pageSize=1`）。待领料真实路径为 `GET /mes/wm/issueheader/list`（权限 `mes:wm:issueheader:list`），不是 `/mes/wm/issue`。
- [x] **H-D10** 设备区。**已拍板：第一期只给入口。** 有维修/点检菜单才出现跳转，不做汇总数字。
- [x] **H-D11** AI。**已拍板：有许可与对话权限才给出入口。** 不在首页嵌完整会话。
- [x] **H-D12** 公告/消息。**已拍板：用现有本租户公告与站内信。** 不做平台群发（S5 不重开）。
- [x] **H-D13** 平台是否读工厂布局参数。**已拍板：不读。** `mes.index.layout` 只作用于工厂工作台。平台改全局默认只影响尚未 overlay 的厂。
- [x] **H-D14** 工厂如何改布局。**已拍板：参数设置新增/修改本厂 overlay 行。** 工厂列表看不到全局内置行；删除 overlay 后回到全局默认。不为首页再做「我的布局」拖拽或用户级偏好。
- [x] **H-D15** 布局开关落点。**已拍板：只走参数设置，不写 yml。** 对齐 `AGENTS.md` 红线 10：`mes.index.layout` 用增量 SQL 种子 `sys_config`，运行时读 `ISysConfigService.selectConfigByKey`（前端走已有 `configKey` 接口）。禁止新增 yml 键、`@Value`、`@ConfigurationProperties`。密钥仍不进 yml，也不明文进参数表（本键不是密钥）。
- [x] **H-D16** 统计怎么展示。**已拍板：按数据形态选形态，不要整页同一套数字卡。** 图标卡、柱状图、列表、入口磁贴按块选用（映射见设计）。禁止为填图表新增 KPI 或时序接口；禁止把互不互斥、不可加总的数字画成饼图。`single` / `role` 只改排法，不改各块形态。平台回家无 MES 数字，只用图标入口，不上图。

## H-I — 隔离 / 权限

- [x] **H-I1** 恢复哪些按钮权限。**已拍板：只恢复首页会请求的接口。** 不在本轨重开全部 `ktg-mes` 被注释的 `@PreAuthorize`。
- [x] **H-I2** 工单三态接口。**已拍板：** `getIndexNum` 增加 `prepareNum`（`PREPARE`）；加上 `mes:pro:workorder:list`。待确认工单不打沉重的工单 `/list`。
- [x] **H-I3** 403 与全局 toast。**已拍板：** 首页这几发请求可静默非 401 错误（避免并发弹一串通知）；其它页面默认行为不变。某块失败只藏该块。
- [x] **H-I4** 配置落点。**已拍板：** 全局行 `tenant_id` 空、内置 `Y`；工厂 overlay `tenant_id` 为本厂。`sys_config` 仍是全局表（I8），不进专库 catalog。
- [x] **H-I5** 日志与契约。**已拍板：** 不改既有 list URL / method / `code/msg/data` 与 `rows/total`。日志不打印 token、cipher、内部路径。
- [x] **H-I6** runAs。**已拍板：** 进厂后读**目标厂** overlay 与**目标厂**业务数据，与工厂用户同一套工厂工作台。

## H-F — 前端

- [x] **H-F1** 分流。**已拍板：** `index.vue` 按 `isPlatformTenant && !isRunAs` 选平台页，否则工厂页。用现有 user store，不新造身份接口。
- [x] **H-F2** 权限判定。**已拍板：** `auth.hasPermi` 与侧栏同一套 `getInfo` 权限字。
- [x] **H-F3** 空态。**已拍板：** 加载用骨架；数字 0 仍可点进空列表；工厂无任何 MES 块时一句「暂无业务待办」，公告/消息有则仍显示。去掉整页大字「欢迎使用本系统」作为主体。
- [x] **H-F4** 点击。**已拍板：** 跳转现有列表并带同一状态（工单待确认用 `PREPARE`）。不新开待办详情页。
- [x] **H-F5** 依赖。**已拍板：** 不升级 Vue / Vite / Element Plus / echarts；不提交 lockfile；不引入第二套图表库（含 vue-echarts）。首页图用已有 `echarts`，组件写在 `views/dashboard/`。
- [x] **H-F6** 参数读取。**已拍板：** `GET /system/config/configKey/mes.index.layout`；失败或非法值当 `single`，不挡整页。
- [x] **H-F7** 图表失败。**已拍板：** 某块图初始化或数据失败，按 H-I3 只藏该块；不因图挂整页。无数据时仍按 H-F3 显示 0，可点进空列表。
