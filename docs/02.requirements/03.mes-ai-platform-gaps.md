# MES 多租户 AI 平台缺口清单

- 与 Phase 1 内嵌助手的关系：`docs/02.requirements/04.mes-ai-phase1-gaps.md` 与 `docs/04.specs/57`–`59` 是 **MES 内嵌助手 Phase 1**（无 RAG / 无工厂 `ai` 套餐）。本文件与 `48`–`56` 仍是**后续平台轨道**。Phase 1 实现者不要用本清单的 A1/A5/A9 覆盖 04 的已拍板决策。
- 轨道：在 `feature/mes-multi-tenant` 上并行建设 AI 平台；AI 是租户许可能力（`mes_module.ai`），不是第二套认证或第二套租户
- 设计：`docs/03.design/06.mes-ai-platform-plan.md`
- 开发单元总控：`docs/04.specs/48.mes-ai-platform-program.md`（阶段单元 `49`–`56`；本清单落盘时未改 Java/SQL）
- 对照参考（只读，不合并）：`ruoyi-ai` 后端、`ruoyi-web` 用户对话端
- 状态：`[ ]` 开放 · `[x]` 已收口（收口时在对应 spec 第 4 节写证据，并把本文件该项改为 `[x]`；产品决策类可在设计「已拍板决策」表收口）
- 分类：`A` 产品决策 · `I` 集成/隔离 · `F` 前端 · `V` 向量库
- 禁止在文档中写入真实服务地址、凭据或内部敏感路径

本轮产品决策 **A1–A22、I-A1–I-A6、F-A1–F-A4、V1–V4** 已拍板。拆 spec 不等于代码完成。

## A — 产品决策

- [x] **A1** 目标形态。**已拍板：做 AI 平台**（模型、会话、知识库、后续工具），不是「MES 里嵌一个助手」的终态。第一版先交付可运营的最小平台。
- [x] **A2** 首家对话供应商。**已拍板：OpenAI 兼容**（可配 `baseUrl` + 模型名）。不在第一版并行接入智谱原生 / 百炼原生 / 仅 Ollama 专用协议。
- [x] **A3** 模型密钥存放。**已拍板：按租户加密落库。** 列表打码；API 不回传明文或 cipher。揭明文若做，仅本租户管理员、写审计且审计不记明文。
- [x] **A4** 加密主密钥。**已拍板：** 算法与 JDBC 相同（AES-256-GCM）。主密钥只来自环境变量 `AI_MODEL_CIPHER_KEY`，**不**复用 `TENANT_JDBC_CIPHER_KEY`。密钥轮换不进本期。缺密钥且已有加密模型行 → 拒启动（对齐 S6 门禁风格）。
- [x] **A5** 知识库。**已拍板：要。** 原文在 MySQL 片段表 + MinIO 附件；向量库只存向量与引用 id。
- [x] **A6** 向量库批次。**已拍板：A 方案。** 第一批 Weaviate / Milvus / Qdrant 策略工厂（部署只开一种）；紧接着第四策略 DashVector。不要四种齐头并进当同一单元。
- [x] **A7** Agent 与 MES 库。**已拍板：不能直连。** 后续用可配置 Tools 提供只读/白名单能力；禁止内置 `execute_sql_query` / `query_all_tables`。Tools/Agent **不进 49–56**。
- [x] **A8** 第一版前端形态。**已拍板：内嵌 `startech-mes-front`。** 不另开用户对话端；不部署、不改 `ruoyi-web` baseURL。
- [x] **A9** 分支与许可。**已拍板：** 与租户同分支 `feature/mes-multi-tenant` 并行。AI 是租户能力：`mes_module` 增加 `ai`，写入 `sys_tenant_license`。未许可拒绝 `/ai/**` 且 `getRouters` 不出现 AI 菜单。
- [x] **A10** 与 ruoyi-ai 关系。**已拍板：只参考，不整仓合并。** 不引入 Sa-Token、MyBatis-Plus、第二套 JWT、`org.ruoyi` 包。
- [x] **A11** HTTP 前缀。**已拍板：一律 `/ai/**`。** 禁止复用 ruoyi-ai 的 `/system/message|session|info|attach`、`/chat/send`、`/auth/login`。
- [x] **A12** Maven 落点。**已拍板：新建 `ktg-ai`，`ktg-admin` 依赖。** 不塞进 `ktg-mes` / `ktg-system`。包名 `com.ktg.ai`。`ktg-admin` Controller 保持薄。
- [x] **A13** Embedding。**已拍板：** 与对话同一条 OpenAI 兼容协议（可另配 embedding 模型名与维度）。维度创建向量 collection 时写死。
- [x] **A14** 向量集群归属。**已拍板：平台基础设施。** endpoint / API Key 只放环境变量，不按工厂落库。工厂只管本租户模型密钥。
- [x] **A15** 认证。**已拍板：复用现有 JWT / `LoginUser` / 手机号登录分支。** `/ai/**` 必须登录。禁止第二套 `SecurityFilterChain`。禁止把聊天口写进 `MesPermitAllProvider`。
- [x] **A16** 上传。**已拍板：默认仍 `POST /common/uploadMinio`。** 知识附件走 MinIO + `tenant/{id}/` 前缀（I2）。不引入 OSS 为默认上传。
- [x] **A17** SSE 契约。**已拍板：MES 自定** `POST /ai/chat/send`（SSE）。事件字段先只要 `content`（可选 `reasoning`）。不在第一版兼容 ruoyi-ai 的 MCP / `[NODE_CHUNK_*]` 工作流帧。
- [x] **A18** 独立对话端。**已拍板：v1 不做。** 以后若给进不了管理端的人用，再开端并补登录/SSO；不在 49–56 预埋第二套账号。
- [x] **A19** 游客对话。**已拍板：禁止。** 不复制 ruoyi-web「未登录可进 `/chat`」。
- [x] **A20** 模型列表 VO。**已拍板：永不下发 `apiKey` / cipher / apiHost 口令。** 用户可选模型只回 id、展示名、模型名。
- [x] **A21** `DATABASE` 租户。**已拍板：AI 表必须进入专库 catalog / 同一套增量。** 未迁成功则该厂 AI 失败关闭，禁止回落主库写共享库。
- [x] **A22** Tools/Agent/工作流/短剧/Harness。**已拍板：不进本期 49–56。** 工作流匿名 `/run`、内置 SQL MCP、短剧、Coding Harness 明确不搬。

## I — 集成 / 隔离

- [x] **I-A1** 行级隔离。**已拍板：** AI 表 `tenant_id bigint NOT NULL`，加入 `tenant.line.include-tables`。无上下文访问失败关闭。INSERT 填充/校验。
- [x] **I-A2** 许可闸。**已拍板：** 除平台账号外，调用 `/ai/**` 须当前租户有效 `module_code=ai` 许可；过期视为未许可。平台模块永不许可给工厂的规则不变（F3）。
- [x] **I-A3** 向量隔离。**已拍板：** 写入/检索必须带 `tenant_id`。允许「collection/class = 前缀 + kid」但查询仍要过滤 `tenant_id`，禁止只靠 kid 防串租。
- [x] **I-A4** 异步对话。**已拍板：** SSE/embedding 线程沿用 `TenantTaskDecorator`，不用 `InheritableThreadLocal`。空上下文不得调向量库、不得写租户文件键。
- [x] **I-A5** 日志。**已拍板：** 不打印模型 Key、DashVector/Weaviate/Milvus/Qdrant token、JWT、MinIO 凭据、内部绝对路径。异常对前端不回密钥。
- [x] **I-A6** 配置根键。**已拍板：** 应用根键保持 `ruoyi:`。AI 段用占位环境变量（如 `${AI_MODEL_CIPHER_KEY:}`、`${VECTOR_STORE_TYPE:weaviate}`），不写真实值。

## F — 前端

- [x] **F-A1** 只改 Vue3 `startech-mes-front/`。**不改**遗留 `frontend/`。
- [x] **F-A2** 依赖。**已拍板：第一版不引入** `vue-element-plus-x`、UnoCSS、`hook-fetch`、TypeScript 工程形态。气泡/输入用现有 Element Plus 重做。禁止为聊天升级 Vue / Vite / Element Plus，禁止提交 lockfile。
- [x] **F-A3** 交互蓝本。**已拍板：** 对照 `ruoyi-web` 的会话列表、模型下拉、SSE 气泡；不搬登录弹窗、扫码、注册、应用市场、MCP 卡片、工作流 runner。
- [x] **F-A4** 页面。**已拍板：** 全宽 `/ai/chat`（弱化 tagsView）+ 模型配置 + 知识库管理。均走现有 `request.js` Bearer JWT。

## V — 向量库

- [x] **V1** 策略工厂。**已拍板：** `VectorStoreService` 风格接口；`type=weaviate|milvus|qdrant|dashvector`。未知 type 失败关闭，不静默落到「不隔离的内存库」。
- [x] **V2** 第一批三种。**已拍板：** 重写适配，不复制 ruoyi-ai 的 MyBatis-Plus Mapper。本地默认建议 `weaviate`（单容器）。
- [x] **V3** DashVector。**已拍板：** 第四策略，独立单元 56。官方 SDK 或 HTTP；平台 Cluster；Partition 或 Field 带 `tenant_id`。
- [x] **V4** 不自建多种同时运行。**已拍板：** 一个进程只连一种。三种实现可共存于代码，配置只激活一个客户端。
