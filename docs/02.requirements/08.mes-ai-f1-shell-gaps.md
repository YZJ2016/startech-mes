## 用户故事

已登录且具备对话相关权限的工厂用户，在**任意**管理端业务页按 **F1**（或点顶栏「助手 (F1)」）打开同一只抽屉，用当前页/当前单的标签跟既有会话说话。不离开当前单据。无对话权限时 F1 不拦截，浏览器默认帮助页照常。

## 现网事实（以代码为准，禁止臆造）

核对仓库：`startech-mes-basic/startech-mes-front/`、`backend/ktg-ai/`（2026-09-08）。

| 项 | 现网 |
| --- | --- |
| 独立会话页 | Vue3 路由 `/ai/chat`，组件 `src/views/ai/chat/index.vue` |
| 会话 HTTP | `GET/POST /ai/session`；`GET /ai/session/{id}`；`PUT/DELETE /ai/session/{id}`；`GET /ai/session/{id}/messages`。封装 `src/api/ai/session.js`。权限字 **`ai:chat:list`** |
| 纯对话发送 | `POST /ai/chat/send`，`text/event-stream`；`@PreAuthorize('ai:chat:send')`。封装 `src/api/ai/chat.js` `sendChatStream`。Bearer 与 `getToken()` 相同 |
| Agent 发送 | `POST /ai/agent/send`，同一 DTO `AiChatSendRequest`，同一权限字 **`ai:chat:send`**。封装 `src/api/ai/agent.js` `sendAgentStream` |
| 现网 POST body | `{ sessionId?, modelId, content, knowledgeId?, agentId? }`。**无** `context` 字段 |
| SSE 信封 | `data:` 行 JSON 基础信封 `{ content, done }`；扩展字段白名单 `error` / `reasoning` / `status` / `tool` / `step`（允许出现，不要求前端必显） |
| 权限字 | **没有**名为 `ai:chat` 的单一权限。现网是 `ai:chat:list` 与 `ai:chat:send` |
| Navbar | `startech-mes-front/src/layout/components/Navbar.vue`。右侧有 HeaderSearch / 主题 / 通知，**无**助手按钮、**无** F1 监听 |
| 布局 | `startech-mes-front/src/layout/index.vue`。**无**全局 `keydown` |
| 菜单搜索 | `src/components/HeaderSearch/index.vue`。仅点击图标打开；**无** `/` 热键 |
| 工作台 AI | `src/views/dashboard/FactoryHome.vue`：`showAi = auth.hasPermi('ai:chat:list')`，点击 `router.push('/ai/chat')`。**无** `dispatchEvent` |
| Vue2 | `frontend/` 另有 Navbar，本轨不改 |

## S-D — 产品决策

- [x] **S-D1** 目标形态。**已拍板：壳层助手，不是第二套对话运行时。** 任意已登录管理端页（含 `/ai/chat`）F1 打开同一抽屉。独立全宽 `/ai/chat` **保留**。同一套 `ai_session` / 模型 / SSE / Agent 档案选择规则（A36：未选档案走 `chat/send`，选中走 `agent/send`）。
- [x] **S-D2** 热键与权限。**已拍板：** 在布局或 Navbar 上 `keydown` 捕获 `F1`，有权限则 `preventDefault` + **toggle** 抽屉（再按关闭）。焦点在 input / textarea / contenteditable 内**仍拦截** F1（F1 不是可输入字符；不拦会弹出浏览器帮助）。拦截条件与工作台 AI 入口同一字：**`ai:chat:list`**。无此字**不拦截**（不 `preventDefault`）。发送仍要 **`ai:chat:send`**。不存在的 `ai:chat` 不得写进代码当权限字。
- [x] **S-D3** 页面上下文。**已拍板：** Pinia（推荐 `src/store/modules/aiContext.js`）放 `aiContext`；业务列表/详情 `onMounted` 写入；keep-alive 下 `onDeactivated` 清空、`onActivated` 恢复 `LIST_CONTEXT`（查看对话框仍打开时才补单据字段）；`onUnmounted` 仍清空。字段冻结见设计 09 的 `MesAiContext`。P0 至少工单列表写入；打开同页「查看」对话框时补单据字段；**关闭查看后回到列表态，清掉 `resourceKey` / `recordId` / `recordLabel`**。其它页同一约定后续加，不要求本轨扫全站。
- [x] **S-D4** HTTP 增量。**已拍板：** 现有 `POST /ai/chat/send` 与 `POST /ai/agent/send` 增加**可选** `context`（与 `AiChatSendRequest` 同 DTO）。URL、method、认证头、`code/msg/data`、SSE `{content, done}` 基础信封 **不变**（扩展白名单见 A17）。缺 `context` 或服务端解析不出可信标签 = 现网行为，不多拼 system 句。**忽略**客户端 `screenLabel` / `recordLabel`（抽屉标题仍可用前端 store 展示，不进 prompt）。屏名只认服务端 `screen` 白名单（现网：`mes.pro.workorder.list` / `mes.pro.workorder` →「生产工单」；`mes.home.factory` →「工厂工作台」；未知 `screen` 不拼页名）。单据侧只信服务端按 `resourceKey`+`recordId` 查库得到的工单号（无权限 / 未知资源 / 查不到则省略单据侧）。拼句格式：「用户正在 {screenLabel}，单据 {recordLabel}」（缺一侧则省略该侧，不编造）。
- [x] **S-D5** 抽屉。**已拍板：** 右侧 `el-drawer` `direction=rtl`，宽约 400–480（实现可微调）。**不用**右下角自研浮层。标题旁展示当前 `screenLabel` / `recordLabel`（无则只写「助手」）。**第一次打开再挂载**聊天组件；此后保持挂载。瘦面板须有「打开对话页」链到 `/ai/chat`。不在首页嵌完整会话。
- [x] **S-D6** Tooltip。**已拍板：** 顶栏入口文案 **「助手 (F1)」**。
- [x] **S-D7** P0 明确不做。**已拍板：P0 不做** 按 `resourceKey+recordId` 拉业务摘要、工作台预填、写库 Agent / `confirmToken`、改 Vue2、把 `/` 绑成助手、新开 `/ai/**` path、把聊天口写进 `MesPermitAllProvider`。
- [x] **S-D8** `/` 不抢（P0 即锁）。**已拍板：** F1 处理器只认 `event.key === 'F1'`（或等价 `keyCode === 112`）。**禁止**用 `/` 打开助手。P0 不改 HeaderSearch。
- [x] **S-D9** P1 只读摘要。**已拍板：** 发送时若 `context.resourceKey` + `recordId` 齐全，`ktg-ai` **服务层**调现有 MES service 拼短摘要（状态、数量）。**85 本期省略缺料句**（现网无以缺料/齐套命名的可复用 service，禁止临场新造；对齐 H-D5）。缺料能力留开放缺口 **S-G1**。禁止整单 JSON 进 prompt。禁止 JDBC / 任意 SQL。未知 `resourceKey` 跳过摘要；P0 标签句仍按 **S-D4**（白名单 `screen` / 服务端单据号），不回退到客户端 label。
- [x] **S-D10** 工作台预填。**已拍板：** 工厂工作台 AI 卡改为 `window.dispatchEvent` 打开**同一抽屉**并带预设问题（写入输入框，**不自动发送**）。`detail.preset` **锁死**为 `帮我看看当前工作台的待办和工单`。**不回退** `router.push('/ai/chat')`（84 先落地，壳与工作台同在已登录布局）。仍不嵌完整会话（不重开 H-D11）。无 `ai:chat:list` 时卡不出现（现网已如此）。
- [x] **S-D11** P1 的 `/` 与 F1。**已拍板：** `/` 给菜单搜索（HeaderSearch）。P1 可补：焦点不在可编辑控件时，`/` 打开 HeaderSearch 并 `preventDefault`。F1 仍只开助手。输入框内敲 `/` 必须仍是字符 `/`，不得被助手或菜单搜索抢走。
- [x] **S-D12** 更晚不做。**已拍板：本期仍不做** 对话二次确认（`confirmToken` 或等价 UI）；追踪见 `docs/02.requirements/05.mes-ai-runtime-hardening-gaps.md` **R10**。本 F1 两期仍不做第二套认证、AI 直连业务库 SQL、独立用户对话端。不把确认闸或写库执行面塞成本轨新能力。
- [x] **S-D13** 窄屏图标。**已拍板：** 顶栏「助手 (F1)」跟现网工具图标同一规则：`device !== 'mobile'`（布局宽度 **&lt; 992** 为 mobile）才显示。窄屏无按钮；有 `ai:chat:list` 时 F1 仍可开抽屉（实体键盘）。不假设平板为交付端。
- [x] **S-D14** 全宽页 context。**已拍板：84/85 都不改** `views/ai/chat/index.vue` 发送体。全宽页继续不传 `context`。契约仍是可选字段，旧客户端不受影响。
- [x] **S-D15** 开工前行为（U1–U10，2026-09-08）。**已拍板：** U1 右侧 drawer；U2 窄屏不显示图标；U3 全宽页不传 context；U4 工作台不回退路由；U5 本期省略缺料句并记 **S-G1**；U6 输入框内仍拦 F1；U7 toggle；U8 关查看清单据字段；U9 抽屉有「打开对话页」；U10 preset 锁死上文句子。

## S-I — 隔离 / 权限

- [x] **S-I1** 租户。**已拍板：** `context` **禁止**带 `tenantId`。只信 JWT / `LoginUser` / `TenantContext`。跨租户 `recordId` 摘要失败关闭，不回他厂字段。
- [x] **S-I2** 摘要鉴权。**已拍板：** 拉摘要必须复核该资源既有 list/query 权限字（工单至少 `mes:pro:workorder:list` 或 `query`，以实现时现网注解为准）。无权限 = 不调 MES service，prompt 不加摘要，不 500。
- [x] **S-I3** 匿名面。**已拍板：** `/ai/**` 必须登录；不进 `MesPermitAllProvider`。不新开匿名摘要口。
- [x] **S-I4** 脱敏。**已拍板：** 日志 / SSE / toast **不**打印 apiKey、cipher、JWT、内部路径。摘要与标签不得含密钥。`context` 不回显到 SSE。客户端 `screenLabel` / `recordLabel` **不**进 system（S-D4）。

## S-F — 前端
