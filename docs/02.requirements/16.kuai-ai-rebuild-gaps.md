## 用户故事

组织管理员在管理端维护 LLM 连接、知识库与 Agent 档案（勾选 Tool / MCP / 知识库，按角色或人员授权）。已登录员工在全宽对话页或顶栏助手中选择档案对话；系统按档案装配 Agent 运行，工具调用受权限约束，写操作经白名单 Tool 走既有业务 service。对话内容持久化，重新打开会话可见完整历史（含工具调用轨迹）。

## KR-D — 产品决策

- [x] **KR-D1** 目标形态。**已拍板：按 ktg-ai 领域模型重建 AI 平台产品层。** 覆盖：会话/消息持久化、模型目录（KR-D5）、知识库、Agent 档案+授权、受控写 Tools、MCP 白名单；工作流见 KR-G4。**不是**修补 `core/ai`，也不是把私仓 KU-AI 当黑盒接入。
- [x] **KR-D2** 落点。**已拍板：新建 `apps/kuaiai`（后端）+ `apps/kuaiai`（前端），占私仓预留槽位。** 委托探测自动生效；复用已迁移 `apps_kuaiai_*` 表与 `kuaiai:*` 权限码。与私仓同名的合并风险见 KR-G0/KR-G1。不另起新 app code（避免改委托探测、权限码、表前缀全线）。
- [x] **KR-D3** 引擎。**已拍板：LangChain 1.x。** 依赖增量：`langchain`（`agents.create_agent`/middleware/`@tool`）、`langchain-openai`（`ChatOpenAI`/`OpenAIEmbeddings`）、`langgraph` + `langgraph-checkpoint-postgres`（记忆留口）、`langchain-mcp-adapters>=0.3`（MCP）、`langchain-text-splitters`（切块）。**不引** AutoGen（多 Agent 编排非本形态）、不引 `langchain-classic`/`langchain-community`。`llama-index-core` 保留 `kuaiai-rag` extra 不动，不并存两 RAG 栈（收口见 KR-G6）。
- [x] **KR-D4** 通道不变量。**已拍板不动：** `create_chat_completion` 签名与 `find_spec` 委托；OpenAI chunk SSE 线格式（`choices[].delta.content` + `[DONE]`，前端零改）；`AiRuntimeConfig.load(tenant_id)` 每租户 Key 解析；`require_permission_codes`；`AiAuditMiddleware`；`wrap_ai_sse_stream`。**不**改快格响应约定为 `code/msg/data`，**不**改 `/ai/**` 式前缀。
- [x] **KR-D5** 模型凭证与目录。**已拍板：厂商与模型自由配置，不绑定固定厂商（对齐 ktg-ai `ai_provider`/`ai_model` 语义）。** 新建多行模型目录 `apps_kuaiai_llm_providers` / `apps_kuaiai_llm_models`（`tenant_id`；provider 内置 deepseek/openai/qwen/zhipu/moonshot/siliconflow 等 OpenAI 兼容预设仅作模板，`base_url` 可自定义；非 OpenAI 兼容厂商按适配点后续扩展）；档案 `default_model` 存目录行 id；运行时解析顺序 **目录行优先 → `IntegrationConfig` 单活连接兜底**（OCR/draft/IM 等旧消费方继续走 `AiRuntimeConfig` 不受影响）。Key 只服务端解析、加密落库、禁全局 client、禁 yml 明文、禁前端回传明文/cipher。
- [x] **KR-D6** 会话持久化。**已拍板：** `apps_kuaiai_chat_sessions` / `apps_kuaiai_chat_messages` 自表，纯对话与 Agent 对话**同表同管线**。消息行：`role: user|assistant|tool`；assistant 行存 `tool_calls` JSONB；tool 行存 `tool_call_id`/`tool_name`；存 `prompt_tokens`/`completion_tokens`。会话记 `agent_id`（可空）。
- [x] **KR-D7** 历史供给。**已拍板：消息表回放（方案 B）为唯一基线。** 发送时按 `tenant_id + session_id` 查表重建 LangChain 消息列表（含 `tool_calls`/`ToolMessage` 重建），无 checkpointer 无状态调用。LangGraph checkpointer 默认不接，时机见 **KR-G3**。
- [x] **KR-D8** Agent 档案。**已拍板：** `agent_profiles` 档案字段：`system_prompt` / `default_model` / `knowledge_ids` / `enabled_tools` / `mcp_server_ids` / `status`（对齐 ktg-ai A31 语义）。页面维护勾选；发送时按档案**每请求 `create_agent` 装配**（图构造成本毫秒级，贵资源在外层缓存）。`enabled_tools` 仅白名单子集，未列者不进模型 tool list；`knowledge_ids` 限本租户库，调用时复核归属。
- [x] **KR-D9** 档案授权。**已拍板：** 配置权≠使用权；`grant_mode` 仅 `ROLE` **或** `USER` 互斥；options 只回当前用户有使用权的启用档案；send 装配前校验，无授权 403，不静默降级。启用档案名单不得为空（400）。不造每档案权限字；授权是档案上的数据名单。（对齐 AG-D 系列语义）
- [x] **KR-D10** 受控写 Tools。**已拍板：** 白名单 Tool 调 `kuaizhizao` 等既有 service（如工单状态、报工），RBAC 与审计经 LangChain `wrap_tool_call` middleware + `ToolRegistry` 权限码。**禁止**任意 SQL、裸 SQL 工具、把 DB 连接交给模型、绕过权限码。无权限时回 `ToolMessage(status="error")` 让模型改口，不 500。
- [x] **KR-D11** MCP 白名单。**已拍板：** `apps_kuaiai_mcp_servers` 表（tenant_id + 加密连接配置）；`MultiServerMCPClient` + `load_mcp_tools(tool_interceptors=[...])`；档案 `mcp_server_ids` 为白名单子集；禁任意远程与 SQL MCP；options/详情不回明文。（对齐 A27 语义）
- [x] **KR-D12** 知识库 / RAG。**已拍板：** 复用 `apps_kuaiai_knowledge_documents/chunks`；按类型解析（`pypdf`/`openpyxl`/docx/md/txt，魔数或类型探测失败 = 解析失败不落乱码）；切块参数 `chunk_size`/`chunk_overlap`/`separator`/`top_k`/`min_score` 可配；**pgvector 同库检索**（cosine + `tenant_id`+`document_id` 过滤）；不建外部向量策略工厂、不做 Weaviate/DashVector（快格无 DEDICATED 向量档，见 KR-G7）。
- [x] **KR-D13** 结构化草稿。**已拍板：** `StructuredDraftService` 换 `ChatOpenAI.with_structured_output(Pydantic)`，删字符串抠 JSON 主路径；图片走多模态 content block。
- [x] **KR-D14** 工具循环与流式。**已拍板：** `create_agent` + `recursion_limit` 上限（替代 `MAX_TOOL_ROUNDS`）；带 tools 轮次**真流式**（`astream_events` → OpenAI chunk 适配器）；删除 `wrap_sse_from_completion` 假流式兜底。
- [x] **KR-D15** 确认闸。**已拍板：本期不做**（对齐 startech R10）。预留两路见 **KR-G3**：LangGraph interrupt + checkpointer，或既有 `action_pending_tokens` 另起执行。
- [x] **KR-D16** 工作流。**已拍板：本期不做**，后续另开（语义对齐 A28：仅登录、本应用前缀、自定 SSE、禁匿名 run）。见 **KR-G4**。
- [x] **KR-D17** 审计。**已拍板：** 复用 `core_ai_audit_logs` + 中间件；Tool 级调用经 `wrap_tool_call` 落审计（user/tenant/toolName/latency/token 用量）；不落 apiKey、MCP token、cipher、内部路径。
- [x] **KR-D18** 明确不做。**已拍板：本期不做** 第二套认证、匿名 AI 端点、外部向量策略工厂、专库租户档（快格无 DATABASE 档）、BM25 hybrid、单次检索多向量库融合、搬私仓 KU-AI 源码、AutoGen、`code/msg/data` 信封改造。
