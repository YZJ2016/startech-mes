## 用户故事

组织管理员在管理端维护 LLM 连接、知识库与 Agent 档案（勾选 Tool / MCP / 知识库，按角色或人员授权）。已登录员工在全宽对话页或顶栏助手中选择档案对话；系统按档案装配 Agent 运行，工具调用受权限约束，写操作经白名单 Tool 走既有业务 service。对话内容持久化，重新打开会话可见完整历史（含工具调用轨迹）。

  - **原文：** 沿用 `file_uuid` 指向快格既有文件/对象存储，解析从该存储读流。禁止扫服务器磁盘、禁止下到未隔离临时目录当语料库。解析路由：`pdf`→`pypdf`；`doc`/`docx`/`ppt`/`pptx`→对应轻量解析包（缺包则列入依赖）；`xls`/`xlsx`→`openpyxl`；`md`/`txt`→文本。魔数/类型探测失败或抽出文本为空 → `status=failed`，写 `error_message`，不落乱码 chunk。删文档同事务删其 chunks（含向量）。支持重解析。片段浏览只读。

  - **本期检索能力：** 问句压缩（多轮指代压成独立问句，用当前对话模型；失败回退原句，不 500、不跨租户）；默认开启有限展开（条数小，可配置关闭）；多库分别检索后 RRF 聚合；再用当前 chat 模型做打分再排序（打分失败或超时保留 RRF 顺序）；命中后按同一 document、`chunk_index ±1` 回表扩窗，禁止整篇进提示词；注入带 `file_name`/`source_ref` 等价 metadata；无命中仍纯对话。
  - **仍不做：** HyDE、OCR 扫描件、BM25/hybrid、单次检索多向量库融合、外部向量库（见 KR-D18 / KR-G7）。
