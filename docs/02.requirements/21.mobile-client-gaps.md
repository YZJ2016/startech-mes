## 用户故事

车间、仓库、质量、设备、模具岗位的人在手机上打开星制造工作台。同一套业务可以是 H5、微信小程序，或 Android / iOS 安装包。屏幕上有哪些入口，由已登录用户在对应 scope 下能看到的工作台决定。点进去之后的报工、库存、检验、设备和模具规则仍由现有后端执行。办公室 PC、触屏工位机和好力 GO 不在这个客户端里。

## 现网事实

核对口径：2026-09-29 阅读后端移动路由、渠道表，以及星制造前后端两份 `manifest.json` 的 `mobile_workbench`。本仓没有这些移动页面。下文写的是要做的能力，不是已上线的客户端。

### 后端已有

工作台 `GET /api/v1/apps/kuaizhizao/mobile/workbench`，查询参数 `scope`。未传时后端默认 `equipment`。未知 scope 返回空列表。响应是分区列表，分区字段为 `key`、`title`、`entries`。入口字段为 `key`、`label`、`route`、`icon`，以及可选的 `icon_group`、`solo_row`。

设备角标 `GET /api/v1/apps/kuaizhizao/mobile/bootstrap`。现有字段只有 `pending_fault_count`（待处理设备故障数量）、`overdue_maintenance_reminder_count`（逾期未处理保养提醒数量）。

登录沿用已有企业微信 OAuth，路径前缀 `/api/v1/auth/wecom/`。H5 容器扫码签名走 `GET /api/v1/core/mobile-jsapi/signature`，`provider` 只接受 `wecom`、`dingtalk`、`feishu`。

渠道头 `X-Client-Channel`。正式码里与本端有关的是 `mobile_h5`、`miniprogram`、`android`、`ios`。后端还会把 `h5`、`expo_android` 一类别名归一成正式码。本端只发上面四个正式码。

工作台按后端 manifest 条目上的 `permission` 或 `permissions_any` 过滤。管理员绕过该过滤。无权限的入口不出现在响应里。权限码以 manifest 条目为准，本文不抄一份。

分区 `title` 为空表示不展示分区名。禁止用「工作台」填这个空标题。

### 入口清单

前后端 `mobile_workbench` 在本次核对时内容一致。运行时接口读的是后端 manifest：

- `kuaigeyun-mes/riveredge-backend/src/apps/kuaizhizao/manifest.json`
- `kuaigeyun-mes/riveredge-frontend/src/apps/kuaizhizao/manifest.json`

五个 scope：`workshop`、`warehouse`、`quality`、`equipment`、`mold`。现网没有按端拆入口。现有条目都没有 `icon_group`。只有 `scan-report` 的 `solo_row` 为 true。

| scope | 分区 key | 分区 title |
| --- | --- | --- |
| `workshop` | `production_exec` | 空 |
| `warehouse` | `warehouse_ops` | 仓储作业 |
| `quality` | `quality_ops` | 质量检验 |
| `equipment` | `equipment_ops` | 设备作业 |
| `mold` | `mold_ops` | 模具作业 |

各入口的 key、中文名、route 见 **MOB-Q2** 至 **MOB-Q6**。工程目录用这些 key 做子目录名，目录树只写在设计第 5 节。

### 客户端与部署现状

`kuaigeyun-client` 里目前只有工位壳 `riveredge-app-station`，没有 `riveredge-app-mobile`。`kuaigeyun-mes/README.md` 仍把移动端写成私仓里的 Expo 工程，那份产品介绍本需求不改。H5 的部署路径已经改到 uni-app x：本机用 HBuilderX 发行 Web 后，脚本把 `unpackage/dist/build/web` 复制到现有 Caddy `/mobile`；没有产物时仍是占位页。脚本不在服务器或 CI 里从零编译。细节见设计第 8 节。Caddy 的 `/mobile` 规则本轮没有改。

PC 顶栏「小程序码」是一张图片（`HeaderClientDownloadButton` 里的图片列），不是移动端业务模块。旁边的安装包二维码是下载入口，同样不是本文的五个 scope。
