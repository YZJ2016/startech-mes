- 状态：`[x]` KR-ORP1 已有实现证据，见 `docs/04.specs/176.kuai-outsource-receipt-stock-cost-same-transaction.md` 第 4 节。该节同时记下未跑的真实数据库回滚。

## 问题

委外收货在事务里先把单据标成 completed，库存、成本和应付用后台任务补，失败只打 error 日志。因此委外收货不能当成实时库存和应付已经落账。

## 验收口径

- [x] **KR-ORP1** 免检创建或确认返回前，库存与成本已经落账。库存或成本失败时，收货单不能保持 `completed`，委外工单已收数量与之一同回滚。应付在该事务提交之后同步生成；失败时调用方收到业务错误，收货单可以仍是 `completed`。既有委外收货 URL、method、认证头、响应外层结构保持不变。证据见 spec 176 第 4 节。
