## P1-D — 产品决策

- [x] **P1-D1** 目标形态。**已拍板：MES 内嵌助手。** 不是再做一个 AI 平台。不做独立对话端、不做游客聊天。
- [x] **P1-D2** Maven / 包 / HTTP。**已拍板：** 新建 `ktg-ai`，包 `com.ktg.ai`，HTTP 前缀 `/ai/**`。`ktg-admin` 依赖该模块。Controller 薄层，业务在 `ktg-ai` service。
- [x] **P1-D3** 认证。**已拍板：仅现有 Spring Security JWT。** 对话必须登录。禁止 `/ai/chat/**` 进入 `MesPermitAllProvider`。禁止 Sa-Token、第二套 `SecurityFilterChain`、第二套 Token 服务。
- [x] **P1-D4** 租户。**已拍板：** 表 `tenant_id bigint NOT NULL`，加入 `tenant.line.include-tables`。上下文只信 JWT `LoginUser`。默认 **ROW**；`DATABASE` 租户仍写 `tenant_id`，表进专库 catalog，禁止回落主库。
- [x] **P1-D5** 上传。**已拍板：默认仍 `POST /common/uploadMinio`。** 不引入 OSS。Phase 1 **无**知识库上传。
- [x] **P1-D6** 前端。**已拍板：只改 `startech-mes-front/`。** 不改遗留 `frontend/`。不引入 `vue-element-plus-x`、UnoCSS、hook-fetch、Ant Design Vue、Vben、TypeScript 工程形态，不提交 lockfile。
- [x] **P1-D7** 模型供应商。**已拍板：OpenAI 兼容 HTTP**（DeepSeek / 自定义 `apiHost`）。JDK `HttpClient` + Jackson 解析 SSE。禁止为本期引入 LangChain4j 全家桶（以后可另立项）。
- [x] **P1-D8** 密钥。**已拍板：** 落库加密（AES-256-GCM，主密钥 `${AI_MODEL_CIPHER_KEY:}`，不复用 `TENANT_JDBC_CIPHER_KEY`）**或**行内空 Key 时运行时回退 `${AI_DEFAULT_API_KEY:}`。列表与 `options` **永不**回明文 `apiKey`；详情可回打码。禁止回 cipher。
- [x] **P1-D9** UI 对照。**已拍板：只读参考** `ruoyi-web` 对话交互、`ruoyi-admin` `views/chat/{provider,model}` 字段清单。不拷其技术栈。
- [x] **P1-D10** 明确不做。**已拍板：不进 Phase 1：** RAG、Agent、MCP、workflow、短剧、coding harness、ruoyi-ai 租户套餐、登录租户下拉。禁止匿名 `/workflow/run`。禁止会话 API 使用 `/system/message`。
- [x] **P1-D11** 许可闸。**已拍板：Phase 1 用 `@PreAuthorize` + 菜单权限，不建 `mes_module.ai` 工厂套餐。** 48–56 的许可工厂闸留给后续平台轨道。
- [x] **P1-D12** 表。**已拍板：** `ai_provider`、`ai_model`（单元 A）；`ai_session`、`ai_message`（单元 B）。模型分类 `chat` 先用；`vector` / `rerank` 列保留但对话拒绝。
- [x] **P1-D13** HTTP 契约。**已拍板：下列路径冻结**（见各 spec  verbatim 块）。分页信封 `code/msg/data` 与 `rows`+`total`。全部需登录。
- [x] **P1-D14** 权限字。**已拍板：** `ai:provider:list|query|add|edit|remove`，`ai:model:list|query|add|edit|remove`（`ai:model:*`），`ai:chat:list|send`。

## P1-I — 集成 / 隔离

- [x] **P1-I1** 行级隔离。**已拍板：** include 表无上下文失败关闭；INSERT 填充/校验 `tenant_id`；跨租户 id 读写 404/403。
- [x] **P1-I2** 专库。**已拍板：** `ai_*` 表名追加 `TenantDedicatedSchema.tenantTables()`；对应 **表 DDL** 文件名追加 `incrementalSqlFiles()`。菜单 SQL 走主库 `sys_menu`（全局表），**不要**把纯菜单脚本标进专库 catalog。
- [x] **P1-I3** 异步。**已拍板：** SSE 出站线程沿用既有 `TenantTaskDecorator`（或项目同等拷贝 `TenantContext` 的方式），不用裸 `InheritableThreadLocal`。
- [x] **P1-I4** 日志。**已拍板：** 不打印 apiKey、cipher、`${AI_DEFAULT_API_KEY:}` 解析后的值、JWT、MinIO 凭据、内部绝对路径。SSE 事件不含密钥。
- [x] **P1-I5** 配置根键。**已拍板：** 应用根键保持 `ruoyi:`。AI 占位只写 `${AI_MODEL_CIPHER_KEY:}`、`${AI_DEFAULT_API_KEY:}`，不写真值。
- [x] **P1-I6** 默认上传。**已拍板：** 不改 `/common/upload` 为默认；图标若需上传仍走 `POST /common/uploadMinio`。
