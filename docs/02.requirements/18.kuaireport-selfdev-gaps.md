# 星报表自研缺口（快格云应用槽位）

- 轨道：**快格云自研**。实现落在 `kuaigeyun-mes` 的应用槽位 `apps/kuaireport`（后端与 `riveredge-frontend` 同名目录）。本文是用户点名的自研轨道，不是「把快格云能力纳入主工程」的对照切片。
- 边界：禁止把该实现合并进 `startech-mes-basic`，禁止并进 UReport。对照仓只作能力来源，不把私仓页面拷进主工程。
- 总览追溯：`docs/02.requirements/13.mes-kuaige-capability-overview.md` 的 **CAT-A10** 保持 **默认后置**。本文件不把该行改成对照轨道开工，不挤占出库 Hub 的「进行中」。
- 设计：`docs/03.design/18.kuaireport-selfdev-plan.md`
- 后继域：星数采见 `docs/02.requirements/19.kuaiiot-selfdev-gaps.md`。数采不在本文件展开。两边的 HTTP 衔接放在数采做出来之后，不放进报表第一段。
- 拍板：2026-09-28。顺序按 side chat 第二轮：执行引擎 → 账表 → 设计器 → 大屏 → 分发。五段全部纳入本文件，按此先后做完，再开数采。

- 禁止在文档中写入口令、Token、密钥、JDBC 或生产地址。

## 用户故事

报表管理员在星报表里登记数据源，查看并发布系统报表与自定义报表，用设计器配一张账表，用大屏配一块看板并分享。业务人员打开库存台账、工单跟踪、检验合格率，以及效能统计、节点时效、处理效率、销售/采购/物料追溯、业务综合看板，能筛选、分页、合计、打印和导出。此阶段不读取数采。

## 范围与先后

五段都在本文件内。前一段未具备「能往下用」的结果时，不跳去下一段把设计器或大屏当成入口。

| 编号 | 段 | 纳入的能力 | 本段结束时具备 |
| --- | --- | --- | --- |
| **KRP-P1** | 执行引擎 | 数据源三种：`static`、引用现有数据集、HTTP。HTTP 只允许已经登记的地址。`executeReport` 按 `report_config` 的字段、筛选、分页、合计返回 `data` / `total` / `summary` | 有数据源、能按配置查出一页结果。设计器此时还没有 |
| **KRP-P2** | 账表（报表中心） | 列表、草稿/发布、业务分类、系统报表与自定义报表。预览与打印走 `UniReport`。全量导出在后端生成 Excel。代码种入的系统报表见 **KRP-D6**，不靠设计器画 | 能查、能导出。还不能自己拖列 |
| **KRP-P3** | 表格设计器 | 只编辑 `report_config`：数据源、列、筛选、格式、合计。保存时写入已有版本表。本段是账表设计器 | 能设计并保存一张账表。不是大屏 |
| **KRP-P4** | 大屏 | 使用已有 `layout_config`、`widgets_config`、`theme_config`、`tv_config`。组件先做指标、表格、图表，再做边框、标题、轮播、时钟、图片、视频、网页嵌入。每个组件绑一个数据源，自带刷新间隔。预览与免登录分享走已约定的 `/apps/kuaireport/dashboards/shared`，并在本段做完链接过期、访问口令、IP 白名单、访问日志。见 **KRP-D7**。空 IP 白名单见 **KRP-D8**。账表免登录 `/apps/kuaireport/reports/shared` 同一套四项见 **KRP-D9** | 能设计、预览，并分享受控的大屏与账表 |
| **KRP-P5** | 分发 | 表已在迁移 563。顺序：按角色授权 → 定时订阅（先站内信，Excel 附件在本段内后补）→ 版本回看与恢复。分享链接的四项管控（含账表免登录，**KRP-D9**）不在本段，已在 P4 | 能授权、能订阅、能回看并恢复版本 |

本文件收口：能建数据源，能设计并发布一张账表，能设计并分享一块受控大屏（KRP-D7），并能按 KRP-D9 分享一张受控账表，KRP-D6 的系统报表能打开。收口时不读数采。

## KRP-D — 已拍板

- [x] **KRP-D1** 落点。应用槽位 `apps/kuaireport`，骨架对齐仓内 `apps/kuaiai`。表用现成 `apps_kuaireport_*`，不另起一套，不改已经进过库的迁移文件名。槽位收归本仓：忽略规则与专业包组装名单里去掉本应用，避免组装删目录。之后不对这个目录做私仓组装。
- [x] **KRP-D2** 顺序。五段为 KRP-P1 → P5。数采六步不在本文件。报表完成前不出现数采专用接口。
- [x] **KRP-D3** 数据源。一张报表或一个大屏组件只绑一个数据源。多源指一块大屏上混用多个源，不做跨库关联查询。销售、采购、物料追溯等跨业务内容，用 MES 这一个库上的查询写成系统报表。报表配置不存放任意 SQL。平台数据集继续当查询执行器。
- [x] **KRP-D4** 固定页。星制造里写死的看板页留在原应用，不搬进星报表。
- [x] **KRP-D5** 与主工程隔离。不合并进 `startech-mes-basic`，不并进 UReport，不改变主工程既有接口契约。CAT-A10 仍为对照轨道的默认后置。
- [x] **KRP-D6** 系统报表名单（2026-09-28）。代码种入、不靠设计器：库存台账、工单跟踪、检验合格率、效能统计、节点时效、处理效率、销售全链路追踪、采购全链路追踪、物料全生命周期追踪、业务综合看板。效能统计与节点时效、处理效率一样写入 `report_config`，出现在报表中心的系统报表里。不恢复已下线的「效能中心」侧栏分组。「分析报表」「跨业务报表」只是菜单分组，不另种一张表。星制造写死的固定页不迁入。此后增补须另拍板。
- [x] **KRP-D7** 大屏分享一次做完（2026-09-28）。KRP-P4 含设计、预览、免登录入口 `/apps/kuaireport/dashboards/shared`，以及链接过期、访问口令、IP 白名单、访问日志。P4 结束时不留下不受控的免登录链接。KRP-P5 只做按角色授权、定时订阅（先站内信，Excel 附件仍在本段后补）、版本回看与恢复。报表分享不在 P5 另起一截；账表免登录本期就在 P4，见 **KRP-D9**。
- [x] **KRP-D8** 空 IP 白名单（2026-09-28）。`share_allow_ip_cidrs` 为空时不做 IP 匹配。过期和访问口令仍然有效。白名单非空且 IP 不在名单内才拒绝。这是可选加严，不是打开分享的必填项。大屏与账表同一套规则。
- [x] **KRP-D9** 账表免登录分享本期交付（2026-09-28）。落在 KRP-P4（spec 148），不放到 KRP-P5。`/apps/kuaireport/reports/shared` 与大屏同一套四项管控（过期、口令哈希、IP 白名单、访问日志）通过后才返回账表数据。页面文件为 `riveredge-frontend/src/apps/kuaireport/pages/ReportSharedView.tsx`。KRP-D6 的 10 张系统报表默认不开启分享（`is_shared` 为假），必须人显式打开后才签发免登录链接。登录后的按角色授权仍只在 KRP-P5。

## 明确不做

- 本文件不做星数采，不做 `equipment-ops-feed`，不把数采 JSON 配进报表第一段。
- 不把星制造各域固定看板页迁成设计器产物。
- 不在 `report_config` 里保存任意 SQL，不做跨库关联。
- 不把快格云 BI 并进 UReport，不把 FastAPI / 插件扫描搬进主工程。
- 订阅的 Excel 附件后补于站内信，不单独立项到数采之后；未做附件时订阅仍以站内信为界。
- 不写可执行任务清单，不在本文件记验证记录。
