## A — 产品决策（运行时加固）

- [x] **A29** 共享会话准备 / SSE / 错误 / 租户上下文。**已拍板：** 从现网 `AiChatServiceImpl` 与 `AiAgentServiceImpl` 抽出统一的 session-prepare、SSE 推送、异常映射与 `TenantContext` 拷贝，供 `POST /ai/chat/send`、`POST /ai/agent/send`、`POST /ai/workflow/run` 复用。**冻结**三条 HTTP path 与既有 `{content, done}` 信封；不得为抽公共层而改 path 或引入 ruoyi `[NODE_CHUNK_*]`。证据：`docs/03.design/07.mes-ai-runtime-hardening-plan.md` §5.1。实现单元：`docs/04.specs/66.ai-shared-runtime-pipeline.md`。
- [x] **A30** Agent 记忆落库。**已拍板：** LangChain4j `ChatMemoryStore` 读写 `ai_message`；`memoryId` 冻结为 `{tenantId}:{userId}:{sessionId}`（字符串拼接，分隔符 `:`）。禁止全进程一份内存；禁止客户端传 `memoryId` 换租户。跨租户 session 404/403。证据：设计 07 §5.2。实现单元：`docs/04.specs/67.ai-agent-memory-store.md`。
- [x] **A31** 租户 Agent 配置与按需 Tools。**已拍板：** 学 ruoyi `agent_info`（**不要** Supervisor）：租户级 `ai_agent` 档案字段冻结为 `modelId`、`systemPrompt`、`knowledgeIds`、`enabledTools`、`mcpServerIds`；A24 工厂按档案组装一份 `MesAiAssistant`。**默认**受控写 Tools（A26）与 MCP（A27）**关闭**（无 profile 时亦同；未传 `agentId` 用默认 profile，其 seed 亦不含写/MCP）；`enabledTools` 仅白名单 Tool 名子集，**未列出者不得**出现在模型 tool list；`mcpServerIds` 为租户 MCP 白名单（A27）的**档案级子集**（非「启用 mcp 即挂本租户全部 server」）；`knowledgeIds` 绑定本租户知识库 id，Tool 调用时仍复核归属。`POST /ai/agent/send` 可选 `agentId`；未传则用租户默认 profile。管理端 CRUD 冻结为 `/ai/agent/profile`。**禁止** Supervisor 多 Agent 拓扑、禁止任意 SQL / JDBC Tool。证据：设计 07 §5.3。实现单元：`docs/04.specs/68.ai-agent-profile.md`。
- [x] **A32** RAG 检索管线。**已拍板：** 知识解析采用**重叠切块**（overlap）+ **分隔符**（per-knowledge 可配或租户/全局默认）；检索支持**相似度阈值**与**可配置 topK**（租户或知识库级，具体字段留给实现 spec）。`POST /ai/chat/send` 挂知识库与 Agent `searchKnowledge` **共用** `AiRetrievalService`。**69 基线不做** hybrid 检索、**不做** rerank、**不做** 多向量融合。证据：设计 07 §5.4。实现单元：`docs/04.specs/69.ai-rag-pipeline.md`。**覆盖升级（另立，不改本条字段）：** 生产级 Parser + LangChain4j Advanced RAG（含 RRF / Scoring 再排序）见缺口 `docs/02.requirements/10.mes-ai-production-rag-gaps.md`、设计 11、单元 89–93。仍禁止 BM25 hybrid 与多向量库融合。
- [x] **A33** 工作流 chat 步骤。**已拍板：** 工作流步骤允许 `toolName=chat`，经 A24 `(tenantId, modelId)` 工厂调 LangChain4j 对话；SSE 仍自定 `content` / `done` / 可选 `step`，**禁止** langgraph、**禁止** ruoyi `[NODE_CHUNK_*]`。不改 `POST /ai/chat/send` / `POST /ai/agent/send` 信封。证据：设计 07 §5.5。实现单元：`docs/04.specs/70.ai-workflow-chat-step.md`。
- [x] **A34** Tool 调用审计。**已拍板：** 每次 Tool 调用（含受控写、MCP、知识检索、工作流节点）须落审计：用户、租户、Tool 名、业务主键（若有）、耗时、token 用量（若上游返回）。**禁止**日志 / SSE / 审计行写入 apiKey、MCP token、cipher、JDBC。**禁止**引入 `ruoyi-common-trace` 或第二套链路追踪。证据：设计 07 §5.6。实现单元：`docs/04.specs/71.ai-tool-audit.md`。
- [x] **A35** Agent 档案 Vue3 管理页。**已拍板：** 在 `startech-mes-front` 落地 `/ai/agent` **配置 CRUD**（学既有 `ai/mcp`、`ai/knowledge` 表格/对话框），**不是**独立对话 SPA、**不是** Supervisor。表单字段与 A31 / `/ai/agent/profile` 对齐：`name`、`systemPrompt`、`defaultModelId`、`knowledgeIds`、`enabledTools`（仅 `searchKnowledge` | `submitProductionFeedback` | `updateWorkorderStatus`）、`mcpServerIds`、`status`、`remark`。新建 `src/api/ai/agent.js`；组件路径 `ai/agent/index`；菜单 **9107** 在页面就绪后取消隐藏（`visible='0'`；若依 `visible='1'` 为隐藏）。权限字沿用 `ai:agent:profile:*`。默认交互：写 Tool 与 MCP **默认不勾**。MCP/模型/知识库 options **不回显** cipher / apiKey。禁止改 Vue2；禁止引入 element-plus-x / hook-fetch。证据：设计 07 §5.7。实现单元：`docs/04.specs/72.ai-agent-profile-ui.md`。
- [x] **A36** 对话页可选档案走 Agent 发送。**已拍板：** 现有 `/ai/chat` 增加可选「Agent 档案」选择器；**选中档案**（含显式选默认档案）时 SSE 走 `POST /ai/agent/send`（body 可带 `agentId`）；**未选档案**时仍走 `POST /ai/chat/send`（纯对话、无 Tool；58/59 信封与 path **不变**）。**不新开**独立 Agent 聊天路由 / 菜单。发送权限复用 `ai:chat:send`。不把 chat 页改成工作流 runner。证据：设计 07 §5.8。实现单元：`docs/04.specs/73.ai-chat-agent-select.md`。
