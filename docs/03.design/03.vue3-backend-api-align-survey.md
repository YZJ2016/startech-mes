# Vue3 与换壳后后端 API 对齐调研

Date: 2026-08-21  
Status: 设计已确认（原则 C + 验收 B + 文档驱动方案 1）  
Code: 28–34 静态对齐已落地（nested `startech-mes-front`）；运行时冒烟 / `build:prod` 未做。下文对照表为调研时快照，不随代码回写。

## 背景

`startech-mes-basic/startech-mes-front` 在 RuoYi Vue3 3.9.2 壳上迁入了 Vue2 的 MES `src/api`。当时的迁移 spec 假定后端仍是 RuoYi 兼容 **3.8.2**，因此关掉了锁屏和密码过期 UI。

`startech-mes-basic/backend` 已完成平台换壳到若依 `master` 线：**JDK 17、Spring Boot 4.1.0**，模块名仍 `ktg-*`、包名仍 `com.ktg`。MES 五项接线仍在。嵌套仓库分支以工作区为准（换壳线，不是文档里的旧 Java 8 描述）。

两边叠在一起后，缺口主要在平台壳，而不是「MES URL 整包消失」。

## 对照事实（静态）

| 点 | 后端 | Vue3 现状 |
| --- | --- | --- |
| `POST /login` | 有 | 有 |
| `GET /getInfo` | 另有 `pwdChrtype`、`isDefaultModifyPwd`、`isPasswordExpired` | store 忽略这些字段 |
| `GET /getRouters` | 有 | 有 |
| `GET /captchaImage` | 有 | 有 |
| `POST /unlockscreen` | `SysIndexController` | lock store / `lock.vue` 被禁用；Navbar 无锁屏；无 `/lock` 路由 |
| `GET /loginOuth` | 有（mes 接线） | API + 路由 + 白名单已有 |
| `POST /common/uploadMinio` | mes | FileUpload / ImageUpload 默认已是该路径 |
| `GET /system/notice/list` | **仅 mes** `SysNoticeListController` | `listNotice` 仍调该 URL（路径对）；铃铛另调了不存在的 3.9 接口 |
| 3.9 `listTop` / `markRead` | admin Controller **无** mapping；`SysNoticeReadService` 仅 Service | `notice.js` + `HeaderNotice` 在调 |
| MES 已读 | `GET /system/notice/detail/message`、`POST /system/notice/detail`；JSON `readStatus` / `userId1` | `notice.js` 仍有封装，铃铛未使用 |
| `GET /system/user/deptTree` | 有 | 有 |
| cache 清理 | `DELETE` | Vue3 为 `DELETE` |
| 登录日志清空 | `DELETE /monitor/logininfor/clean` | Vue3 为 `DELETE` |
| 登录日志解锁账号 | `GET /monitor/logininfor/unlock/{userName}` | 有（与锁屏无关） |

粗抽 `src/api` 与 `*Controller` 时，不要把「类级前缀 + 空 method mapping」或「`/bom` vs `/bom/{id}`」报成 MES 整包缺失。归一规则：类 `@RequestMapping` + 方法 mapping；路径变量统一成 `{id}`；忽略末尾 `/`。

## 契约三层

### 层 1 — 平台

只启用后端 **已经挂 HTTP** 的若依能力：登录、`getInfo` 密码字段、锁屏、`deptTree`、标准 system/monitor/tool。不把无 mapping 的 Service 当成契约。

### 层 2 — MES 定制

必须保持：公告列表与已读、MinIO 默认上传、SSO `/loginOuth`、autocode、ureport（URL 来自环境变量）。

### 层 3 — 禁止

- admin 不得增加 `GET /system/notice/list`，也不得增加 `listTop`/`markRead` HTTP 来替代层 2。
- 不得用 OSS 签名或 `/common/upload` 替换 MinIO 默认。
- 本轨道第一单元不改 `/mes/**` 及既有无前缀 MES 路径的 URL/method。
- 不改 Vue2 `frontend/`。`getInfo` 多出的字段 Vue2 可忽略。

## 第一单元数据流

```text
POST /login → token
GET /getInfo → user, roles, permissions, pwdChrtype, isDefaultModifyPwd, isPasswordExpired
GET /getRouters → 动态菜单
铃铛 → GET /system/notice/detail/message ；已读 → POST /system/notice/detail
锁屏 → POST /unlockscreen  body { password }
上传 → POST /common/uploadMinio
SSO → GET /loginOuth
```

`passwordRule.js` 读 session `pwrChrtype`。写入时源字段为后端 `pwdChrtype`。

## 验收

静态：`src/api` 的 URL+method 对 Controller；`P` 项收口。  
运行时（有本地后端才勾）：登录、密码字段、锁屏、MES 铃铛、MinIO 路径、`loginOuth` 存在性。无环境则写未验证。
