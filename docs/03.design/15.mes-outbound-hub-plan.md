## 1. 问题与目标

现网生产领料与销售出库是两张互不聚合的 CRUD。仓管要在两个菜单之间跳。快格云用出库 Hub 把多类型收进一张表。要对齐的是这条**运营闭环的一小段**（已有散页 → 一张表 + 抽屉），不是它的 6 种类型、借料、送货单或 OQC 闸。

本轨从入库 **IH-G1** 拆出，避免把出库塞进 104/105。

### 1.1 目标

- 工厂角色勾选 9310 后，Vue3 侧栏多一个出库 Hub：领料 + 销售出库同行分类型
- 点单号打开抽屉：表头、现网明细、状态、关联工单/销售单深链
- 执行仍走现有 `PUT /mes/wm/issueheader/{issueId}`、`PUT /mes/wm/productsalse/{salseId}`
- 旧领料/销售出库菜单与 URL 仍可用

### 1.2 非目标

- 借料 / 送货 / 退料退货 / OQC / 金额 / 打印（112–114 与 OH-G2/G4/G5；**不得打进 107**）
- 借料、送货单、委外发料、其它出库、采购退货、11 种类型
- 生产退料 / 销售退货进 **出库** Hub（已拍板不纳入；OH-G1 关闭。归入库 Hub 余型 IH-G10，不是出库 P3）
- 销售出库 OQC 闸、入库 IQC/FQC 闸
- CAT-W01 / W04 / W05 / W06 / W07
- 出库金额（OH-G5）、Hub 打印（OH-G4）
- 换若依壳、kiosk、第二套组件库、改 Vue2
- 替换旧 list/执行 URL
- 改首页、F1、行业包、改入库 Hub

### 1.3 回归基线

未勾 9310 的用户：无出库 Hub 菜单；旧页仍在。本刀不改执行语义，因此旧页过账行为与今日一致（含领料自动建采购、销售出库回写订单）。

## 2. 页模式与运行时

```text
快格云                         Startech MES
─────────────────────────────────────────────────────────
多源前端聚合                    GET /mes/wm/outboundhub/list（服务端合并）
DetailDrawer + AntD            el-drawer + Element Plus
确认出库卡 OQC                  本刀不做（OH-G2）
6 种 outbound_type             仅 ISSUE + PRODUCT_SALSE
```

运行时（编码开始后，非现在）：

```text
① 工厂角色勾 9310（不自动授）
        │
        ▼
② GET /mes/wm/outboundhub/list
   许可 ∩ 角色；SQL 带 tenant_id
   行：outboundType + 现网主键 + 单号/状态/日期/仓库（可筛 warehouseId）
        │
        ▼
③ 抽屉：现有 GET 头 + 行；关联工单/销售单深链
        │
        ▼
④ 执行：
   领料 `PUT /mes/wm/issueheader/{issueId}`
   销售 `PUT /mes/wm/productsalse/{salseId}`
   失败 AjaxResult.error；本刀不新增闸
```

### 2.1 Hub 行

| 字段 | 含义 |
| --- | --- |
| `outboundType` | `ISSUE` / `PRODUCT_SALSE` |
| 主键 | 领料 `issueId` 或销售 `salseId` |
| 单号 / 名称 / 状态 / 日期 | 展示 |
| `warehouseId` / 仓名 | 有则带出；可筛 |
| 工单号或客户/销售单号 | 有则带出；无则空 |

筛选：类型、状态、单号、日期、**仓库**（`warehouseId` 可空）。分页在服务端完成。**P0** 无打印按钮、无 OQC 列；抛光见 §7.4（116 / 115）。

### 2.2 抽屉

- 上：`el-descriptions` + 状态轴（字典 `mes_order_status`）；关联工单 / 销售订单能跳则跳
- 中：现网已有行列。领料行 `quantityIssued`/`batchCode`；销售出行 `quantitySalse`/`batchCode`。**P0** 两边都没有单价、行金额、序列号集合；**117** 已在 Hub 抽屉为领料/销售行加可空单价与行金额（旧行页不重排，UI-A）。序列号集合仍不对齐入库 IH-D19
- 主按钮：与旧页同一套执行 API；无权限隐藏。**P0** 无打印、无 OQC 预览；**116** Hub 打印、**115** 销售抽屉 OQC 预览 + 执行闸（头表 `oqcId`/`oqcCode`；见 §7.4）

## 4. 错误处理
