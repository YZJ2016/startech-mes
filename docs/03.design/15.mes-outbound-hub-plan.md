## 1. 问题与目标

现网生产领料与销售出库是两张互不聚合的 CRUD。仓管要在两个菜单之间跳。快格云用出库 Hub 把多类型收进一张表。要对齐的是这条**运营闭环的一小段**（已有散页 → 一张表 + 抽屉），不是它的 6 种类型、借料、送货单或 OQC 闸。

本轨从入库 **IH-G1** 拆出，避免把出库塞进 104/105。

### 1.1 目标

- 工厂角色勾选 9310 后，Vue3 侧栏多一个出库 Hub：领料 + 销售出库同行分类型
- 点单号打开抽屉：表头、现网明细、状态、关联工单/销售单深链
- 执行仍走现有 `PUT /mes/wm/issueheader/{issueId}`、`PUT /mes/wm/productsalse/{salseId}`
- 旧领料/销售出库菜单与 URL 仍可用

### 1.2 非目标

- 编码（须 105 手验或用户明示开工；见 106/107 门禁）
- 借料、送货单、委外发料、其它出库、采购退货、11 种类型
- 生产退料 / 销售退货进 Hub（默认；OH-G1 待确认）
- 销售出库 OQC 闸、入库 IQC/FQC 闸
- CAT-W01 / W04 / W05 / W06 / W07
- 出库金额（OH-G5）、Hub 打印（OH-G4）
- 换若依壳、kiosk、第二套组件库、改 Vue2
- 替换旧 list/执行 URL
- 改首页、F1、行业包、改入库 Hub

### 1.3 回归基线

未勾 9310 的用户：无出库 Hub 菜单；旧页仍在。本刀不改执行语义，因此旧页过账行为与今日一致（含领料自动建采购、销售出库回写订单）。

## 2. 页模式与运行时

```text
快格云                         Startech MES
─────────────────────────────────────────────────────────
多源前端聚合                    GET /mes/wm/outboundhub/list（服务端合并）
DetailDrawer + AntD            el-drawer + Element Plus
确认出库卡 OQC                  本刀不做（OH-G2）
6 种 outbound_type             仅 ISSUE + PRODUCT_SALSE
```

运行时（编码开始后，非现在）：

```text
① 工厂角色勾 9310（不自动授）
        │
        ▼
② GET /mes/wm/outboundhub/list
   许可 ∩ 角色；SQL 带 tenant_id
   行：outboundType + 现网主键 + 单号/状态/日期/仓库（可筛 warehouseId）
        │
        ▼
③ 抽屉：现有 GET 头 + 行；关联工单/销售单深链
        │
        ▼
④ 执行：
   领料 `PUT /mes/wm/issueheader/{issueId}`
   销售 `PUT /mes/wm/productsalse/{salseId}`
   失败 AjaxResult.error；本刀不新增闸
```

### 2.1 Hub 行

| 字段 | 含义 |
| --- | --- |
| `outboundType` | `ISSUE` / `PRODUCT_SALSE` |
| 主键 | 领料 `issueId` 或销售 `salseId` |
| 单号 / 名称 / 状态 / 日期 | 展示 |
| `warehouseId` / 仓名 | 有则带出；可筛 |
| 工单号或客户/销售单号 | 有则带出；无则空 |

筛选：类型、状态、单号、日期、**仓库**（`warehouseId` 可空）。分页在服务端完成。无打印按钮。无 OQC 列。

### 2.2 抽屉

- 上：`el-descriptions` + 状态轴（字典 `mes_order_status`）；关联工单 / 销售订单能跳则跳
- 中：现网行表字段（待补全 OUT-F05：不臆造合格量/序列号列）
- 主按钮：与旧页同一套执行 API；无权限隐藏；无打印；无 OQC 预览

## 3. HTTP 与数据

### 3.1 保持不变

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/mes/wm/issueheader/list` | 旧领料列表 |
| PUT | `/mes/wm/issueheader/{issueId}` | 执行领料；副作用 OUT-X01 不改 |
| GET | `/mes/wm/productsalse/list` | 旧销售出库列表 |
| PUT | `/mes/wm/productsalse/{salseId}` | 执行销售出库；副作用 OUT-X02 不改 |
| GET/POST/PUT/DELETE | 领料/销售出行及退料/退货 | URL 不变 |

### 3.2 附加（编码开始后）

**`GET /mes/wm/outboundhub/list`**

- 登录；`mes:wm:outboundhub:list`
- Query：与 RuoYi 分页一致（`pageNum`/`pageSize`）+ `outboundType`（可空）+ 状态/单号/日期 + **`warehouseId`（可空）**
- `data`：现网 `TableDataInfo`（与 `BaseController.getDataTable` 对齐）
- 无上下文 4xx/业务失败关闭，不扫他厂
- UNION/合并每侧都带 `tenant_id`；禁止前端假分页

本刀不加 `oqc-gate` GET。

### 3.3 持久化

- **master** Flyway：`sys_menu` 9310 段。本刀无新 `sys_config` 闸键。
- **tenant**：本刀默认无新列（待补全 OUT-F05 未要求加列前不加）。不加金额列（OH-G5）。
- 不新建出库头表。不把 Hub 行物化成第三张单据表。
- 不改历史 `backend/sql/`。

### 3.4 事务

执行事务仍在现网 `execute`。Hub list 只读。抽屉不另开写接口；改明细仍走旧行 POST/PUT。

## 4. 错误处理

- Hub list 某一类型查询失败：整单失败（4xx/5xx），不半页他厂数据
- 执行失败：沿用现网 `AjaxResult.error`；不堆栈、不内部路径
- 403 不泄漏他厂是否存在该 id

## 6. 风险

- 把退料/退货默默并进 Hub（违反 OH-D2 / OH-G1）
- 把 OQC 闸或仓储其它块打进出库 P0（违反 CAT-N2 / OH-D3）
- 前端假分页（OH-D10）
- 在 105 未手验、用户未明示开工时改 Java/Vue（违反编码门禁）
- PageHelper 对 UNION 分页：编码时须在一条 SQL 或等价服务端分页上测 `total`（入库 Hub 已有先例，可对照不可拷快格云）
