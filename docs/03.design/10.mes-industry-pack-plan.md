## 1. 问题与目标

快格云用「通用宿主保持中性、行业差异用声明挂钩」：侧栏只露一个行业包容器；模块可插拔；关掉就回退；同一宿主菜单槽位同时只允许一个 replace。

Startech 已经有同类**能力闸**，形态不同：

- 模块 = `sys_tenant_license.module_code` ∩ `mes_module`
- 侧栏 = 全局 `sys_menu` 经 `getRouters` 许可裁剪
- 页面 = Vue3 `views/**` 静态 glob，component 字符串来自菜单行

要对齐的是**运营体验**（给某厂开一个行业、侧栏多一组菜单），不是再做一套插件运行时。

### 1.1 目标

- 平台给工厂许可 `ip.demo` **且**该厂角色已勾 9200 后，Vue3 侧栏出现「行业包」及桩页；仅许可不够；撤许可后消失
- 通用 MES 菜单与组件不被替换
- 为后续真实行业留下：`ip.<code>` 许可码、`mes/ip/...` path、P1 槽位互斥
- 两厂许可互不影响；`DATABASE` 仍读主库菜单

### 1.2 非目标

- 扫描 `manifest.json` / 应用中心 / 按租户重建 `sys_menu`
- 快格云套餐、PRO Key、`X-Tenant-ID`
- 把 BOM/工艺/工单改成可热替换页（P1 亦不做，见 IP-G3）
- 辐条轮毂、ESD、电子钢网等**领域功能**
- 新认证、新 ORM、改 Vue2、pad `/platform/**`、本轨 `/ai/**`
- 为行业包新建 `ktg-industry` 模块

### 1.3 无包路径（回归基线）

验收基线：**无 `ip` / `ip.*` 许可的租户 = 现网**（IP-D20）。行业包是加法、opt-in。

- `getRouters`、侧栏、登录、工单 / BOM 与今日一致
- 不得插入必见的空「行业包」目录，不得改现网 `sys_menu` 结构使全厂多出可见项
- 不得默认给所有租户开 `ip`，不得把 `ip` 放进必选许可，不得因未启用行业包让 `getRouters` 500
- `ip.demo` 同样 opt-in：平台未给该厂开则与无行业包相同；桩不是运行前提
- 零包路径不依赖角色授权：没有 9200 可展示（IP-D20）；有许可但未勾角色则侧栏仍无行业包（IP-D21）

## 2. 四层形态（对照快格云，落到 MES）

```text
快格云                         Startech MES
─────────────────────────────────────────────────────────
manifest.json 扫描              不做。Java 登记 + Flyway 菜单/字典
应用中心 install/enable         平台租户页勾选 mes_module（已有）
industry-pack 隐藏应用          全局目录菜单 9200（path=mes/ip）
rebuild_pack_menus 写库         不写菜单库；getRouters 许可过滤
on_module_activated 种子        P0 无；P1 只校验槽位
standalone 新页                 P0：views/mes/ip/demo
replace+profile                 不做（IP-G3）；将来 sys_config overlay
replace+document                不做（无替换组件）
```

MES 运行时链路：

```text
① 平台 PUT /platform/tenant/{id}/licenses
   含 ip.demo → 自动补 ip；全无 ip.* → 去掉 ip
   只写许可，不写 sys_role_menu（IP-D21）
   P1：校验 replace 槽位，冲突则 400 整单不写
        │
        ▼
② 工厂「角色管理」：能改角色者手动勾 9200 / 9201
   仅许可不够；不抄快格云自动补权限
        │
        ▼
③ 工厂登录 JWT → TenantContext
   getRouters：role_menu ∩ 许可（MenuModuleMapper）
   无 ip / ip.demo → 9200 段不出现（IP-D20）
   有许可、角色未勾 9200 → 侧栏无「行业包」，MES 其余照常
        │
        ▼
④ Vue3 loadView('mes/ip/demo/index')
   普通业务页路径不变
        │
        ▼
⑤ （P1）IndustryExtensionRegistry
   已许可模块的 replace 声明；槽位 (hostPath) 互斥
```

### 2.1 许可后侧栏（两步，IP-D21）

侧栏出现「行业包」必须同时满足：

1. 平台已给该租户许可 `ip.demo`（并派生 `ip`，IP-D5）
2. 该用户所属角色已在 `sys_role_menu` 中勾选 9200 段（工厂管理员或任何能编辑角色菜单的人，在「角色管理」手动勾；**不是**许可写入的副作用）

缺任一步：无「行业包」目录。缺第 2 步时通用 MES（工单 / BOM / 工艺）仍可用。撤许可后第 1 步失效，即使角色仍勾着 9200，许可过滤也会丢掉 `mes/ip` 节点。

## 3. 与现网许可模型的接线

现网工厂可见范围（39 已落地）：

```text
角色菜单 IDs  →  loadMenuTreeByIds
              →  filterByTenantLicense(TenantContext)
              →  buildMenus
```

`filterByTenantLicense`：`licensed == null`（平台回家）则全放；否则仅保留 `resolveMenu ∈ licensed`。**`resolveMenu` 为 null 的节点被丢弃。**

因此「行业包」父节点必须能解析到 `ip`，且该码在许可集中（IP-D5）。

`MenuModuleMapper` 增量（顺序敏感，长前缀在前）：

| path 前缀 | module_code |
| --- | --- |
| `mes/ip/demo` | `ip.demo` |
| `mes/ip/<future>` | `ip.<future>` |
| `mes/ip` | `ip` |

perms 前缀：`mes:ip:demo:` → `ip.demo`；`mes:ip:`（仅壳）→ `ip`。不要把 `mes:ip:demo:list` 误映射成 `ip`。

`selectValidModuleCodes` 现网会丢掉 `platform`/`job`；不要把 `ip` 加进该黑名单。

过期：现网 `expireTime` 不晚于 now 则无效；行业码同样。

## 5. 菜单与权限字（P0）

建议（实现可微调按钮字，但 path / module_code 冻结）：

| menu_id | 名称 | parent | path | component | perms | 映射 |
| --- | --- | --- | --- | --- | --- | --- |
| 9200 | 行业包 | 0 | `mes/ip` | 空 / `ParentView` | `mes:ip:list` 或空目录 | `ip` |
| 9201 | 行业说明 | 9200 | `demo` | `mes/ip/demo/index` | `mes:ip:demo:list` | `ip.demo` |
| 9210 | 查询（F） | 9201 | | | `mes:ip:demo:query` | `ip.demo` |

若 9200 的 perms 为空，必须靠 path `mes/ip` 映射到 `ip`（现网 `resolveMenu` 先 perm 再 path）。目录节点建议写 `mes:ip:list`，避免与 2210 组织架构同类「算不出模块」问题（master `V20260902.33` 前车）。

工厂不得获得 `system:menu:*` 给自己加行业菜单（39 已述）；许可是第二道闸。

## 6. P1 扩展声明（不做插件扫描）

快格云 `IndustryExtensionDecl` 的**字段含义**可保留，载体换成 Java：

```text
IndustryExtensionDecl
  id, moduleCode (ip.*)
  kind: standalone | replace
  replace 时: strategy profile|document
              hostPath（对齐 sys_menu 全路径，如 mes/md/bom）
              hostModule（可选，如 md）
              profileKey / replacementComponent   // 88 可声明，不接线到页面
```

P0 的 `ip.demo`：`kind=standalone`，无 hostPath。

互斥：`saveLicenses` 在事务内，对将要生效的 `ip.*` 收集 replace 声明，`assertNoReplaceSlotConflict`。冲突 → `ServiceException` 400，**整单许可不写**（现网 `saveLicenses` 已是先删后插同一事务）。

不要：前端按 path 拉 `/industry-extensions/document-replacements` 再换组件——现网没有第二套 component 加载器，也没有替换页。

测试：88 用夹具模块码（不必进字典）或包内测试声明，覆盖「两模块同一 hostPath」。

## 9. 抄思路 / 不抄实现

**抄（产品语义）：**

- 侧栏一个行业容器，而不是每个行业一个顶级应用
- 模块可开关；关掉则侧栏回退
- standalone = 行业自己的页，不改通用 MES
- replace 槽位互斥，避免两行业同时改同一宿主菜单

**不抄：**

- Python / Tortoise / 按租户菜单同步 / `rebuild_pack_menus`
- 应用中心、插件目录扫描、`pluginLoader`、动态 `import()` 行业包
- `useDocumentReplacement` + `documentReplacementRegistry`
- TenantConfig `industry.ext.*` profile 种子、Gerber/钢网 JSON
- `spoke-wheel` 同心度、ESD 看板及任何领域模型
- `PackageService` 套餐、`activate-pro`、License Key
- 请求头 `X-Tenant-ID`（与 MES「登录后只信 JWT」冲突）
- 付费行业目录 16 个空码占位
- element-plus-x / UnoCSS 等前端栈（MES 也没有）
