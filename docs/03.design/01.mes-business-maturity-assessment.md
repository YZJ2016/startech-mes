# MES 业务成熟度评估

- 视角：真实离散工厂车间能否靠这套系统独立跑起来
- 评估对象：`yixiang-mes-system/`（后端领域包、Web 管理端、车间平板端）
- 依据：代码与页面静态审查，不是现场实施访谈
- 评分标尺：1–5 分，5 分表示可独立支撑闭环运营
- 评估日期：2026-08-19

## 总评

能跑通主路径，还撑不起工厂闭环。

综合成熟度 **2.7 / 5**（约 54 分）。

这是一套面向离散中小工厂的开源 MES 骨架（苦糖果 / RuoYi），叠了亿翔定制（转运盘、海康摄像头、Godex 打印、售后、合同）。工单 → 任务 → 报工 → 领退料 → IQC / IPQC / OQC 这条主链是通的，适合作为实施基座。

离「可独立运营的成熟 MES」还差一层：质量不卡流程、异常无闭环、追溯只有号段、没有 ERP / 设备采集、权限注解几乎全部被注释掉。

## 车间主链路：每一步卡在哪

### 1. 计划下达

Web 可建工单、按 BOM 展开、确认后生成工位任务。缺：ERP 同步、齐套检查、有限产能排程。计划员仍要靠人判断能不能开线。

### 2. 备料发料

领料/退料单据齐全，执行后走库存事务进虚拟线边库。缺：按任务定额强制发料、缺料安灯、FIFO。仓库可以发错、超发。

### 3. 工位作业

平板选工位、看任务、开始/暂停、报工合格不良待修。缺：强制扫码上料、SOP 作业卡控、设备/工装点检未完成不许开工。

### 4. 过程质量

有 IPQC 单据和缺陷记录。缺：NG 不拦截下工序；不良只记数量，没有隔离库与返工路由。质量是记录，不是闸门。

### 5. 完工入库

关键工序报工会产出到线边库，再走成品入库。缺：OQC 卡入库、序列号绑定工单/批次/操作人、超产自动冻结。

### 6. 发运与售后

有销售出库、退货、售后页。缺：出货与 SN/箱码强制勾稽、客户投诉回追投料批次。售后是单据，不是追溯入口。

## 适用边界

### 适合什么样的工厂

离散机加/装配、几十到一两百人车间、工艺相对稳定、愿意用工位平板报工、库存用单据管理而不是自动仓。

作为实施项目的基座是合格的：主数据、工单任务、仓储事务、三检单据都在，定制成本可控。

### 现在不要承诺的事

不要承诺汽车/医疗级追溯、不要承诺替代 WMS/ERP、不要承诺设备 OEE 和大屏运营、不要承诺「扫码即可防错」。

亿翔定制里，教育评估、学生报表、合同、售后属于周边；转运盘是车间核心却未完成，产品叙事上要分开讲。

## 产品经理结论

按 ISA-95 车间执行层来看，当前系统停在「单据型 MES」：能记账、能报工、能出入库，还不是「纪律型 MES」（闸门、防错、追溯、异常闭环）。下一步不要铺新模块，先把已有生产/质量/库存三条链变成硬约束，平板只暴露已接通的动作。做到这一步，成熟度可以从 2.7 拉到约 3.5，才具备单厂上线条件。

未验证：真实工厂主数据质量、现场扫描枪/打印、与现有 ERP 对账、平板真机与权限菜单配置。评分会随这些运行时证据上下浮动。
